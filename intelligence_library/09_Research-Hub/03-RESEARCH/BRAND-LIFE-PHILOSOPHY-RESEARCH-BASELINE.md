## 1. 哲学母题

### 1.1 Canonical Philosophy

**芥子纳须弥**

### 1.2 当前正式现代化定义

**微小之中本身就包含通向整体的结构。**

### 1.3 解释边界

“芥子”在本体系中不是单纯的尺寸“小”，而是 **最小的有意义单元（smallest meaningful unit）**。它可以表现为信号、数据、事件、行为、关系、知识单元、代码模块、Agent 感知单元或其他具有意义的局部实体。

“须弥”不是单纯的尺寸“大”，而是由关系、结构、意义和演化形成的 **整体（whole）**。

本哲学的核心不应被简化为 `small → big` 或“由小单元机械组装成大系统”。核心关系是：**局部中的结构与关系具有通向、显现和参与整体的潜能。**

## 2. 生命层抽象

当前研究将品牌哲学向生命层提升为一个概念框架，而不是声称已经存在一个名为“Living System”或“Living Intelligence”的正式产品。

    ↓

    ↓

    ↓

    ↓

### 2.2 当前生命层命题

**生命并非孤立单元的简单堆叠，而是在持续关系、反馈与演化中形成并保持为整体的过程。**

该命题属于 `CONCEPT`，用于指导研究、产品哲学和未来架构推演；不得直接当作已实现功能或既定科学结论。

## 6. 方法论原则

### 6.1 从局部理解整体

研究不只统计单点，而要识别局部信号背后的关系、结构、上下文与系统意义。

### 6.2 从整体反哺局部

整体模型形成后，应反过来改善对单个信号、事件、实体和行为的解释。

### 6.3 证据先于结论

任何重要研究结论必须记录来源、证据、推理链、适用范围和验证方式。

### 6.4 可验证地学习

外部技术、开源模型、论文和案例只能作为研究输入。进入生产前必须经过适配、Contract、测试和审计。

### 6.5 可演化但不越权

系统可以持续学习和演化，但演化不能成为绕过权限、生产边界、安全规则或发布 Gate 的理由。

### 7.1 当前状态

### 7.2 最高语义约束

候选名称应能够长期承载以下语义空间：

```text
Part
  ↓
Relation
  ↓
Structure
  ↓
Meaning
  ↓
Intelligence
  ↓
Action
  ↓
Feedback
  ↓
Evolution
  ↓

```

### 7.3 Primary Concept

**Embedded Wholeness**：整体并非后来添加，而是可以通过局部中已有的关系与结构被显现。

### 7.4 Secondary Concepts

- Relation
- Structure
- Meaning
- Revelation
- Intelligence
- Emergence
- Becoming
- Living System

这些均为研究语义，不自动构成产品名称或商标名称。

### 7.5 命名硬门槛

候选必须进行现实世界冲突筛查，至少覆盖：

- Company / Organization
- AI / Software / SaaS
- Robotics / Agent
- GitHub / Developer ecosystem
- Domain / digital presence
- Trademark similarity
- 中文、香港、澳门、韩国、美国、英国、欧盟等主要市场的初步检索
- 发音、拼写和负面语义
- `Core / Intelligence / Research / AI / Platform / OS` 延展性
- 十年生命周期测试

搜索不到冲突不得解释为法律安全；正式商标和法律结论仍需专业检索与当地专业人士确认。

## 8. 研究结果状态体系

| 状态 | 含义 |
|---|---|
| `FACT` | 当前代码、仓库或官方材料已核实 |
| `VERIFIED` | 多来源交叉核实 |
| `PENDING` | 尚需验证 |
| `CONCEPT` | 哲学、架构或未来构想，不代表已实现 |
| `RECOMMENDATION` | 研究后的建议 |
| `LEGAL REVIEW` | 需要专业法律/商标审查 |
| `LEGACY` | 历史资料，不作为当前规范 |
| `REJECT` | 已明确淘汰 |

## 9. 已知命名研究结论

- `Xujing`：作为历史 GitHub / 产品英文用法处理；不作为新的 Canonical English Brand。
- `Avenor`：已发现多个现实软件/AI/数字产品使用，当前研究状态为 `REJECT`。
- `Emergence`：保留为方法论语义词，不作为 Canonical Brand 候选；现实 AI/软件生态中已有明显占用。
- `Living Intelligence`：保留为战略概念，不作为 Canonical Brand；该表达已被多个现实商业/AI主体使用。
- `Invara`：发现现实商业使用，当前不进入最终候选。
- `Orivane` / `Inerra`：历史创意候选，仅可作为研究样本；尚未通过完整全球冲突筛查，不得视为可用品牌。
