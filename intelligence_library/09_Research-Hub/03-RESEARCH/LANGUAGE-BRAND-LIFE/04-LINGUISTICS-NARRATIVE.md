## 1. 语义引力（Semantic Gravity）

**[Semantic Gravity（LCT 学术定义）]** E3 / VERIFIED / 英 / 2014– / Maton, *Knowledge and Knowers* (Legitimation Code Theory)
- 学术定义：语义引力 = 意义的**具体性/接地性**程度标度——从"最具体、情境绑定、here-and-now"到"最抽象、去情境、普适"。
- 相伴概念：Semantic Density（语义密度）= 符号内意义凝聚的程度。
- 命名启示：一个名称的语义引力越高，越"粘着"于既有含义；**品牌命名需要"恰当的语义引力"**——既要有可被直觉理解的具体锚点，又要保留抽象延展空间。

**[Semantic Gravity（AI/提示词工程转义）]** E2 / VERIFIED / 英 / 2026 / xram.net《Semantic Gravity》
- 转义：token 的习见含义对解释的"牵引力"，可强到覆盖显式指令（例：字段名 `Final Result` 让模型填入结论而非数据值）。
- 工程启示：schema/字段/变量命名是隐式指令；命名越"重"越会把处理拉向常规语义。**命名本身就是约束**——与序境"命名体系不可自改、名称约束处理"一致。
- 与序境命名协议：候选名称应评估"语义引力方向"——是否自然吸附品牌母题（Embedded Wholeness / Relation / Life）而非吸附到无关或负面常规义。

## 2. 音义联想 / 声音象征（Phonetic Symbolism）

**[bouba-kiki 效应]** E3 / VERIFIED / 跨文化（英/坦米尔语等） / 2001– / Ramachandran & Hubbard；跨语言 95% 一致
- 圆润形状→"bouba"（浊音/圆元音），尖刺形状→"kiki"（清塞音/高前元音）；跨语言稳定。
- 命名含义：辅音/元音结构携带无意识联觉——高频前元音≈小/轻/锐/女性气质；低频后元音≈大/重/圆/阳刚。

**[Sapir mil/mal 实验 + 音类联想]** E3 / VERIFIED / 英 / 1929– / Sapir；PBS *The Hidden Linguistic Messages in Brand Names*
- 语音分类联想（业界实证）：
  - 清塞音（p/t/k）：小、轻、锐（Pepsi, Tic Tac, Kodak）
  - 浊塞音（b/d/g）：有力、奢华（Duracell, Godiva, Balenciaga）
  - 摩擦音（f/s/sh/v/z）：柔、快、轻（Febreze, Silk, Swiffer）
  - 鼻音（m/n）：暖、亲切（Amazon, McDonald's, Nike）
  - 流音（l/r）：流畅、可靠（LinkedIn, Rolls-Royce, Rolex）
- 命名含义：音素结构是品牌性格的潜意识编码；跨语言还需检查 phoneme inventory（音位库）、音节结构（CVC vs CV）、声调语言（中/泰）与书写转写。

**[中文命名语言学规律]** E3 / VERIFIED / 中 / 学术（ResearchGate 两项） / Huang & Chan
- 中文好名的语言学偏好：
  - **双音节**（90.5% 偏好；现代汉语双音化）
  - **高调（H-H / L-H 调组合）**：响亮易记（47.13% H-H vs 8.91% L-L）
  - **积极涵义**（66%+ 正向语义）
  - **偏正复合结构**（modifier-noun）
- 含义：序境中文名符合双音节+正向；韩文名 서경 需对应评估韩文音韵与语义。

## 3. 品牌命名方法论（跨文化）

**[命名五大路径]** E3 / VERIFIED / 中英 / 2026 / NAMERS 方法论 + 行业
1. 具象描述法：名称即说明书，沟通成本最低但商标显著性弱（全棉时代）。
2. 意向隐喻法：借自然/神话/日常具象转移品质联想，审美溢价+情感共鸣（Apple, 天猫）。
3. 创始人/家族命名法：信任契约（Chanel, Ford, 李宁）。
4. 抽象/生造法：独创词，商标护城河深+多义封装（Rolex, Sony），需遵循"声学编码"。
5. 文化/成语借代法：借集体潜意识（中国品牌专属优势）。
- 与序境：英文 Canonical 命名主路径应偏向 **4+2（生造/抽象 + 隐喻）**，兼顾全球语音与语义引力。

**[跨语言负面含义清单法]** E3 / VERIFIED / 多语 / 2026 / MADnext + 行业通识
- 必须跨市场检查音义：Nova（西语"不走"）、Bing（中文"病"音近）等反例；需检查音位库、音节结构、声调、书写转写。
- 对应序境命名协议第 2 步"全球语言学负面含义排查"。

**[AI 时代的命名实体消歧]** E3 / VERIFIED / 英 / 2026 / Mental Momentum Research
- 品牌名正成为 AI 推荐系统的"锚定实体"：语音助手/购物 Agent/LLM 采买短名单在无人工检视阶段按名称消歧；高泛化/易混淆/词典化名称会被算法降权。
- 命名含义：**音韵独特、结构独特、语义一致的名称 = 更强的机器实体消歧**，同时利于人类记忆与算法检索。

## 4. 品牌—文化语境（中 / 英 / 韩）

**[中文语境]** E3 / VERIFIED / 中 / 2026 / 学术+行业
- 双音节、高调、正向、偏正结构；语义场与文化记忆（诗词/成语/节令）是重要借力资源。
- 序境：双音节 ✓、正向 ✓、与"境界/环境/序"的东方宇宙观同频。

**[英文语境]** E2 / VERIFIED / 英 / 2026 / 语言学+命名研究
- 2–3 音节最佳，清浊音结构编码性格；拉丁/希腊词根=科学可信，法语音=奢感，日耳曼=工程可靠，盎格鲁-撒克逊=亲和诚实。
- 序境英文候选应避免"词典化重词"（语义引力过强、商标弱、算法难消歧），倾向轻量独创词。

**[韩文语境]** E1 / CONCEPT / 韩 / v1.0 2026-09-04 / 本库
- 서경（序境）为 Canonical 韩文名；韩文命名需评估谚文书写、音韵（是否双音节/响亮）、汉字义（序=秩序/顺序，境=境界/场域）、以及韩语负面音近词。
- 待补：韩文命名候选生成与全球排查（遵循 05 协议）。

## 5. 内容创作 / 创意营销 / 故事叙事 / 舆情传播

**[语义密度与叙事张力]** E2 / VERIFIED / 英 / 2013– / Maton LCT
- 高语义密度（意义浓缩的符号/金句）+ 语义引力的来回移动（抽象↔具体）= 累积性叙事与知识建构。
- 与序境：内容创作应"一句高密度金句 + 可下钻到 Evidence 的具体事实"，对应 Source→Evidence→Knowledge→Insight→Recommendation。

**[故事弧与母题复用]** E1 / CONCEPT / 通用 / v1.0 2026-09-04 / 本库
- 前沿叙事母题（可复用为创意引擎角度）：从局部窥见整体（芥子纳须弥）、关系的显现（Relational Becoming）、危机即转机（对比/反向）、文化盟友（声音/符号转译）、用户共创（真实证据）。
- 对应创意引擎已有机制：constraint/culture/symbolize/eventify/participate/cocreate/reverse/resonate/sit。

**[舆情分析与传播]** E1 / CONCEPT / 中英 / v1.0 2026-09-04 / 本库
- 舆情 = 语义引力在人群中的传播动力学：一条信息被"吸附/放大/曲解"取决于其语义引力方向与圈层语义场。
- 与 ZBC：单条事件（芥子）→ 全网结构/传播路径（须弥）→ 回馈单条解读与应对建议；所有结论以 Evidence 支撑，不得伪造。
