# GitHub / Mainline
main is the only writable development/integration/production-candidate branch. Reconcile local state with origin/main and preserve unknown work. Never force-push main or routinely create task branches/PRs. Use GitHub for remote truth/CI and Git CLI for local truth. A local commit is not remote evidence until pushed.
