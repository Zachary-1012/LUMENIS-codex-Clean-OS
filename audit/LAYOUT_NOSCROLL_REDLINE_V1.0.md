# ZBC 布局红线：No-Scroll 有限视口 · PC/手机双端 V1.0

> 2026-09-06 用户明确："禁止滑动超出 PC 端和手机端尺寸范围，放不下就理清层级关系，不要大铺面"
> 对齐既有 audit/WEB-NOSCROLL-CONTRACT-original.md（WEB-NO-SCROLL v1.0，P0/normative），本文件是其在 ZBC 的可执行落地版，所有页面（ZBMP/CTH/SYSTEM，含新设置页）强制遵守。

## 一、硬规则
1. **整页不滚动**：document/body 与页面外壳不得成为纵向滚动容器。PC 主工作区锁定在视口高度内（100dvh 减去顶栏+左侧导航），移动端锁定 100dvh 并适配安全区(safe-area-inset)。
2. **只有"数据集合"允许局部滚动，且必须有界**：表格/长列表/日志流可用 `overflow:auto` 的内部容器，但要有明确 owner、固定高度边界、可见滚动归属；**禁止嵌套失控滚动容器、禁止外层页面跟着滚**。
2.1 **横向叠层滑动（用户指定，纵向不滚的合法补充）**：同级、可枚举、并列的一组卡片放不下时，允许做成**横向分页叠层滑动**（对标 iOS 照片"合并发送后左右滑动浏览、点开可展开"），边界必须清楚：
   - 仅用于同级并列内容组（一组 KPI/事件/成员/图表卡），不得用来掩盖层级混乱；一个视口内横滑容器数量克制，禁止横滑套横滑、禁止横竖嵌套失控。
   - 横滑容器同样有界：固定高度、明确 owner、不引起页面纵向滚动；必须带位置指示（分页圆点 / 第n张共m张 / 进度条），且除手势外提供箭头/按钮可达（PC 箭头+拖拽，手机 swipe，双端一致）。
   - 单卡"点开可展开"=模态聚焦层(sheet/dialog/聚焦详情)，遵守弹层契约：明确边界、Esc/返回关闭、焦点返回、不超视口；展开层内仍不整页纵滚。
   - 卡片尺寸、间距、"露出下一张"的预览量统一为设计 token，不逐页随意。
3. **放不下→建层级，不铺面、不缩到不可用**：
   - L1 摘要/核心结论首屏常显（Core）
   - Primary 空间允许时显示；Secondary 紧凑或可展开
   - Deep detail 进 Tab/子路由/抽屉(sheet)/弹层(dialog/popover)/聚焦详情，不堆在同一屏
   - 优先用：页内 Tab 分区、折叠面板、右侧聚焦抽屉（非常驻右栏）、详情弹层、二级路由；而不是无限加卡片
4. **不追求塞满屏幕**：目标是"每次交互的最大有效信息且不拥挤"，产品气质 integrated / compact / calm / operational；卡片网格按视口自适应列数，宁可一屏少而清，不要大铺面。
5. **导航模型**：左侧导航 → 中央工作区；默认不设永久右侧上下文栏；超过一屏的功能变成子状态/路由/弹层。
6. **弹层契约**：单一 owner / 单一挂载点 / 统一 z 层 / 明确开关 / 焦点返回 / Esc与返回关闭 / 不超出视口边界；不靠堆 z-index 解决布局冲突。
7. **防覆盖自检（每页必查）**：单一 render/state/layout/overlay owner；无重复 mount；无竞争异步渲染；无误生 stacking context；**无失控 overflow、无内容被隐藏裁剪(hidden clipping)**。
8. **材质克制**：玻璃/渐变/毛玻璃是功能层不是装饰，避免 glass-on-glass 和大面积装饰玻璃；优先级 信息 > 功能 > 层级 > 动效 > 装饰（渐变新元素只用在关键数据卡/CTA/viz，不用来铺面）。
9. **动效有界**：每个动效有触发/起止态/时长缓动token/可中断/降级(reduced-motion)，不遮挡内容与交互。
10. **可见即真实**：每个可见值映射 runtime/view-model（/api/viz 函数驱动），状态反映真实生命周期 DEFINED→…→VERIFIED；缺失 null/—，不造数、不用静态成功态。

## 二、双端断点与尺寸约束
- PC（≥1280）：左侧导航 + 中央 bounded workspace；卡片网格 auto-fit minmax，核心 KPI 一行内；详情走抽屉/弹层。
- 笔记本（1024–1279）：压缩留白、合并次要列、Tab 收纳。
- 平板/手机（<1024 / <768）：导航收为抽屉或底部 tab；单列；顶部筛选折叠；表格改卡片列表或横向有界滚动（外层页面仍不纵向滚）；触控目标≥44px；适配安全区与 dvh，不出现整页溢出与横向误滑。
- 任何端：不出现 body 级纵向滚动条；用浏览器实测 1280/1440/1920 与 390×844(iPhone) 两档验证无溢出。

## 三、验收（每页 Delivery Ready 必过）
- [ ] 初始视口内看到核心信息，无外层纵向/横向滚动条
- [ ] 长表格/列表只在有界内部容器滚动，外层稳定
- [ ] 深层信息经 Tab/抽屉/弹层/二级可达，未堆在首屏
- [ ] 弹层不遮挡必要控件、不超视口、Esc/返回可关、焦点正确
- [ ] 1280/1440/1920 + 390×844 实测均无溢出、无隐藏裁剪
- [ ] 状态切换时布局不跳动；live 值来自 runtime；数据精准；既有功能回归通过
- [ ] 不缩到不可用、也不无限拉长；不大铺面、不 glass-on-glass
