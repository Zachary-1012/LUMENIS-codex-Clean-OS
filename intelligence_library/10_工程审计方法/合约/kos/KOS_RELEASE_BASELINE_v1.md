# KOS Release Baseline v1

## Current acceptance priority
1. Real usable output today.
2. Collection accuracy and entity ownership gates.
3. KOS account asset management.
4. Contextual operations: comments, outreach, email, cooperation and paid amplification recommendations.
5. Analytics and dynamic HTML reporting.

## Mandatory convergence
All KOS UI, interaction, code and capabilities must follow the global convergence gate. Reuse authoritative capabilities before adapting or developing new ones.

## Business flow
Collection -> quality gate -> entity ownership -> KOS identification -> Evidence -> scoring/tiering -> account asset -> operations -> outcome -> feedback -> reporting.

## UI rule
Use the global design system while adapting information hierarchy to task intent. KOS is account-first: list for scan/compare, detail for 360-degree source of truth, actions driven by account state.

## Truth and safety
No fabricated collection results, metrics, outreach status, delivery status, cooperation status, ROI, or test results. Unverified/anomalous records are quarantined and cannot contaminate official KOS decisions.
