> 源视频：`ca72d2a39b533181736e0f83b3a2a176_raw.mp4`（微信，222.7MB，**157.18s / 1206×2622 / 60fps / HEVC**）

> 用途：ZBC/ZBMP 手机端与网页端 UI/UX 施工的**动效与组件事实基线**，与侘寂黑白灰 Design Token 配合。结论全部来自逐帧实测，非印象。

## 0. 视频内容全貌
ChatGPT App 深色起手，完整走了：对话 → 附件菜单 → 键盘 → 全局侧边抽屉 → 资料库/项目/已计划/插件/远程 → 全局搜索 → 设置（深色）→ 控制中心切浅色 → 设置浅色态 → 订阅/强调色/通知/家长控制/声音/语言/安全登录。覆盖列表、表单、弹层、导航、主题、空/加载态几乎全部基础组件。

## 1. 颜色与分层（最重要，纠正"一片黑/一片白"）
- **深色**：页面底近黑 `#0d0d0d`；分组卡比底亮一档 `#1c1c1e`；输入/代码块再亮一档 `#2c2c2e`；分隔线极淡 `#2c2c2e@低透明`；主文字 `#f5f5f7`、次文字 `#8e8e93`；强调蓝 `#0a84ff`。
- **浅色**：页面底是**浅灰** `#f2f2f7`（不是白）；分组卡纯白 `#fff`；分隔 `#e5e5ea`；主文字 `#1c1c1e`、次文字 `#86868b`；强调蓝同。
- **分块靠"底色明度差"，不靠描边**：几乎没有可见硬边框，靠 底→卡→输入 三级明度差分层。→ 我们当前"每块都描边"的做法要收敛为弱边框/明度分层。
- 语义色极克制：蓝=可点/选中/发送/链接；系统绿 `#34c759` 只用于开关"开"；红只用于危险/关闭；其余全部黑白灰。状态=小圆点+文字，颜色不作唯一表达。

## 2. 组件量化规范
| 组件 | 实测规范 |
|---|---|
| 分组容器 | inset-grouped：圆角 10–12，组内行间细分隔线且**左缩进到文字**（不贴图标），组间留白 24–32 |
| 列表行 | 高 44–48；左线性图标 20–22 + 标题 15–17pt；右侧"次色小值 + chevron ›"；点按行底色变灰作反馈 |
| 导航栏 | 居中标题；模态页 X 关闭；push 页左上"< 返回"；大标题在滚动内容内、组标题吸顶 |
| 输入条 | 全圆角胶囊（半径≈高/2），左"+"附件、右语音/蓝色圆形发送；贴底，随键盘同步上移 |
| 附件菜单 | 相机/照片/文件/插件/深入思考，线性图标+文字，**从输入条向上贴附生长**（非居中） |
| 代码块 | 比卡深一档底、等宽字、右上复制/全屏小图标、可横滚 |
| 弹层选择 | anchored 白色小卡，选项前纯色小圆点，选中项加 ✓，非模态、点外部即关 |
| 开关 | iOS 全圆滑块，开=系统绿 |
| 加载态 | 灰色 skeleton 圆角条脉冲（无 spinner 海）；无结果=居中线性图标+一句话+一个小主按钮 |
| Hero/头像 | 设置顶部圆形头像居中；语音模型=大圆形渐变球；功能空页=居中线性图标+标题+说明+主次全宽按钮 |
| 主/次按钮 | 主=实心胶囊（深色白字/浅色黑字）；次=透明/描边胶囊，同宽并列 |

## 3. 动效质感（60fps 实测，全部量化）
| 交互 | 触发与过程 | 时长/曲线 |
|---|---|---|
| 键盘 | 自底部上滑，输入条紧贴键盘顶同步上移，**页面主体不跳** | ~0.25–0.3s，spring |
| 附件/锚点菜单 | 从触发元素位置向上生长、fade+轻微 scale | ~0.2s ease-out |
| 侧边抽屉 | 自左滑入占≈85% 宽；底层右移并压暗、**不缩放保持全高**；遮罩点击反向 | ~0.3s ease-out |
| anchored popover（强调色/外观/模型/语言） | 从锚点行 `scale(.92→1)+opacity 0→1`；**非模态、底层不压暗、点外即关**；选中即时回写行值；关闭反向 | ~0.2–0.25s |
| push 二级页 | 新页自右 `translateX(100%→0)`，底层左移≈28% 并加投影/微暗；左上出现"<" | ~0.32s spring |
| pop 返回 | 新页向右滑出、底层回位（push 反向） | ~0.3s |
| 模态 sheet（设置） | 近全屏卡片盖入，带 X；高打断才用 | ~0.3s |
| **深↔浅主题切换** | 控制中心选定后**全页语义色同步 cross-fade，零位移、零布局变化** | ~0.25s |
| 滚动 | 惯性滚动，组标题吸顶；skeleton→内容平滑替换 | — |

**动效总原则（钉死）**
1. 时长只在 **200 / 250 / 320ms** 三档；统一缓动 `cubic-bezier(.22,1,.36,1)`（近似 iOS ease-out/spring）。
2. 动的只有 **位移 / 透明度 / ≤1.08 的轻微缩放**；**绝不动布局尺寸、不跳变、不重排**。
3. 新层出现必有方向：**左=抽屉、右=push 详情、下=键盘/动作表、锚点=选择 popover、居中=高打断模态**。
4. **同一时刻只有一个主动效层 / 一个模态**（直接对治此前"日报弹窗+ZBMP 密钥门叠加、点击被覆盖"的 bug：选择类一律改非模态 popover，只有登录/确认/高打断才居中，且互斥）。
5. 每次点按都有反馈：行高亮 / ✓ / 开关位移 / 发送钮变色，必要时配 haptic。

## 4. 信息架构观察（对应我们的层级）
- 顶层用**左侧抽屉**承载"全局空间切换 + 会话/项目历史 + 新建/设置"，工作区主界面保持干净（对应我们的 CTH-POMS / ZBMP 工作区切换器，方向一致）。
- 二级内容（资料库/项目/插件/设置子页）统一 **push 进栈**，顶部 segmented 切换同页维度，列表搜索贴底/贴顶。
- "设置"是**独立 self-contained sheet**：头像 hero → 分组列表 → 子页 push，和业务内容隔离。对应我们"系统设置"应是独立栈，不在主导航里堆卡片。

## 5. 对 ZBC/ZBMP 的直接施工映射（本轮起执行）
1. 三级明度分层落地：页面底 / 卡 / 输入(代码) 三档，弱化硬描边；深浅两套 token，切换零位移 cross-fade。
2. 新增统一动效 token（`--zb-dur-1/2/3`、`--zb-ease-ios`）与四类运动原语：drawer / push / popover / sheet；禁止随手写 transition。
3. 二级详情改 **push（右入左出）**；枚举/筛选/选择改 **anchored popover（非模态）**；仅登录、危险确认、高打断用居中模态且全局互斥。
4. 列表统一 inset-grouped：行 44–48、分隔线缩进、组间大留白、行右值+chevron。
5. 加载统一 skeleton，空状态统一"线性图标+一句话+主操作"。
6. 输入条胶囊化、贴底、随键盘上移；"+"附件用 anchored 动作菜单。
7. 语义色收敛：蓝可点/选中、绿仅开关、红仅危险，状态一律小圆点+文字+线性图标三表达。
