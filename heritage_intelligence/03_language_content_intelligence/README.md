# Language & Content Intelligence

本域保存语言、语境、本地化、内容表达与跨语言创作知识，不是语言教材，也不直接成为 Production Runtime。

当前 Collections：

- P0：[`Korean Content Intelligence Collection`](Korean_Content_Intelligence_Collection/README.md)
- Content Production：[`Xiaohongshu Brand Content Intelligence Collection`](Xiaohongshu_Brand_Content_Intelligence_Collection/README.md)

其中 Xiaohongshu Brand Content Intelligence Collection 用于沉淀品牌内容、商业体内容、活动内容、会员内容、视频笔记与情绪型内容的语言结构、叙事机制、生产流程与评估方法。只学习机制与方法，不机械复刻历史文案。

准入链：

```text
Source → Provenance → Semantic Review → Copyright/License Review
→ Current Equivalent → Decision → Optional Capability Promotion
```

禁止保存完整影视台词、完整字幕、未经授权字幕包或第三方受限源码；外部品牌/平台内容进入学习资产时应优先保存结构化研究结论、来源信息与可复用方法，而非大段复制原文。
