# 广告投流与深度学习模块设计文档 v1.0

## 一、模块定位

`ad_intelligence` 是序境/LUMENIS 的商业应用级广告投流智能模块，负责：
- 全平台广告数据采集与分析（只读）
- 投流策略生成与优化（AI 辅助）
- 深度学习模型（CTR/CVR 预测、智能出价）
- 投流操作执行（带 Permission Gate，默认关闭，需人工确认）

## 二、红线原则

1. **投流操作默认关闭**：所有写操作（创建计划、修改出价、暂停/启动）必须经过 Permission Gate + 人工确认
2. **资金操作最高保护**：任何涉及预算调整、出价修改的操作必须人工二次确认
3. **只读优先**：数据采集、分析、预测默认可用；写操作需显式授权
4. **不破解平台 API**：使用官方 API 或浏览器只读采集，不对抗平台风控
5. **可追溯**：所有投流操作必须记录操作人、时间、前后状态、审批记录

## 四、权限等级

| 等级 | 能力 | 默认 | 说明 |
|------|------|------|------|
| READ | 数据采集、查看 | ✅ 启用 | 只读广告数据 |
| ANALYZE | 分析、预测、建议 | ✅ 启用 | AI 分析与预测 |
| PREVIEW | 策略预览、模拟 | ⚠️ 需授权 | 模拟投流效果，不实际执行 |
| EXECUTE | 实际投流操作 | ❌ 关闭 | 创建/修改/暂停计划，必须人工确认 |

## 五、深度学习模型

### 5.1 CTR 预测模型
- 输入：用户特征 + 广告特征 + 上下文特征
- 输出：点击率预测概率
- 模型：DeepFM / DCN / 轻量级 GBDT+LR
- 训练数据：历史广告曝光-点击数据

### 5.2 CVR 预测模型
- 输入：点击后行为序列 + 用户画像 + 商品特征
- 输出：转化率预测概率
- 模型：DIN / DIEN / 序列模型
- 训练数据：历史点击-转化数据

### 5.3 智能出价优化
- 目标：最大化 ROAS 或 转化量
- 约束：预算、出价上下限
- 算法：强化学习 / 贝叶斯优化 / 线性规划
- 安全：出价建议必须人工确认后执行

### 5.4 特征工程
- 用户特征：年龄、性别、地域、兴趣、行为序列
- 广告特征：素材、文案、定向、出价、落地页
- 上下文特征：时间、平台、竞争强度
- 实时特征：当前曝光量、点击率、转化率

## 七、投流策略框架

### 7.1 受众定向
- 基础定向：年龄、性别、地域
- 兴趣定向：兴趣标签、行为标签
- 自定义受众：种子人群、相似人群（Lookalike）
- 再营销：已互动用户、已访问用户

### 7.2 预算分配
- 日预算/总预算
- 多计划预算分配（按 ROAS 动态调整）
- 预算 pacing（匀速/加速）

### 7.3 出价策略
- CPC（按点击付费）
- CPM（按千次曝光付费）
- oCPM（优化千次曝光）
- 智能出价（目标成本/目标 ROAS）

## 八、与主系统集成

- 广告数据 → 数据资产层（统一存储）
- 投流策略 → AI Gateway（智谱 glm-5.3 深度推理）
- 深度学习模型 → 本地 Ollama / 智谱 API
- 投流操作 → Permission Gate（11 级权限模型）
- 操作记录 → Evidence Chain（全链路追溯）

## 十、商业应用级标准

1. **数据准确性**：广告数据与平台后台误差 < 1%
2. **预测精度**：CTR/CVR 预测 AUC > 0.75
3. **响应速度**：数据采集 < 5 分钟延迟
4. **安全性**：所有写操作可追溯、可回滚
5. **稳定性**：7×24 小时运行，故障自动恢复
6. **可解释性**：AI 建议必须给出理由和置信度
