# CTH 商业主体数据情报采用研究

> 研究日期：2026-09-27　｜　基线：`origin/main = b6974d5847cd2997ef279a556e1eeae519ac75f6`　｜　访问日期：2026-09-27
> 状态：有界桌面研究与现有 owner 映射；不是生产数据、来源授权、运行验收或商业就绪证明。
> 范围：广州太古汇与罗湖深圳万象城作为受控案例，探索 CTH 商业主体的运营决策情报。未访问产品 DB、账号、Cookie、XHS/RedNote 浏览器或运行采集。

## 研究结论

CTH 的商业主体研究应围绕可核验的运营问题组织，而非把“商业情报”变成新的产品领域。现有产品定位已经规定 CTH 为 Subject-first 商业运营，覆盖商业主体、场地、品牌/品类、事件、案例、风险、决策、行动和报告。消费者反馈、社媒传播和媒体报道是解释运营变化的信号来源；它们不能代替出租/销售/客流等主体或运营方披露的数据，也不能单独证明现场库存、门店执行、经营原因或行动成效。

优先形成“真实运营证据 + 市场背景 + 消费者/传播早期信号”的证据组合：运营方/监管者/上市披露提供直接经营状态；官方统计提供城市/行业基线；有权处理的消费者反馈及公开媒体/社媒提供体验、关注和风险线索。每种信号必须保留空间、主体、时间窗口、口径、来源权利、捕获状态及证据链，并说明哪些结论是观察、解释或待确认假设。

**研究事实**：国家统计局报告 2025 年社零总额 50.1202 万亿元、同比增长 3.7%；广州 2025 年社零 11,032.38 亿元、增长 5.5%；深圳 2025 年社零 10,259.93 亿元、增长 2.3%。这些是不同层级的宏观基线，不代表任一商场销售额或市场份额。[国家统计局](https://www.stats.gov.cn/zwfwck/sjfb/202601/t20260119_1962323.html)（2026-01-19），[广州市统计局](https://tjj.gz.gov.cn/stats_newtjyw/sjfb/content/mpost_10670158.html)（2026-01-30），[深圳市统计局](https://tjj.sz.gov.cn/szstjjwzgkml/szstjjwzgkml/sjfb/tjfx/content/post_12624918.html)（2026 年发布）。

**推断**：能支撑真正运营判断的差异化价值在于跨信号核验及把信号送入 Case → Decision → approved Action → Outcome，而不是多抓几个平台、做单一热度榜或生成未核实的运营建议。公开材料仅能证明其披露范围内的事实；太古汇和万象城也不能代表全球商业主体覆盖。

## 真实岗位、任务与决策

1. **商业主体/商场运营负责人**：回答“本主体当前发生了什么、哪些业务单元受影响、什么已证实、应该由谁在何时处理？”检查运营方披露的出租/零售销售、招商与开闭店、租户组合、活动、服务投诉、安全/监管事件和竞品变化；形成有证据的 Case、责任人、待核实项、允许的行动与回访指标。现场库存、活动执行、店铺销售等非公开运营事实须由获授权的内部系统/人员提供；外部声量不能替代它们。
2. **区域/资产管理者**：比较一个商圈或一组商场在明示时间窗和口径下的结构变化，区分城市大盘、主体披露与项目事件的差异；识别租户流失、空置、客流/转化风险或机会并确定需补充的内部资料。不可把年度出租率与短期社媒热度直接相加成分数。
3. **消费者体验/舆情负责人**：发现主题重复出现、影响面扩散或高严重度投诉，回看原始发布与官方回应，区分个人意见、可核实服务故障、正式通报和确认事件；按现有权限升级案例、答复或服务补救，跟踪后续证据与反馈。公众帖子是线索而非对作者身份、代表性或事实性的证明。

这些任务可由现有 CTH/Shared/SYSTEM owners 承接：Subject/Registry/context 负责对象与范围，Collector 负责获准获取，Evidence/Canonical 负责来源与事实谱系，CTH 业务调用方负责事件/Case/决策意义，Permission/effect fence 负责可见范围和行动，Reporting/Evaluation/Learning 负责可复核结果。不要创建新的情报、消费者画像、数据仓库或决策 owner。

## 证据强弱与运营决策门槛

- **事实**：原始来源明确陈述的内容，如运营方年报披露的出租率、政府公告记载的活动时间、统计局发布的城市社零。展示来源范围、原文和时间。
- **观察/指标**：按版本化口径计算的变化或样本分布。必须有分子/分母、窗口、实体范围、去重方法、来源集合与计算版本；比较前检查单位、基期、币种、汇总层级、缺项与重述。
- **推断/建议**：如“客流改善可能与活动有关”。需列出证据支持、反证/其他解释、信心与人工确认状态；模型输出是派生建议，不成为 Canonical Truth、Permission 或已发生结果。
- **行动/结果**：决策须由适格用户审核；发布、联系、支付、外部经营动作须沿现有 Permission → Approval → Effect Fence。行动完成必须由行动结果 Evidence 证实，并记录后续指标和评价。社交平台只读采集本身不授予发布/回复权限。

来源许可记录至少应包括来源主体、条款/API 版本和检查日期、目的/可处理范围、是否含个人信息、保存/删除要求、跨境限制、商业再分发范围、允许的字段与速率、授权负责人及复核时间。2025-01-01 生效的《网络数据安全管理条例》要求数据处理者承担网络数据安全责任；《个人信息保护法》强调明确合理目的、最小必要，且处理已公开个人信息仍限于合理范围，重大影响须依法取得同意。把“公开可见”推成“可批量抓取/画像/商用”没有依据；涉及个人特征/敏感或可识别位置数据时必须由现有合规/Permission owner 审查，不能因社媒来源公开而跳过。[《个人信息保护法》](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)，[《网络数据安全管理条例》](https://www.cac.gov.cn/2024-09/30/c_1729384452307680.htm)。

## 全球覆盖与受控案例

### 全球 / GLOBAL / ALL

宏观统计、交易所披露、公司年报、监管公告、行业组织调查和获许可的地图/消费者研究可作为全球来源**类别**。跨地区的官方经营方披露可提供口径样例：美国 Simon Property Group 披露其美国商场与 Premium Outlets 2025-12-31 出租率 96.4%，并定义了租金/每平方英尺零售销售额的组合口径；它的地产组合与中国商场定义不可直接横比。[Simon 2025 全年业绩](https://investors.simon.com/news-releases/news-release-details/simonr-reports-fourth-quarter-and-full-year-2025-results)（2026-02-02）。每个国家/地区、语言、行业、场地形态和来源的数据制度、发布周期、许可与实体身份规则不同。先由 Product Owner 批准一个可版本化的基线定义：声明覆盖地域、零售/商业资产类型、纳入标准、命名/别名和关系消歧、排除/并列规则、来源/版本、更新时间与授权边界；随后由 Canonical Registry/Evidence owners 建立清单、覆盖分母及成熟度。基线不表示“全世界所有商业主体”，长尾/不可授权对象应可查询并诚实显示 `NOT_COLLECTED` / `NOT_CONFIGURED` / `BLOCKED` 等状态，之后按同一 canonical path 扩展。

当前未发现 Product Owner 已批准的全球重要商业体纳入规则及完整主体基线。全国统计数字、一个上市运营商组合、行业问卷、少数示范场地或本次三地来源样本均不能构成全球覆盖；`Global Commercial Coverage=NO / NOT VERIFIED`，`LUMENIS_INTERNAL_FULL_UNIVERSE_READY=NO` 应按现行契约保持。

### 广州太古汇 / 深度参考 Subject

太古地产 2025 年度业绩披露，广州太古汇 2025 年零售销售额同比增长 2%，截至 2025-12-31 出租率 100%，太古地产权益 97%。这是高质量经营方年报信号，粒度为项目年度汇总；不能推出具体品牌或门店销售、日常客流、租户库存、增长原因或 2026 实时状态。广州全年社零增长 5.5% 可作为宏观参照，不是同口径比较基准。[Swire Properties 2025 Annual Results](https://www.swireproperties.com/-/media/files/swireproperties/results-announcement/swire-properties-2025-annual-results_e.ashx)（2026 年 3 月；访问 2026-09-27）。

### 罗湖深圳万象城 / 额外 CTH 案例

罗湖区商务局关于 2025 米其林美食节的政府稿区分活动现场 3 天入场逾 3 万人次、现场营业额逾 350 万元、**蔡屋围商圈** 3 天客流逾 60 万人次（同比 +15%）、周边商圈消费逾 2 亿元（同比 +25%）。这是可核实的事件/商圈联合运营信号，主体层级与空间范围不可混用：现场营业额属于活动，不等于商场销售额；商圈客流与消费不等于万象城独有指标。[深圳市政府/罗湖区商务局](https://www.sz.gov.cn/szzt2010/yhyshj/yszx/content/post_12463827.html)（2025-10-29）。深圳市政府公开的智能客流项目需求曾描述人流摄像去重、热点/拥堵、顾客标签、优惠推送和室内导航；这只证明项目构想/采购需求曾公开，不能证明系统已部署、数据对外开放或 LUMENIS 有权获取。[深圳市发改委](https://fgw.sz.gov.cn/ztzl/qtztzl/szscjmyjjfzzhfwpt/scdj/yycjqd/fmxf/content/post_12276228.html)（2025-07-11）。

深圳全市 2025 社零增长 2.3% 同样只是城市基线。深圳万象城（罗湖）不得与深圳湾万象城、深圳万象天地或深圳龙岗/布吉万象系项目混为同一 Subject；即使集团年报披露组合数据，也应按实体 ID 和经营/持有口径分别核实。[深圳市统计局](https://tjj.sz.gov.cn/szstjjwzgkml/szstjjwzgkml/sjfb/tjfx/content/post_12624918.html)。本次未找到可据以声称罗湖深圳万象城全年客流、出租率或销售额的 2025 公开项目级原始披露；该字段应为 `NOT_AVAILABLE / NOT_COLLECTED`，继续寻找获许可的运营方数据。

### 2025–2026 行业旁证

## 数据质量 / 验收要求

沿用现有 Global Universe / Real Delivery Overlay 与 owner 合约，不另设总分或覆盖阈值：

1. 固定真实岗位与决策产物；输入为当前获准主体与其真实来源。真实 E2E 从 GLOBAL / ALL 或主体上下文进入，检索来源，形成 Case/Decision 和获准后续动作，展示用户结果、缺口、证据和回到原主体工作的路径。
2. 报告授权来源覆盖、来源成功/失败/限流/不支持、最后尝试、刷新/重试安排和来源缺口；同一版纳入规则应给出覆盖分母。来源不可得是缺口，不是数值零或空成功。
3. 按实体、关系、地区、语言、来源、事件类型与时效作可重现抽样；包括广州太古汇、罗湖深圳万象城和旋转的非参考跨区域主体。注册实体样本不能定义全球基线。若注册人口/成熟度字段不存在，报告样本数 0 和 owning gap。
4. 指标须明确单位、币种、权益/合并口径、统计空间、比较期、分母和发布日期；日期分别保留 `captured_at / collected_at / published_at / occurred_at / metric window / derived_at`。各来源按更新周期设置 freshness 目标，当前不臆造 SLA。
5. 校验证据原文与哈希、Subject/Source/Canonical/Evidence 引用、时间线、修订与去重、实体别名、关系、量值范围及缺失语义。`0` 只表示来源确实测得为零；未知/未采集/不可用/过期/受限/失败不得相互覆盖。
6. 分别评估运营披露、官方事件、统计基线和消费者/社媒样本的质量、偏差、来源权利与解释力度；媒体转载与转发不视为独立佐证。重大行动前要求对应权威或多来源核验及人类确认。
7. 记录用户是否据此完成核验/案例/行动、行动执行者与 Permission 决定、实际结果、未解决事项及反馈；Evaluation / Learning 只消费经授权且有 Evidence 的结果，不把模型生成文本写回来源事实。

## 现有能力、明确缺口与 15 轮承接

**HEAD 源码快照中可见的既有基础**：`subject_context.py` 有 CTH Subject Context 和 `GLOBAL / ALL` 类型；旧 CTH ProductContext 默认仍指向广州太古汇，存在兼容性/默认化问题。`subject_registry.py` 已有单一 registry 路径和 Subject 类型/名称/行业/关键词/状态等，但当前读取的 HEAD 定义不能满足全球基线所需的完整地区、别名/身份消歧、关系、来源授权及成熟度覆盖证明。`canonical_data.py` 的记录模型保留 source/external ID、source type/platform/URL、capture 与 publication 时间、质量/核验状态、Evidence 引用等数据位置。已有 `event_graph.py`、`case_deep_analysis.py`、`risk_engine.py` 和 CTH API/监测调用方提供可追溯/分析代码落点。目录/函数存在不等于共享 Canonical schema 中唯一事实已闭合，也不证明实时、主体授权、线下运营数据或 E2E。

**来源边界**：公共 HTTP/RSS/Atom/Sitemap/Browser 能力应汇入现有 SYSTEM Collector → Evidence → Canonical owners；Source rights、手动默认、范围与 actor Permission 在采集前验证。对涉及个人信息的消费者反馈，仅使用经合法授权、最小且适用于目的的字段；优先主体级匿名/聚合及投诉主题，避免单人长期画像和跨平台身份拼接。现存应用/账号 Cookie 与个人工作账号不得被视为外采许可。
