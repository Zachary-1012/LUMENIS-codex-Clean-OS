## 二、运行 / 调用流程（系统按此顺序执行）

1. **先读 `catalog.md`**：按任务定位分类与候选仓库 ID（A01…E03）。
2. **再读 `apple-ui-reference-db.json`**：用 ID 取该条的
   - `use_case`（用途，判断是否匹配）
   - `html_url` / `clone_url`（看源码 / 拉源码）
   - `verified_key_paths`（已核实存在的关键文件路径，直接拼 `html_url + /blob/ + path` 阅读）
   - `local_snippet`（若有，先读本地样本，不必联网）。
3. **读 `code-snippets/` 对应样本**：图标几何 / 矢量导出 / 液态玻璃等核心实现已有本地副本。
4. **需要完整源码时**再 `git clone --depth 1 <clone_url>`，不要盲目全量克隆。
5. **落地到本项目**：把规范翻译成 `templates/*.html`、`static/css`、`static/js` 的实际改动（映射见第五节）。
6. 引用任何外部仓库代码时，在提交说明里标注来源仓库与文件路径，License 以各仓库为准。

## 三、★ 提示重点（给 AI 下任务时必须覆盖的要点）

后续让系统/AI 基于本库做 UI 时，**提示词必须写清以下 7 项**，缺项结果就会跑偏：

1. **平台与载体**：说明是「本项目 Web 网页端 / 手机浏览器 / 未来 App」哪一种；本项目是 Web 技术栈，**不是 Swift**，要求把苹果规范翻译成 HTML/CSS/JS，而不是直接给 SwiftUI 代码。
2. **具体界面**：指明作用对象（导航栏、品牌页、笔记列表、短信验证弹窗、cookie 失效二维码弹窗、设置页、Zachary 聊天窗、底部 Tab 等），不要泛泛说"做苹果风"。
3. **引用来源**：要求先读 `db.json` 选定具体记录 ID 与 `verified_key_paths`，输出里注明参考了哪个仓库/哪份 snippet，**禁止凭印象编造苹果规范或仓库**。
4. **图标几何硬指标**（涉及任何图标/头像/圆角卡片时必须带上）：
   - 画布 1024、安全内容区 832（占 81.25%，四周各留 1/16）；
   - 图标圆角为内容边长的 22%（相对整张画布约 17.875%）；
   - 必须是**连续圆角 continuous（squircle）**，不是普通四分之一圆弧，Web 上要显式说明近似方案；
   - 1024 营销图不允许带 alpha 透明通道。
5. **材质与层级**（涉及玻璃/模糊/悬浮控件时）：液态玻璃只用于**悬浮在内容之上的导航/控制层**，列表/正文/媒体内容层不加玻璃；禁止玻璃叠玻璃；多块玻璃必须在同一容器内；对比度 ≥ 4.5:1。
6. **交互与无障碍**：触控目标 ≥ 44×44；支持深色模式；尊重"减弱透明度/减弱动效"；图标用单色可着色矢量，不使用多色位图当系统图标。
7. **合规边界**：SF Symbols 是 Apple 资产，**仅限 Apple 平台按系统 API 使用**；本项目是 Web/跨端，不能把 SF Symbols 字体或导出图标当自有素材直接上线商用——Web 端改用自绘 SVG 或许可宽松的图标库，只把其**造型/栅格/尺寸规范**作为设计参考。

## 五、苹果规范 → 本项目 Web 代码 落地映射（重点）

本项目前端是 Flask 模板 + 原生 CSS/JS，Swift/SwiftUI 样本**不能直接用**，按下表翻译：

| 苹果概念 / API | Web 落地写法 | 备注 |
|---|---|---|
| 连续圆角 `RoundedRectangle(style:.continuous)` | 普通 `border-radius` 只是圆弧；近似用 `border-radius:22%`，精确用 SVG squircle path 或 CSS `paint()` Houdini（参考搜索词 continuous-corner） | 视觉差异在大圆角时最明显 |
| 图标安全区 832/1024 | 图标盒内再嵌一层 `width:81.25%` 的内容层并居中 | 四周留白=1/16 |
| SF Symbols 单色矢量图标 | 内联 SVG，`currentColor` 随文字着色，`stroke-width` 统一 | 不得内嵌 Apple 专有字体 |
| `.ultraThinMaterial` / Liquid Glass | `background: rgba(255,255,255,.6); backdrop-filter: blur(20px) saturate(180%);` + 1px 内描边高光 + 柔和阴影 | 深色模式换深色半透明 |
| `.interactive()` 按压缩放/回弹 | `:active{transform:scale(.96)}` + `transition: transform .2s cubic-bezier(.2,.8,.2,1)` | 尊重 `prefers-reduced-motion` |
| GlassEffectContainer 融合 | 同一父容器统一背景与模糊，相邻玻璃块共用一个伪元素，避免各自模糊叠加 | 防"玻璃叠玻璃" |
| 44×44 触控目标 | 可点元素 `min-width/min-height:44px`（手机端），视觉图标可小于此但热区补足 | HIG 硬指标 |
| 深色模式 | `@media (prefers-color-scheme: dark)` + CSS 变量切换 | 与本项目现有主题变量对接 |
| 减弱透明度/动效 | `@media (prefers-reduced-transparency / reduced-motion)` 降级为纯色/去动画 | 无障碍要求 |
| 可变填充图标（音量/信号 0–1） | SVG `stroke-dasharray` 或双层 SVG 遮罩按比例显示 | 对应 variableValue |

- 根目录另存有整包压缩件 `D:\Taikoo-monitor-new\apple-ui-reference-db.zip`，用于备份/迁移。
- 本库只做**设计参考与代码索引**，不含可直接运行的本项目功能代码；任何 UI 改动仍在 `templates/`、`static/` 内完成并自行回归验证（手机端视口、深色模式、弹窗层级）。
