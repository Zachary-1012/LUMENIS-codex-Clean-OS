# 国家、市场与主体关系导航：有界采用研究

研究日期与访问日期：2026-09-27。状态：`ADAPT / RESEARCH`，不是产品实现、全球覆盖或 UI 设计批准。归属：现有 Canonical Registry / Shared Database / Evidence / Permission，CTH 与 BMP 分别消费；Experience 只决定最终呈现。

## 决定

用户可按 `CTH 或 BMP → 国家 → 商业市场或品牌市场 → 主体` 逐步缩小查找范围；这是从既有 Canonical 实体与关系事实生成的导航视图，不能创建另一套主体或市场真值。主体仍可直接搜索、添加，也可跨多个市场出现。`GLOBAL / ALL` 保持默认，清除聚焦返回全域。

国家选择优先表达**实际经营或服务的市场**；发源地、注册地、法律地址和总部各是独立事实，不能拿一个字段代替另一个。Nike 官方同时列出美国总部与上海大中华区总部，足以证明单一“品牌所属国家”会误导。GLEIF 区分法律地址、总部地址及法律主体关系，可作为公司身份核验的候选参考；LEI 不等于品牌、商场或所有经营市场。[Nike 公司资料](https://about.nike.com/en/company)；[GLEIF Level 1 字段](https://www.gleif.org/en/lei-data/access-and-use-lei-data/level-1-data-lei-cdf-3-1-format)；[GLEIF API](https://www.gleif.org/en/lei-data/gleif-api)。

国家代码使用 ISO 3166-1 alpha-2 的真实代码。英国为 `GB`；“其他国家”只是界面聚合剩余真实国家的视图，不能存成虚构国家。`UNKNOWN`/`NOT_COLLECTED` 应独立显示，不能塞进“其他”。[ISO 3166](https://committee.iso.org/iso-3166-country-codes.html)。

“商业市场”和“品牌市场”是各自业务领域的筛选语义，不是两个新 owner。CTH 可按城市、商圈、商业体/业态和实际运营范围组织；BMP 可按国家、品类、消费者需求和渠道组织。市场成员关系是多对多，需有来源、捕获时间、适用区间、状态及冲突处理，不应靠名称或关键词猜归属。

广州太古汇与场内品牌/业态是 `商业主体 → 场内租户/业态` 的有时效关系。太古地产 2025 年报提供了截至该报告期的租户与新增品牌名单，但不能推出某品牌今天仍在场内，更不能把该品牌的全球帖子全部归为商场监测。CTH 场内信号须再核对地点、活动、门店或对应来源。[太古地产 2025 年报](https://ir.swireproperties.com/en/ir/reports/ar2025.pdf)。

关系脉络建议先展示少量与当前任务直接相关的关系，例如“经营市场”“所属公司”“场内品牌”“竞品”“关联事件”，每条都可打开来源、时间和缺失状态。先做可操作的列表与路径返回；只有真实关系足够密集、用户任务确实需要空间浏览时，才在已批准 Experience 规格内考虑图形。避免全量节点图、固定 PPT 关系模板和未经核实的连线。

## 当前数据缺口与验收

2026-09-27 本地实际产品库只读核对：Registry 有 BMP 101、CTH 6；Registry 尚无国家/市场/关系字段，现有表也没有可用的主体关系表。因此现在不能声称 14 类已经达到每类 BMP 与 CTH 各 50 个。13 个具名国家加“其他国家”共 14 个界面类，验收至少涉及 28 个国家×领域单元、每单元 50 个**有来源的归属**；同一实体可以在多个国家经营，单元计数不是 1,400 个不同主体。

按现有 Round/Owner 收敛：ROUND 03 的 Canonical 身份、关系和 Schema；ROUND 06 的真实 Source/Evidence；ROUND 10–13 的 CTH/BMP 业务消费；ROUND 15 的全球覆盖、随机实体和用户工作验收。每个归属需稳定主体 ID、关系类型、国家代码、市场范围、来源/Evidence、有效时间、缺失与冲突状态。新增主体走既有注册路径，聚焦本身不触发采集或赋权。没有真实数据的国家单元显示 `NOT_COLLECTED` 和覆盖差距，不能用候选名单、样本或预测值凑满。

首批反例验收：Nike 美国品牌与中国经营市场并存；字节跳动品牌/公司及不同国家法律或经营主体不混一；深圳罗湖万象城不混深圳万象天地/深圳湾万象城；广州太古汇的场内品牌有时间与场地 Evidence，且全球品牌内容不自动进入 CTH 场内监测。用户应能从 GLOBAL 经国家与市场找到主体、聚焦、查看结果和来源，再清除聚焦返回 GLOBAL。
