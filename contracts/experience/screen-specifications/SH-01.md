## 1. Product invariant and scope

SH-01 is the Shared Capability catalog consumed by CTH and BMP. It is not a third product, and catalog membership does not establish a CTH Subject or BMP BrandFocus. The App displays safe registered capability metadata from the shared catalog. It does not execute a capability.

The current global content Evidence list and detail routes do not bind the authenticated actor to a product domain or an Evidence object. The App must not call them, expose their records or totals, or attribute them to CTH/BMP. The detail response also forwards arbitrary structured output that could echo a prompt or input. Output remains hidden until object scope and output redaction are verified.

### 10.7 Navigation research and integration boundary

Reviewed 2026-09-29 against installed Flutter 3.47.5 and `go_router` 18.0.1:

- **ADAPT** the existing route owner's pre-navigation callback. The current
  `/workspace/:screenId` route reuses one route for several screens, while Shell
  also changes its selected screen before requesting a URL change. A route-exit
  callback alone therefore does not protect every page change. The installed
  `go_router` `OnEnter` callback exposes current/next route states and explicit
  Allow/Block results; connect it to the same UI leave decision used by Shell,
  without creating a second router or draft store.
- **ADAPT** [Flutter PopScope](https://api.flutter.dev/flutter/widgets/PopScope-class.html)
  only for the navigation gestures it actually controls; it is not evidence that
  browser reload, Shell selection or native close is protected.
- **DEFER acceptance** of app-close protection until its platform path is tested.
  [AppLifecycleListener.onExitRequested](https://api.flutter.dev/flutter/widgets/AppLifecycleListener/onExitRequested.html)
  is called for cancelable exit requests; forced termination is not guaranteed.
  Keep the exact supported behavior visible in the acceptance result.

This adopts APIs from already installed framework/navigation dependencies; no
package, business capability, persistence, Permission or Evidence owner is added.
No new source is promoted by this research note. The pending integration must
also prevent an old scope's cached version details from appearing while the
controller's draft is quarantined, and must revalidate before revealing it again.

### 10.8 Bounded exit-protection decision — 2026-09-30

Use one presentation-only leave decision for the existing editor Back action,
Shell selection, incoming route/history navigation, explicit scope selection and
cancelable application exit. This adapter belongs to the existing Flutter
navigation/Experience owner; it stores no draft, grants no Permission and does
not replace the media controller. Confirm before changing the selected page or
sending the existing context PUT/DELETE. Cancel keeps the URL, scope, material,
selected clip, timeline position and unapplied inspector fields unchanged.
Concurrent leave requests share one pending decision rather than stacking
dialogs. An import/export still in flight must remain visible and must never be
described as canceled by leaving the page.

Unapplied inspector text is unsaved user intent even when the controller's last
exported timeline is unchanged. A failed context refresh must quarantine reads
and effects without disposing that recoverable intent; a successful scope change
must not relabel the old output. Revalidate through the existing controller before
revealing or reusing a quarantined source/version.
