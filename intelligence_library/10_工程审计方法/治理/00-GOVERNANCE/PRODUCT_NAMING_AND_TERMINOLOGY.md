# 序境｜产品命名与术语治理

## Product
- 中文：序境
- 品牌哲学：芥子纳须弥
- 历史研发标识：Zachary（不得作为新的产品展示名）

## Internal product layers
- 序境-Core：生产核心层
- 序境-Intelligence：智能协同层

## Naming rules
1. UI、README、报告、设置页统一使用「序境」。
2. 仓库名保持 Git 历史稳定，不因品牌改名强制重命名。
3. 新模块必须有唯一 Module ID、Page ID、Workflow ID、Data ID。
4. 同一概念不得存在多个正式名称。
5. 旧名称进入 LEGACY，不再产生新引用。

## Comment rules
注释只回答：做什么 / 为什么 / 限制。短、准、可维护；禁止把研发日志写入源码注释。
