# 01 · 生命系统 / 系统科学 / 复杂性 / 涌现 / 自组织

> 知识库条目规范：`**[条目]** 证据等级 / 状态 / 语言文化 / 时间版本 / 来源`
> 本模块为「序境」生命层框架与系统化能力提供科学依据，反哺 Agent 架构、舆情动态分析与内容生态设计。

## 1. 过程本体论作为生命系统的哲学底座

**[过程优先于实体 / Becoming over Being]** E3 / VERIFIED / 英 / 1929– / Whitehead; Rovelli（量子力学关系解读）
- Whitehead：现实由动态过程而非静态实体构成；"actual occasions" 是生成的事件而非静止之物。
- Rovelli（量子力学）："It isn't things that enter into relations but, rather, relations that ground the notion of 'thing.'" —— 在量子世界，不存在无关系的实在；**事件**是基本单位。
- 与序境：系统状态不是"快照对象"而是"事件流"，为动态可视化、时间轴、增量更新提供本体论依据（状态=关系在时间中的显现）。

## 2. 生命系统核心概念

**[Living System]** E2 / VERIFIED / 英 / 通用 / 系统科学文献
- 定义：通过与环境的持续物质/能量/信息交换保持自身结构、并具备自组织与演化的系统（参考 Maturana & Varela 自创生 autopoiesis 传统）。
- 关键：**结构与环境的耦合产生意义与行为**；稳定来自模式的重建而非静态不变。

**[Autopoiesis / 自创生]** E2 / VERIFIED / 英/西 / 1972– / Maturana & Varela
- 生命系统自我生产、自我维持自身组织；边界在过程中生成而非预先给定。
- 与序境：双子库的"边界稳定但内部演化"、系统的自我修复/自动恢复理念可与此对齐（CONCEPT 层映射）。

## 3. 复杂性 / 涌现 / 自组织

**[Emergence / 涌现]** E2 / VERIFIED / 英 / 通用 / 复杂性科学（Mitchell; Holland 等）
- 整体行为不可还原为局部分量之和；涌现来自组分间局部交互的宏观规律。
- 与「芥子纳须弥」严格同构：**局部关系产生整体性质**。是命名语义空间（Emergence）与系统能力（Agent 群体、舆情全网）的科学锚点。
- 注意占用：`Emergence` 已被现实 AI/软件生态显著占用（见 05 命名文件），仅作方法论语义。

**[Self-organization / 自组织]** E2 / VERIFIED / 英 / 通用 / 热力学/复杂系统
- 系统内部相互作用自发形成有序结构，无需外部指令（耗散结构、贝纳德对流等）。
- 与序境：**自组织 ≠ 无纪律**——序境规则是"自组织的边界条件"，系统在边界内自发演化（对应零号序列"演化但不越权"）。

**[Complexity / 复杂性]** E2 / VERIFIED / 英 / 通用 / 系统科学
- 高连通、非线性的系统行为；小扰动可被放大（蝴蝶效应），长程相关，不可简单分解。
