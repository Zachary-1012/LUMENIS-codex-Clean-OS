# K｜P0/P1/P2 Roadmap

> 交付物 K · 所属：OSAI P0 三位一体研究体系 · ① AI Frontier Research

## P0（立即做，Q4 2026）

| 项目 | 目标 | 交付物 | 依赖 | 成功标准 |
|------|------|--------|------|---------|
| **Identity & Evidence Foundation** | 建立身份管理和全链路证据收集 | Identity Provider、Evidence Collector、Audit Trail | 无 | 所有操作可追溯，证据不可篡改 |
| **Memory Layer** | 分层记忆存储和检索 | Working/Episodic/Semantic/Procedural Store、Vector Retriever | Identity | 记忆检索准确率 ≥80% |
| **Experience Engine（核心）** | 强改变经验学习机制 | Experience DNA Store、Reflection Agent、Rule Engine、Reliability Scorer、六层防御（1-3层） | Memory | 规则命中率 ≥60%，行为改变率 ≥40%，投毒检测召回 ≥95% |
| **Research Layer** | 系统化研究流程 | Search Orchestrator、Evidence Collector、Research Pipeline | Identity | 研究产出包含 Evidence 覆盖率 ≥90% |
| **Permission & Safety OS** | 任务绑定权限和沙箱 | Permission Ticket System、E2B Sandbox 集成、Policy Engine | Identity | 任务结束权限 100% 撤销，无越权操作 |
| **Research-to-Code（集成）** | 七层管道+Coding Agent 集成 | Contract Generator、Trae/Claude Code Connector、MCP Server | Research、Permission | Contract 生成准确率 ≥85%，执行成功率 ≥70% |
| **Evaluation Matrix** | 12 维评估体系 | Evaluation Engine、Benchmark Integrator、Regression Detector | Evidence | 12 维度全部可测量，Safety 硬门槛生效 |
| **Tools Layer** | 工具注册和 MCP 集成 | Tool Registry、MCP Server/Client | Identity | OSAI 能力可通过 MCP 被外部调用 |

## P1（6-12 个月，Q1-Q2 2027）

| 项目 | 目标 |
|------|------|
| **Planning Layer** | 长程规划、Checkpoint/Restore、动态调整 |
| **AI Browser Research Framework** | BrowserGym+Browser Run 集成、Hybrid 感知、Persistent Browser 研究 |
| **Proactivity Layer** | 五阶段 Interruption Policy、Insight Engine、通知分级 |
| **Human Collaboration** | Mixed-Initiative、可调自主性、建设性分歧 |
| **Experience Engine 增强** | 温/冷存储分层、投毒检测自动化（第五层）、贝叶斯动态更新 |
| **Skeptic/Red-Team Engine** | 3 Agent 辩论、红队测试、Constitutional AI 适配 |

## P2（12-24 个月，2028）

| 项目 | 目标 |
|------|------|
| **World Model / Cognitive Map** | Entity+Temporal+Causal 三层融合图谱 |
| **Autonomous Experiment Lab** | 假设生成→实验设计→沙箱执行→结果比较 |
| **Experience Engine 成熟** | 跨项目经验共享、自动经验压缩、认知闭环 |
| **Proactivity 成熟** | 用户偏好自适应学习、高价值洞察自动生成 |

## 暂缓（2029+）
- 完全自主的多 Agent 协作系统
- 通用世界模型（AGI 级）
- 自建 Coding Agent（持续评估集成方案是否足够）

- 用"AI 判断"替代确定性业务规则
