# Source Owner / Reuse
Read LUMENIS-SOURCE-OWNER-INDEX-CURRENT.md and dependency-trace existing owner/callers/contracts/tests. Prefer reuse -> adapt -> bind -> verify. A missing adapter or UI binding never justifies a second platform or truth owner. If current authority is contradictory, fail closed and reconcile it before adding implementation.
