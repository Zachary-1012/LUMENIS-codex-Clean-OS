本目录 `continuity.py` 为 Codex 的 `SessionStart`（含 compact）及每轮 `UserPromptSubmit` 提供短上下文指针，同时要求在适用工程工作中实际应用仓内 pstack 方法。它不复制私有原文、不读取会话凭据、不运行测试、不阻断 Stop、不调度 Agent、不写产品数据。用户级注册仅针对本机新根及旧历史根生效，其他项目无输出。按 Codex 原生 `/hooks` 审阅和信任确切定义；文件已配置与真实事件已触发分别核实，不能手填信任哈希或绕过审核。

本机启动入口保存在用户 Codex `bin`，显式进入新根并沿用用户当前配置；不得再硬编码模型、推理强度、切换供应方或结束其他会话。钩子、入口和配置的维护验证属于开发环境准备，不是产品能力验收。
