    小程序采集说明

    微信小程序数据相对封闭，无公开搜索入口。本系统采用 Shadow 模式：用户主动截图小程序数据页面 → 系统 OCR 识别字段 → 人工确认后入库。不碰小程序自动化、不逆向 API、不抓包，完全合规。

    适用场景：小程序活动页访问量、会员数据、优惠券领取量、门店预约数等 Web 端无法获取的指标。
