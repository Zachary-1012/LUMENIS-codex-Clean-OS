## 三、逐模块真实成色（不夸大，按源码+实测）

### 1. 认证体系 auth/ —— 账密/三级权限/安全问答 可用
- 已实测：Zachary 主账号登录、PBKDF2 校验、token 7天、5 次失败锁 15 分钟、owner/admin/user 权限隔离（admin 越权 owner 接口 403）、安全两题（手机号 18504635216 / 生日 1012）全对才放行、错误答案拒绝且不建号、登出 token 失效。
- **未实现/缺口**：
  - 你要求的"**账号密码 + 手机验证码滑动切换**"——目前只有账密，**手机验证码登录未做**（短信通道也需要第三方服务）。
  - v4 自带的是独立 token 体系，现网是 HTTP Basic。**正式接入需要一座"登录桥"**：用户从现网点进 `/v4/settings/` 时要能自动带上凭证，否则会 401（这是接入前必须补的第 1 件事）。

### 2. 苹果风设置页 settings/ —— 框架与主流程可用，两处占位
- 已实测可用：苹果风分组（账号管理/系统设置/关于）、账号列表、添加账号（带安全问答）、启停/改密、操作审计日志（时间/用户/动作/IP 齐全）、错误原密码改密被拒。
- 占位/未完成（点击只弹"开发中"toast）：**系统参数、模块管理**。
- 安全验证问题入口目前只弹出现有两题，**没有增删问题的 UI**（后端接口在）。
- 响应式：代码含 @media(max-width:480)、容器 max-width、弹窗 90% 宽；本环境浏览器无法模拟 390px 视口（CDP 通道限制），**真机 390 显示需你肉眼复核一次**。

### 3. 外部数据导入 importer/ —— 修复后可用
- parser 扎实：PDF(pdfplumber/PyPDF2 双回退)、Word(python-docx)、Excel(openpyxl/pandas)、CSV、TXT，连表格一起解析。
- analyzer：AI 不可用时规则回退（情感词表+高频词），**脱离 AI 能跑**（符合"AI 撤出核心仍运行"）；规则较粗，"问题"这类词会算负面，后续可细化。
