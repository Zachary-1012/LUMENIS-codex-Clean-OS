# AI_WEB_GITHUB_BROWSER.md

## 定位

本项目支持“内置 AI + Web/GitHub 研究 + 本地执行验证”的研发辅助能力，但这些能力属于研发增强层，不得成为生产舆情监测核心链路的单点依赖。

## 组成

- Web Research：用于查阅公开技术文档、开源项目、平台公开规则和工程资料。
- GitHub Research：用于研究公开仓库的架构、测试、适配器、浏览器自动化和数据工程实践。
- Built-in Browser：用于真实页面观察、E2E 验证、前端交互检查和合法登录状态验证。
- Local Execution：由本地开发环境执行代码、测试、数据库检查和浏览器验证。
- Ollama：本地 AI 推理和辅助分析。

## 研究纪律

研究结果必须区分：源码事实、公开资料、实验结果、模型推断。不得把研究结论直接当作生产事实。

## 爬虫/反爬研究边界

可以研究：请求生命周期、限流、重试、缓存、浏览器自动化稳定性、数据质量、robots/公开 API、会话生命周期、风控状态识别、熔断和恢复设计。

不得以破解验证码、绕过安全验证、规避平台访问控制或逃避封禁为研发目标。生产系统遇到平台风控应停止危险请求、记录状态、冷却并等待合法恢复。

## GitHub 同步原则

重要架构决策、状态快照、开发日志、测试矩阵、数据库模型和发布规则应进入 GitHub；密钥、Cookie、Token、真实账号凭证和敏感生产数据禁止提交。
