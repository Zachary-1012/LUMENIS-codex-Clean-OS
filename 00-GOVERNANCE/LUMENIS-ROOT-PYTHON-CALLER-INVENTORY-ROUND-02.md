## Method

1. Read the required CURRENT governance files and rendered only `tmp/pdfs/round02/page-015.png`.
2. Parsed every tracked Python file with Python AST; for each root module collected top-level classes/functions, Flask-style decorated routes, blueprint registration calls, `__main__`, and exact import edges.
3. Direct callers are tracked Python files whose AST imports the exact root module. Related tests add exact import/string-module references under `tests/` or `test_*.py`. `none found` does not exclude dynamic import, command-line, workflow, plugin, or external invocation.
4. A non-root canonical owner is assigned only where CURRENT governance names that convergence edge or the source is a direct compatibility facade. Importing Database/Evidence/Permission does not automatically transfer a business module's primary ownership; such dependencies remain secondary edges.
5. A self path means the current executable root file remains the only proved owner for this inventory. `UNKNOWN` means evidence was insufficient; it is never a retirement candidate.
6. “Parity surface” lists observable contract-bearing definitions/routes/entrypoints. It is a migration preservation set, not proof that behavior is globally unique or duplicated.
