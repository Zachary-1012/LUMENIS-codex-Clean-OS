# v5.2 — 舆情雷达 / 事件优先 UI

## 核心变化
- 产品名从“舆情情报中心”调整为“太古汇 · 舆情雷达”。
- 首页从“指标大盘”改为“事件优先”：今天态势 → 事件流 → 需要关注 → 14天趋势 → 情感/主题/公开互联网。
- 把笔记库、全网发现、历史复核、报告收进“情报工作台”，避免首页平铺所有逻辑层级。
- 事件卡增加：待核实 / 多来源 / 持续升温 / 已核实状态提示。
- 风险卡只保留必要信息；点击进入右侧抽屉查看完整研判上下文。
- 工具提示支持桌面悬停和移动端点击。
- 新增 `/api/overview`，提供14天信号趋势、活跃事件数、近14天负面信号数。
- 事件列表排序改为优先活跃、多来源、近期事件，再考虑风险分和提及量。
- 保留 v5.1 的本地 AI、全网公开发现、小红书反哺、历史复核、翻译与5G访问能力。

## 设计依据
参考 Apple Human Interface Guidelines 的视觉层级、渐进披露、简洁、明确反馈与上下文帮助原则；没有照搬品牌视觉，而是将这些交互原则应用到舆情监测场景。
- 事件聚合升级：事件键加入“语义信号 + 14天时间窗”，避免把长期存在的“服务投诉”等主题错误合并成一个无限期事件；同时保留风险与来源信息用于排序。
