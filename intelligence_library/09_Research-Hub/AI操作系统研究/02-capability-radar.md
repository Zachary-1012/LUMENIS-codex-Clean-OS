# B｜OSAI Capability Radar

> 交付物 B · 所属：OSAI P0 三位一体研究体系 · ① AI Frontier Research

| 能力 | Current OSAI | Industry Best | Gap | Priority |
|------|-------------|---------------|-----|----------|
| **Memory** | 2/10（基本对话历史） | 8/10（MemGPT/Letta 分层记忆+Generative Agents 记忆流） | 缺少分层记忆、反思检索、经验结构化 | **P0** |
| **Experience** | 1/10（无经验学习） | 5/10（Reflexion 弱改变，无强改变实现） | 核心差异化机会，行业尚无强改变实现 | **P0** |
| **Research** | 3/10（可搜索但无系统化研究流程） | 7/10（Perplexity/NotebookLM 持续研究） | 缺少 Research→Evidence→Decision 流水线 | **P0** |
| **Planning** | 2/10（简单任务分解） | 7/10（Devin/MetaGPT 多步规划+回滚） | 缺少长程规划、Checkpoint/Restore、动态调整 | P1 |
| **Browser** | 1/10（无浏览器能力） | 8/10（OpenAI Operator Browsing Camp 50%+） | 完全空白，应集成而非自建 | P1 |
| **Coding** | 2/10（可生成代码片段） | 9/10（Claude Code SWE-bench 88.6%） | 不应自建，集成 Trae/Claude Code | P0（集成） |
| **Proactivity** | 1/10（纯被动响应） | 5/10（Apple Priority Notifications 单阶段过滤） | 缺少五阶段 Interruption Policy，行业尚不成熟 | P1 |
| **World Model** | 1/10（无认知图谱） | 4/10（GraphRAG/LightRAG 实体图谱，无时序/因果） | 缺少 Entity+Temporal+Causal 三层融合 | P2 |
| **Evaluation** | 1/10（无评估体系） | 6/10（SWE-bench/GAIA 等单维度 Benchmark） | 缺少多维度评估矩阵，Safety 硬门槛 | **P0** |
| **Safety** | 2/10（基本权限控制） | 6/10（E2B 沙箱+Anthropic 权限系统） | 缺少 Task-bound Permission、Memory Poisoning 防御 | **P0** |
| **Human Collaboration** | 3/10（基本对话交互） | 7/10（GitHub Copilot 协作模式+Shared Autonomy 研究） | 缺少 Mixed-Initiative、可调自主性、建设性分歧 | P1 |
| **Self-Improvement** | 1/10（无自我改进） | 4/10（Self-Refine 单轮改进，无持续进化） | 与 Experience Engine 协同，核心差异化 | **P0** |

**评分依据**：Current OSAI 基于当前系统能力评估；Industry Best 引用 66 个案例中的最佳实践；Gap 分析基于研究报告中的技术对比。
