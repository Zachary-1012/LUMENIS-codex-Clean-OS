# 序境交互审核工作副本

这是从私有站 v12 恢复源码后继续修复的独立审核包。当前为44个可操作示例入口（原01–39及69，加新实现70–73；40–68尚未恢复），不是完整200+需求验收，也不是正式产品前端。每例保留人工样例/预生成素材/真实本地计算/后端未绑定的边界。

## 正确入口
- `index.html` + `src/` + `assets/`：当前模块化源码入口。
- `offline.html`：由当前源码新生成、资源已内嵌的离线审阅文件。实际浏览器运行/视觉验证仍待完成；本次云浏览器不允许file协议，而隔离localhost服务未能跨调用访问。
- `historical/offline-v12-recovered.html`：仅保留恢复原件，不包含本轮修复，不要当最新版使用。
- `viewport.html`：当前index入口的窄屏iframe检查辅助，不是已经通过的手机证明。

## 本地运行与回归

本次实际测试环境为 Node v24.19.0、Python 3.12.14；更低版本兼容尚未验证。本包没有运行时npm依赖。

```sh
python3 tools/build_offline.py
node --test tests/*.test.mjs
node --check evidence/offline-bundle.js
python3 -m http.server 8766 --bind 127.0.0.1
```

在同一台可访问该服务的电脑浏览器打开 `http://127.0.0.1:8766/`。不要为连接失败关闭浏览器安全、开放公网或修改产品服务。`package.json` 的 test/start 也提供相同入口。

构建脚本仅支持本包明确使用的静态具名导入/导出；遇到未知语法、缺导出、循环、外部模块会停止，不猜测转换。构建后测试校验每一源模块的SHA、原生ESM导出列表、隔离作用域初始化及最终HTML hash。修改源码后须重新构建并回归，不能拿旧offline当新实现。
