# 品牌营销知识库·第五期：高奢/重奢/小众调性特别篇 + 方案撰写脉络 · 2026-09-03

> 承接第四期（全球4A对标）。本期聚焦高奢/重奢/小众高调性品牌的底层逻辑，
> 并给出「借鉴 ZBC 产品分层架构」的方案撰写模板脉络。
> 来源：新浪财经/Paris of France/Fashion China Agency/BrandClickX 等公开研究。

## 一、高奢品牌的底层逻辑（稀缺即资产）

| 品牌 | 核心打法 | 一句话逻辑 |
|---|---|---|
| Hermès | 计算型稀缺：供<求、不增加产能、不做促销广告、工艺即产品、分销即品牌资产 | 欲望永远大于可得（desire > availability） |
| Chanel | iconography：CC 符号人人认识、多价位可及 | 用符号建立最大公约数认知 |
| Goyard | 全球仅约 30 店、不广告/不代言/不开线上/官网不标价 | 反互联网克制，稀缺感即传播 |
| Brunello Cucinelli | 不请代言、不搞大活动、"害怕太出名"，维系小圈层信任 | 信任感 > 大众认同 |
| Ffern（英国香水） | 一年只卖 4 款、账本会员制限量、常年排队、节气仪式感、不打折不铺货 | 限量+仪式=身份认同与期待情绪 |
| Aesop | 不做大众流行追随者，做小众审美定义者：实验室棕瓶+文学艺术 | 品牌体系=竞争壁垒，视觉即符号 |
| 观夏/闻献/宋朝/野兽派 | 中国香氛"反流量"四强：东方叙事/顶级稀缺/普惠人文/生活方式 | 反流量破局：不追热点、不造焦虑 |

**高奢/重奢/小众共通规律**：
1. **涨价=筛选客群**：Chanel Classic Flap 2021-2026 涨超 80% 仍排长队——价格门槛是营销手段，筛选比讨好重要。
2. **quiet luxury（安静奢华）**：Gen Z/千禧更认可持续、真实性、去 logo 的安静奢华，而非夸张 logo。
3. **克制即营销**：不广告/不代言/不追热点/不做大活动——反其道而行的稀缺感反而产生传播。
4. **工艺与故事=产品**：craftsmanship storytelling 让"产品"变成"人与人、人与匠人的关系"。
5. **渠道即媒介**：选址与一线奢侈品牌为邻（闻献 SKP-S）、门店体验=品牌资产。
6. **时间感**：季度/节气/传世（Ffern 四季、观夏节气）对抗快节奏流量——仪式感产生期待。

## 二、调性坐标（创意引擎 TONALITIES）
- **mass 大众**：狂欢放大、参与机制、玩梗破圈（王老吉x哈兰德、Lay's 玩梗）
- **premium 中高端**：场景种草、质感叙事、圈层认同（Aesop/野兽派）
- **luxury 高奢**：克制叙事、稀缺仪式、工艺故事、**不参与流量狂欢**（Hermès/Goyard/Brunello）

高奢品牌做营销 ≠ 不做传播，而是：把传播本身做成稀缺体验（邀请制、限量、私享、不公开）。

## 三、方案撰写模板脉络（借鉴 ZBC 产品分层架构）
> ZBC 架构：数据层 → 能力层 → 接口层(Contract) → 展示层 → 质量层 → 证据层。
> 方案按同一分层逻辑组织，保证"每个结论都有数据/证据支撑"，可直接比稿。

| 章节 | ZBC 层 | 内容要求 |
|---|---|---|
| 01 背景与市场 | 数据层 | 市场/消费者/竞品/自身真实数据（决策信息优先，不堆文字） |
| 02 洞察与策略 | 能力层 | 数据信号升维成一句话策略主张 |
| 03 创意构想 | 能力层 | Big Idea + 机制（事件化/参与式/符号化/共创/反差/文化共识） |
| 04 传播与触点 | 接口层 | 渠道组合 × 每触点 Contract（内容/互动/转化） |
| 05 执行落地 | 展示层 | 节奏/物料/分工/预算 |
| 06 效果与度量 | 展示层 | KPI/ROI/数据看板（曝光/互动/转化/心智） |
| 07 风险与合规 | 质量层 | 舆情/平台规则/合规 Gate + 应急 |
| 08 证据与附录 | 证据层 | 数据来源/竞品参考/引用（可追溯） |

## 四、数据→拆解→创意链路（pitch_parser + idea_generator）
- `scripts/pitch_parser.py`：方案需求文本/文件(txt/md/json/csv) → 要素提取(品牌/品类/预算/圈层/调性/渠道/目标) + 对标拆解(该品类全球标杆+Gap问题) + 创意建议 + 8章方案脉络
- `scripts/idea_generator.py`：数据信号(主题词/情绪/风险/圈层/热点) × 调性(mass/premium/luxury) × 机制 → 原创创意
- 高奢圈层「高奢小众」符号：限量/稀缺/手作/仪式感/私密；luxury 调性自动切「克制不追热点」叙事
- API：`POST /api/creative/ideas`（创意卡）、`POST /api/creative/pitch-analyze`（拆解，支持文件上传）
