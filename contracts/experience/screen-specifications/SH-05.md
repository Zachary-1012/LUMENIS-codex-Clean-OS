## 1. Product invariant and scope

SH-05 presents versioned learning assets and their evaluation/promotion history. An asset is derivative input, not Canonical Truth, Permission truth or Evidence truth. A displayed candidate, verified version, rejected version or rollback marker never changes a business record by itself.

The current learning history builder returns a global legacy shape without actor-bound scope. The App accepts only typed versioned assets after exact scope and read authorization pass; fixture JSON is not a runtime fallback.

## 2. Binding and response contract

| UI region | Required runtime value | App behavior |
| --- | --- | --- |
| Asset range | `GLOBAL_ALL` or exact `FOCUS` range with safe display name and read authorization | Show business range; hide raw focus id |
| Asset shelf | `data.assets[]` with id, title, version, a known promotion status, `scope_verified` and an explicit Evidence-backed marker | Show safe title, version and status; keep id internal |
| Promotion history | Status from the versioned learning contract: observed, candidate, domain-verified, transfer-candidate, core-verified, rejected, repaired or retired | Preserve the state; do not infer promotion from display or one successful run |
| Review/rollback | Review state, provenance, and explicit rollback availability | Show whether a rollback version is confirmed; require human confirmation for any change |
| Existing route | `GET /api/experience/screen/SH-05` | Current global history response is blocked; no global asset list is rendered |

Every visible asset must carry a version. Unknown promotion state is rejected rather than treated as verified. Every asset also needs canonical row scope, row read permission, Evidence-backed marker, and verified lineage/integrity. A `GLOBAL_ALL` envelope rejects an asset explicitly scoped to a focus; an exact FOCUS envelope accepts only the matching active focus. Unsafe descriptions, paths, provider labels, internal ids and raw diagnostics are not shown.

## 3. Responsive information architecture

### Desktop (available width ≥1120 logical px)

- Header and verified range lead into a shelf with separate all/verified/candidate/retired filters.
- Versioned asset tiles occupy the primary region.
- A version record inspector shows promotion, review, provenance and rollback facts.

### Intermediate width (760–1119 logical px)

- Keep the shelf first and stack the selected version record below it.
- Filter chips remain individually operable and readable.

### Mobile (available width <760 logical px)

- Recompose into range → shelves → selected version record → governance note.
- Selection/filtering is local and read-only; no automatic promotion entry is exposed.

## 4. State and recovery

| State | Meaning | Behavior |
| --- | --- | --- |
| Loading | Asset response is pending | Live status; no stale assets |
| Ready | Scope, read authorization and versioned assets are verified | Render shelves and selected record |
| Empty | Verified response has no usable assets | Explain that the shelf is empty; do not fabricate examples |
| Scope unavailable/denied | Range or read authorization is absent | “学习资产暂不显示”; no assets or identifiers |
| Authentication/offline/invalid | Core recovery or response problem | Safe retry; raw diagnostics hidden |
| Candidate/rejected/retired | Real lifecycle states | Preserve labels and do not color them as success |

## 5. Actions and effects

| Action | Effect | Availability |
| --- | --- | --- |
| Filter shelf | Local view change | Enabled in Ready |
| Select version | Local inspector selection | Enabled in Ready |
| Promote, repair, retire or rollback | Versioned learning effect requiring evaluation, approval, audit and rollback | No active control on this read-only screen |
| Rewrite Canonical data or Evidence | Forbidden cross-owner mutation | Never issued |

## 6. Accessibility and localization

- Version, lifecycle state, review state and rollback availability are readable without color.
- The no-automatic-promotion note is exposed as ordinary accessible text.
- The title uses existing `screen.SH-05` keys in zh-CN, en and ko.
- Asset content is inert text; no HTML, path, provider or internal diagnostics render.

## 8. Review decision

The App slice is implemented as a scope-guarded, read-only version shelf. It preserves explicit promotion and rollback states and cannot autonomously rewrite business truth. The current backend does not yet provide the required scoped learning envelope, so live acceptance remains blocked.
