# LUMENIS Experience Design Language v2.4 — Codex Execution Delta

> Scope: presentation/interaction execution only. It never overrides Production Truth, permissions, data or runtime evidence.

## Identity

LUMENIS must remain recognizable with the logo hidden. Use black-silver / white-silver metallic monochrome, editorial serif display + restrained sans body, `Lumen Axis / 序轴`, `Strata / 境层`, de-boxed hierarchy, hairline structure and semantic motion. Icy Cyan is reserved for truthful data/state semantics. Avoid purple/indigo generic SaaS chrome when inconsistent with this language.

## Anti-template gate

Fail a screen when it reads primarily as a generic dashboard, card wall, component-library demo, AI template or copied external product. Do not solve this by adding decoration. Solve it through composition, hierarchy, typography, spatial rhythm, state behavior, evidence relationship and restrained material/motion.

## Logic is not presentation

Do not visualize internal production chains on ordinary pages. `Evidence → Canonical → Metric`, `Event → Case → Insight → Decision → Action`, Agent/Permission/Effect-Fence chains, Collector/Runtime orchestration and MCP internals are implementation logic. The user-facing surface shows resulting context, evidence, state, relationship, decision support and actions — not a permanent diagram of how the system works.

AI conversation is the controlled exception: it may show citations, evidence sources, retrieval/tool/action progress, approval state, artifact provenance and user-visible execution status. It must never expose hidden chain-of-thought, system/developer prompts, secrets, raw credentials or security internals.

## Calibration gate

`AI-01 + CTH-01` are the first calibration slice. Bind real Production Truth and refine visual language together. Do not propagate to remaining screens until Mask Logo Test, anti-template review, responsive/accessibility checks and Critical E2E pass.

Older Experience Authority remains authoritative for product structure, interaction principles, Production Truth boundary, responsive/accessibility expectations and clean-room constraints. v2.4 is the newer, more specific visual execution delta; where older generic visual suggestions conflict, v2.4 wins without weakening accessibility, truth or functionality.
