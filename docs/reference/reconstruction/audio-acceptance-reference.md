## 3. 材料、统计与通过线如何设

1. **冻结试验对象再看候选结果。** 记录引擎/模型与许可版本、硬件/驱动、输入及导出配置、随机种子、测试集版本、划分、文本归一化和评分脚本；人工转写和客户可交付参考由独立人员校对。hash只负责确认对象一致，不负责音质。公开结果与领域留出集分报，调参集不能再算独立测试。
2. **素材按真实损失分层。** 中英韩各自覆盖：安静单人、自然口语、多人口音、重叠与切换、背景音乐/噪声、专名数字、短关键片段、整集长录音。公开基准以其固定测试集为复现单位；私有集提前定抽样方案、话者/设备/节目来源和数量。单个说话人的大量切片不能冒充很多独立说话人。
3. **量测器先校验，再测节目。** 后续实施应取得 A2 同版测试包，读取其逐项预期值和允许误差，运行适用样例并与独立参考测量器比对；本次未运行，不能现在给合规PASS。重采样、mono/dual-mono、静音及门限边界须覆盖。实际母带与最终编码解码均量测，报告异常/不可计算而非把它转成零。
4. **主观测试有不同人群。** 质量感受可用受筛选且具目标语言能力的听众；细微伪影由具训练的工程/制作人员另审。匿名随机的候选/参考比较，固定播放条件，完整聆听；排除规则预先规定，保留剔除数/理由。不能把模型自评分、开发者自己知道A/B的随手听或几张波形截图当独立专业听审。
5. **样本量由精度/效应需求决定。** 先用不进入最终检验的pilot估计方差，明确业务可感知的最小差异、可接受退化边界与检验功效，再确定话者、片段和听众数。A4对ACR列出每刺激至少8人、每条件96票；它不是所有测试的充分样本数，更不能套给长播客、TTS或三维降噪。A5说严格控制条件下约20名评估者往往能满足某些实验，也不是“20人必通过”。
6. **不要拿均值或“不显著”宣布专业。** 报告各语种/关键条件的误差、有效样本/听众数、置信区间、异常分布和效应大小。按说话人/节目/听众的重复结构做配对或层级分析，避免把同人的数百票当独立样本。比较多个设置时提前处理多重比较；未观察到显著差异不证明等效。
7. **采用可审核的判定式。** 对越低越好的错误指标，令D=候选−基线；事先确定退化边界δ，只有D的预定置信上界小于δ才支持非劣。越高越好的人工评分以置信下界大于−δ判断非劣；声称提升还须越过预先定义的实用改善量。δ来自试验前的任务损失、专家/客户可感知差异与pilot，不能看到候选结果后调整。各语种及关键条件分别满足；CI过宽或样本不足是证据不足，不是通过。若没有已确认基线，则先由独立专业交付定义参考和绝对合格线，不用候选自己定义门槛。
8. **硬故障和专业质量并联。** 关键语义/保全/丢轨/错误导出等硬故障直接阻断相应能力交付，即使MOS更高。目的地格式/响度失败同样阻断该交付配置；它不否定独立已完成的其他功能。所有“行业前沿”主张须有同材料、同条件、当期可复现公开基准及真实专业工作比较，当前没有运行证据，不作该主张。

以上统计方案是可审查的设计建议；不是声称本次做了试验，也不是一次性拍定所有语种同一个CER/MOS阈值。正式执行前应把选定任务的数值边界、样本量、主要指标和失败规则写入对应能力合同，之后不得为了通过而改线。
