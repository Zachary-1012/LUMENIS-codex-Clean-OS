# Zachary AI ↔ ZBC Bidirectional Learning Contract

Zachary AI remains an independent complete AI/product. Before independent commercialization, ZBC is its first cultivation and real-use environment.

ZBC → Zachary: approved ZBC data, cases, domain evidence, system knowledge and real-use results cultivate Zachary's ZBC-domain capability.

Zachary → ZBC: useful validated discoveries, research, capabilities, reasoning improvements, UX/product improvements and engineering improvements may return to ZBC through Evidence → Evaluation → Contract → Governance → Promotion.

Zachary must never directly rewrite ZBC authoritative rules or production data merely because it learned something. Feedback is proposed, evidenced, evaluated and governed before promotion.

Zachary continuously learns outside ZBC. ZBC-domain learning remains restricted to ZBC-related system, business, data, evidence and cases. General learning may generate candidates for ZBC, but applicability must be explicitly evidenced and governed.

```text
ZBC Data → Zachary Context
Zachary Research → Candidate Evidence
Candidate Evidence → Evaluation → Contract → Governance → ZBC Promotion
```

No uncontrolled bidirectional writes, silent rule mutation, or deletion of historical evidence. ZBC and Zachary remain independent, while useful validated capabilities are shared through explicit contracts and governance.

**ZBC养育Zachary；Zachary反哺ZBC。两者独立、双向学习、受控共享、不可互相污染。**

This is an additive supplement to the existing Zachary AI consolidation baseline.
