# 序境 Xujing · UI/UX 权威设计标准 v2.0

> 基于 11 个参考素材（8 视频 + 3 图片）逐帧分析提取
> 基线：iOS HIG + iPod Metal + 6 大域 IA + 序境品牌哲学
> 状态：P0 权威设计标准，所有 UI 实现必须遵循

## 一、设计哲学

### 1.1 品牌哲学
- **芥子纳须弥**：小中见大，极简中蕴含完整功能
- **黑白米灰侘寂**：克制、留白、质感
- **微光银**：iPod 银色金属质感，微风浮过海面

### 1.2 iOS 设计三原则
- **清晰（Clarity）**：文字清晰可辨，图标精准，装饰从属功能
- **遵从（Deference）**：界面辅助理解内容，不与内容竞争
- **深度（Depth）**：视觉层级和动效传达层次，增强理解

### 1.3 操作优先
- 最短安全路径到下一个有意义的动作
- 渐进式披露：概览优先，详情按需
- 无静默上下文丢失

## 六、动效系统

### 6.1 动效曲线
- iOS Spring：cubic-bezier(.22, 1, .36, 1)
- 标准：cubic-bezier(.4, 0, .2, 1)

### 6.2 动效时长
- 微交互：140ms
- 组件转场：220ms
- 工作区转场：320ms
- 复杂可视化：440ms

### 6.3 动效类型
- Stagger 级联：子元素逐个延迟进入
- In-Pop 冲入：scale .85→1.03→1
- Float 漂移：translateY 0→-4→0（4s 循环）
- 数字滚动：easeOutCubic 800ms
- 路径绘制：stroke-dashoffset 1.2s
- 微光扫描：background-position 位移 7-9s
- 弹窗弹性：scale .92→1.03→1 + fade

### 6.4 动效原则
- 动效解释变化、层级、状态、因果
- 不为动画而动画
- 尊重 prefers-reduced-motion

## 七、响应式策略

### 7.1 断点
- ≥1200px：三栏（侧栏 260 + 内容 + 右栏 320）
- 1024-1199px：三栏（右栏收窄 280）
- 768-1023px：两栏（侧栏 240 + 内容，右栏隐藏）
- ≤767px：单栏（侧栏抽屉，底部 Tab Bar）

### 7.2 网页/手机共用
- 同一网址，自适应不同设备
- 手机端：底部 Tab Bar + 抽屉侧栏 + 全屏聊天
- 桌面端：三栏布局 + 固定侧栏

### 7.3 底部 Tab Bar（手机端）
- 毛玻璃背景
- 图标 + 文字
- 选中态：systemBlue
- 5 个 Tab 以内
