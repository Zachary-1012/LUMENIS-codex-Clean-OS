> 对象：ZBIP 生产主页截图 ui-review-home-20260903.png

## 视觉模型结论（原样）

### overall
界面整体简洁但视觉层次与交互细节不足，核心功能突出但辅助信息与状态反馈缺失，需强化信息架构与用户引导

### issues
1. **顶部导航栏图标风格不统一**：搜索实心圆+线条、通知空心铃铛混用 → 统一线性图标（线条勾勒），保持尺寸/粗细/颜色一致
2. **底部快捷操作按钮缺乏视觉区分度**：白底灰字无 hover/active → 核心功能品牌色背景+白字，次要保持灰，加 hover（背景微亮/图标加深）
3. **右下角"需处理1"通知缺乏状态明确性**：仅红色数字 → 加图标或 hover 提示，强化状态语义

### design_checks
- mono_tone: 达标（黑白灰侘寂）
- status_dots: 未达标（仅通知红色圆点，需更多彩色状态反馈）
- line_icons: 部分达标 → 全界面统一线性风格
- whitespace: 基本合理 → 顶部导航与主标题间距可加 10-15px
- hierarchy: 基本清晰 → 快捷按钮与主输入框层级区分不足

### top3
1. 统一导航栏图标风格 + 交互状态（hover）
2. 快捷操作按钮视觉层次（核心品牌色 + hover）
3. 优化右下角通知语义（图标或 hover 提示）
