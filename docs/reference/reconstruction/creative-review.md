## 3. 可供完整方案吸收的工作与交付合同（暂定分析，不是最终规划）

### 研究与案例应用

输入是用户问题、当前资料和范围，允许单份资料、空白笔记、已有研究续接，不把“三份”硬编码门槛。逐份解析并保留原件、精确定位及已处理/未处理范围；把来源陈述、比较、反例、推论和用户判断分开。检索必须按实际语义方法及覆盖报告，词匹配不可宣称语义推理。输出可编辑笔记、比较/研究报告、方法适用说明、来源与冲突；用户可以只替换一段引用、采用一个方法至当前提案、保存自己的拆解/练习。来源或方法撤回分别影响已有结论：旧版本可读并标记，新任务停止使用不再有效部分，其他合法资料仍能工作。研究报告、方法候选和已证明业务提升是三种不同结果。

### 原创策略、文稿、Office

1. 复用事实、受众、目标、预算、品牌约束、必需/禁用信息；人工空白写作不受缺Brief阻塞。只有影响产出的关键歧义请求补充。
2. 形成2–4个**行为与机制真正不同**的方案，写清核心观念、受众行动、品牌可信理由、兑现方式、资源/成本条件和失败可能。不是替换标题与形容词。
3. 可选择一个机制、保留另一方案结尾、指定段落重写。L0技巧→L1公式→L2活动（受众/内容/渠道/节奏/地点/预算）→L3品牌世界观用于内部推理和可检查依据，不强迫用户填算法表单。
4. 按任务交付策略/提案、活动机制、文章、图文、脚本、视频/播客内容，不用四种常规稿限制原创。常规四稿本身仍应可用：共享事实快照，各自语气、平台、审校和父版本。
5. 专业提案保留十段：Brief理解、市场消费者洞察、核心策略、BigIdea、创意落地、整合传播、媒介资源、效果衡量、执行节奏、风险合规；另保八段拆解。低/中/高预算是可编辑情景，不能伪装实价。每张演示页承担具体决策，不把章节标题生成当内容完成。
6. Office按实际对象编辑；选区、人工锁定、已确认段落、图片/图表/公式/备注/嵌入对象保全。保存后重开验证；导出后再读对象，出错不覆盖源件。未支持对象逐项明示，不能压平成图片后称专业编辑。
7. 审核把事实/数字/范围错误独立于创意评价：九维检查逐主张指回来源和选择；用户/客户改动使受影响审校失效。候选机制多样性、品牌不可互换性、可执行性、母语质量及人工返工时间分别评估，平均分不能遮关键事实失败。

### 视频前期到成片

输入目标、受众、平台与可用资源；原稿/提案可选，独立新建始终可用。先形成可编辑镜头任务：目的、可见证据/动作、对白、声音、时长、构图、连续性、所需素材和权利。转入素材选择、镜头序列、粗剪与精修，共用一个工程和素材身份，不让用户重新搬运。专业操作覆盖逐帧/逐词、轨道、关键帧/适用效果、字幕、声音、实际预览。自动建议有明确源区间、父版本和差异，可局部采用并撤销；文本校对不修改声音。四画幅分别完成构图，不拉伸；母版变化只影响关联变体并保留手改。成片、编辑工程、字幕、封面/平台版本、引用/授权和导出损失说明一并交付。工程交换按剪点/时基/轨序/速度/字幕/音量/编辑性核验，XML有效不等宿主可用。取消/缺源/同名换文件/导出失败可恢复，不污染原素材或其他任务。

### 播客全链

日线索保留来源与问题；周选题做聚类、反例和深挖；月规划看覆盖、节目节奏、节点和缺口。十信号是可解释提案依据，缺一项标缺项不补总分。嘉宾基于真实经历、观点和领域证据选择，三Gate（公共价值/独特性、表达能力与意愿、共鸣）保留人工决定。前采建立事实—场景—感受—冲突—选择—后果—反思的问题梯度，既支持深度对谈也支持真人叙事；不能编造嘉宾答案。

录制/导入后把真实时间码绑定人物、场景、决定、情绪/洞察节点和故事结构。后期可以重组叙事但保留断点及上下文，不能剪出相反意思；旁白、环境音、沉默、音乐各有功能，不能把正弦测试当人声听审。文字校对、音频剪切、重录/获准合成是不同动作。完成长节目混音、噪声与齿音、响度/真峰值检查，保留干声/处理后同段A/B及工程。

发布前冻结最终音频hash、流选择、时长、采样率、工程版本及剪辑映射。七件套为plan.json/script.txt/原始VTT/校对VTT/chapters.json/corrections.json/metadata.json，另有真实MP3/M4A、封面、说明、所需RSS及字幕。章节落在删除区间须人工重选/失效，不能挪到最近时间；重复片段映射一对多。所有文件同版本，缺件不产空包“完成”。平台切片保留2–3分钟完整故事及必要限制，适配画面/字幕/标题/配文，并保存来源与母版关系。发布是另一个获授权动作，RSS文件有效不证明客户端已更新。

### 反馈、语言与学习

实际表现按平台、期间、分母及任务目标评价，互动不等转化/因果；低量也可能是分发条件，不直接判内容失败。把高/普通/失败/争议对照、修改原因与新假设回到选题和方法，保留适用/不适用条件。学习分为来源知识、可查改个人偏好、策略/模板和有独立授权的CPU参数；一条反馈不自动训练或升级事实，模型增益要在真实消费者、独立留出及同预算基线证明。GPU训练已撤回。

### 客户反馈必须形成可核的修改范围

为同一条客户意见保留：评论原文/作者/时间、被评版本、原生定位、用户确认的修改对象或时间区间、采取/不采取理由、对应变更与新交付。意见指“第4页这里太夸张”时，页码/坐标不能自动冒充唯一对象；找不到或有多个候选要求消歧。旧锚失效要显示未定位，不贴到新稿相似句。按一条意见关闭，必须有可打开的新对象和差异；“标为已处理”本身不足。

Microsoft 文档说明传统 PresentationML 批注保留页上位置、作者与日期，并不自动提供寰意所需的业务对象身份。因此跨Office文件导入的批注需保存原生锚，同时建立经确认的对象映射，不能假定批注天然稳定绑定文字形状。参考：[Microsoft — Working with comments](https://learn.microsoft.com/en-us/office/open-xml/presentation/working-with-comments)。这是本次推导的产品合同，不声称Microsoft替寰意完成映射。

**验收：**客户PPT中同文两处和一条页边批注→选择目标文本框→仅改选中对象→其它对象/页/备注/媒体原样→批注对应新版本的差异→再次导出重开；再加一个旧版本评论，必须保留原定位并提示重核。文稿/表格/视频以相同任务语义、不同坐标单位验收。

### 交付包应冻结版本并支持增量重交

一项品牌工作可能要PPTX+PDF+预算XLSX+脚本文稿+横竖成片+字幕+声音分轨。当前通用Artifact版本有价值，但需要同一交付批次绑定每个成员的工程版本、变体、检查与文件，不让用户逐文件猜哪版最终。客户只改预算时，系统只列影响的方案页/图表/口播/文件；未关联项保持旧内容，重新导出后再提交完整一致的包。

**新增价值：**减少“PPT已改而PDF/字幕/报价仍旧”的真实返工。**重叠合并：**在F12成果版本/导出上扩展，接F09–11消费者；不新增文件库。**验收：**一成员失败不把整包标成功；补导出不重复生成已合格成员；重开可复现每个成员及来源，历史交付不被覆盖。压缩包与云链接是交付载体，不必成为两个系统。

### 续读四：真实录音、补录和声音表演

新增Fairlight PDF274–339（印刷247–312）第4课连续全文，关键图示PDF285、294、310、334已看。录音演示音频与麦克风仍未实录/实听。本章手工录音、ADR、系统音发生器、拟音采样器及AI生成录音cue均已读；研究工具不能自动成为本产品新增集成。

- “录音可用”至少是选择真实输入及声道→输入电平/试录回放→确认落盘位置/剩余空间→录音准备→真实采集→停止并完成持久化→回放/选take→进入剪辑。录入前的输入电平不能被播放推子掩盖；软件降低监听音量不会修复硬件输入削波。必须区分正在监听、已准备、正在记录和回放已有文件，设备掉线/权限拒绝/空间不足需要保护已有分段及解释恢复边界。
- 同一位置反复录音保留每个take，整段与局部补录均可对比挑选。角色/段落/cue/原稿版本、输入来源、录制起止、已选take与选择原因应持久保留，不依赖临时列表；教程印刷280说明其take列表重开后清空，寰意连续工作要求不应复制这个限制。未选take不能同播叠音；删除选中take后可恢复旧选择。
- 补录不只是上传另一音频：同屏/同步呈现台词与对应画面，预听→练习→正式录制，前后余量和提示音可按录制对象调整；提示音/导引声属于监听，不能意外混入最终交付。保留原声、替换声与决定映射；更改台词要标哪些cue/字幕/译配需重新录制。
- 录音cue导入是有版本的合并：核列含义/时间基/角色/完成状态，重复cue应呈冲突或更新，不静默增一份。自动识别人声只给候选说话人，真实角色必须对应核实。教材示例AI新列表既重复旧词又含Music标签，正好说明“AI跑完”不代表可直接代替人类录音清单。
- 拟音要服务具体动作和空间，而非随机铺音：素材选区/起音、动作同步、远近与响度曲线、连续/单次播放、层叠、替换、撤销与导出均真实。脚步瞬态可供候选切分，但持续落叶/衣物声不能机械按峰拆成动作。保留源音效权利与时间段，生成/自录/授权素材来源不同；没有外部音效库也能用用户素材完成。
- 完整产品不必暴露接线矩阵或振荡器作为一级产品入口；录制所需路由/声道/监听与专业层控制应可用，复杂选择按当前任务呈现。硬件/系统权限是外部条件，专业录音对象模型与失败恢复是软件义务，不能以外部条件为由缩成“上传并导出”。


### 续读五：对白编辑必须处理真实表演，而不只处理文字

新增Fairlight PDF108–187（印刷81–160）第2课连续全文；关键图示PDF122、170、174、182已看。没有运行教程项目或试听参考音频。原章主要对应J22/J25、UX075–086的多轨/逐句/词级精修，也支撑J23/J24导演与前采意图进入后期，不改变旧V1对多机位等后置能力的边界。

- 原始录音可能含机内双声道、独立boom/lav及场记混音，同步结果需要保源时钟、同步方式、偏移与原有声道/元数据。声道选择必须可逐片段试听和切换，单声道工作不删除未选声道。标出说话人只能帮助定位；多个讲话者混在同一声道不能宣称已真正分轨隔离。
- 人物对白轨应包含相应呼吸、叹气、笑与表演性声音，环境/衣服/脚步单独处理而有上下文；“删除所有非文字音/停顿”直接损坏专业成品。智能剪辑应出候选、理由及原时段，用户保留/恢复；不因转录为空自动丢弃素材。
- 对多take需能以同句定位和循环试听选表演，按词/短句组合，同时保源take与选择关系。客户要求只把最后半句换回另一take，软件应定位并局部替换，不让已确认其它段变化；拼接前后自然停顿、呼吸、环境底及微淡化均需在真实回放中验证。
- 时间线剪切、波纹删除、移动到其它轨、原地替换、微移是不同操作；每项明确作用轨/选区/关联字幕与隐藏层。显示隐藏不是锁定/静音；不能以“没有选中就切所有轨”这类教材行为作为寰意默认。切片与移动保源in/out，换轨默认保时间位置，允许显式改变，撤销后逐对象状态复原。
- 多层take与合成段不要求用户靠临时复制一批工程规避数据丢失。选层/弃用/合成保结构化选择；暂不用片段可重启用。编辑当前层时不偷偷移动未选层；修改组合段后旧版本仍能重开。渲染成单文件只是派生成品，不能丢失背后的可编辑组合。
