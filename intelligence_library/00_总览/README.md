判断当前产品行为与开发边界时，以仓库根目录 `AGENTS.md`、`00-GOVERNANCE/LUMENIS-PRODUCT-ARCHITECTURE-CURRENT.md`、`00-GOVERNANCE/CROSS-REPO-CANONICAL-REGISTRY-V1.md`、机器可读跨产品契约和当前源码为准。研究材料只有经过当前源码、数据、权限、证据和运行时验证后，才能进入产品事实。

知识资产按产品域、共享能力、采集与证据、研究案例分类。这里不维护第二套生产代码或跨仓库权威。
