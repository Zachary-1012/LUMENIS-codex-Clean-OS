# 广告投流与深度学习模块设计文档 v1.1

> v1.1 更新：加入真实世界商业体系、平台地区、准入门槛、资金结算、合规约束等现实维度，作为开发硬约束。

## 一、模块定位

`ad_intelligence` 是序境/LUMENIS 的商业应用级广告投流智能模块，负责：
- 全平台广告数据采集与分析（只读）
- 投流策略生成与优化（AI 辅助）
- 深度学习模型（CTR/CVR 预测、智能出价）
- 投流操作执行（带 Permission Gate，默认关闭，需人工确认）

## 二、红线原则

1. **投流操作默认关闭**：所有写操作（创建计划、修改出价、暂停/启动）必须经过 Permission Gate + 人工确认
2. **资金操作最高保护**：任何涉及预算调整、出价修改的操作必须人工二次确认
3. **只读优先**：数据采集、分析、预测默认可用；写操作需显式授权
4. **不破解平台 API**：使用官方 API 或浏览器只读采集，不对抗平台风控
5. **可追溯**：所有投流操作必须记录操作人、时间、前后状态、审批记录
6. **尊重平台商业现实**：不假设所有平台都能直接 API 接入，不假设所有地区都能投放，不假设所有行业都能投广告

## 二点五、真实世界商业体系硬约束（开发必须遵守）

### 2.5.1 平台地区与市场覆盖

| 平台 | 广告系统 | 主要市场 | 中国大陆可直接访问 | 需代理 | 地区定向粒度 |
|------|----------|----------|-------------------|--------|-------------|
| 小红书 | 聚光 | 中国大陆 | ✅ | ❌ | 省/市/商圈 |
| 抖音 | 巨量引擎 | 中国大陆 | ✅ | ❌ | 省/市/商圈/人群包 |
| B站 | 花火 | 中国大陆 | ✅ | ❌ | 省/市/兴趣 |
| 微博 | 粉丝通 | 中国大陆 | ✅ | ❌ | 省/市/兴趣/人群 |
| 知乎 | 知+ | 中国大陆 | ✅ | ❌ | 省/市/兴趣/话题 |
| Facebook | Meta Ads | 全球（欧美/东南亚为主） | ❌ | ✅ | 国家/州/市/DMA |
| X | X Ads | 全球（欧美/日本为主） | ❌ | ✅ | 国家/州/市 |
| Instagram | Meta Ads | 全球 | ❌ | ✅ | 同 Facebook |

**开发约束**：
- 中国大陆平台（小红书/抖音/B站/微博/知乎）默认直连，无需代理
- 海外平台（Facebook/X/Instagram）必须检测代理可用性，无代理时返回明确错误而非假成功
- 地区定向参数必须按平台实际支持粒度传递，不支持的粒度必须降级或拒绝

### 2.5.2 广告平台准入门槛（真实商业现实）

| 平台 | 开户要求 | 行业资质 | 审核周期 | 最低充值 | API 权限 |
|------|----------|----------|----------|----------|----------|
| 小红书聚光 | 企业营业执照+ICP | 部分行业需特批 | 1-3工作日 | 5000元 | 需申请，有配额 |
| 巨量引擎 | 企业营业执照+ICP | 医疗/金融/教育特批 | 1-2工作日 | 10000元 | Marketing API 需审核 |
| B站花火 | 企业认证 | 部分行业限制 | 3-5工作日 | 5000元 | API 有限开放 |
| 微博粉丝通 | 企业营业执照 | 行业资质审核 | 1-3工作日 | 5000元 | API 需申请 |
| 知乎知+ | 企业营业执照 | 内容审核严 | 2-5工作日 | 5000元 | API 有限开放 |

| X Ads | 企业账号+信用卡 | 政策广告需特批 | 即时 | 无最低（信用卡） | API 需开发者审核 |

**开发约束**：
- 系统必须记录每个平台的开户状态（未开户/审核中/已开户/被封禁）
- 未开户平台不得生成投流建议，只能做竞品分析和数据采集
- API 权限状态必须显式记录，无 API 权限时只能用浏览器只读采集
- 行业限制必须在策略生成时检查，受限行业不得自动生成投流方案

### 2.5.3 资金与结算现实

| 维度 | 中国大陆平台 | 海外平台 |
|------|-------------|----------|
| 币种 | CNY | USD（Meta/X） |
| 支付方式 | 对公转账/支付宝 | 信用卡/PayPal |
| 结算周期 | 预充值，按消耗扣 | 后付费/预付费 |
| 发票 | 增值税专用发票 | 电子发票（海外） |
| 汇率风险 | 无 | 有，需记录汇率 |
| 最低消耗 | 有（日预算下限） | 无硬性下限 |

**开发约束**：
- 所有金额必须带币种字段，不得假设统一 CNY
- 跨平台 ROAS 比较必须先统一币种（按当日汇率换算）
- 预算建议必须考虑各平台最低充值和日预算下限
- 汇率数据必须可追溯来源和时间

### 2.5.4 合规与法律约束

| 法规 | 适用范围 | 对投流的影响 |
|------|----------|-------------|
| 广告法 | 中国大陆 | 禁用极限词、虚假宣传、医疗用语 |
| 个人信息保护法 | 中国大陆 | 用户数据采集需授权，定向需合规 |
| 数据安全法 | 中国大陆 | 数据出境需评估 |
| GDPR | 欧盟 | 用户同意管理、数据可携带权 |
| CCPA | 加州 | 消费者隐私权、退出权 |
| 平台广告政策 | 各平台 | 禁止行业、内容规范、 landing page 要求 |

**开发约束**：
- 广告文案生成必须经过合规检查（极限词、医疗用语、虚假承诺）
- 用户定向数据必须标注数据来源和授权状态
- 海外投放必须检查目标地区的隐私法规要求
- 所有 AI 生成的广告内容必须标注"AI 生成，需人工审核"

### 2.5.5 API 权限现实

| 平台 | API 名称 | 申请难度 | 配额限制 | 数据粒度 | 写操作权限 |
|------|----------|----------|----------|----------|-----------|
| 巨量引擎 | Marketing API | 中（需企业资质） | 有QPS限制 | 小时级 | 支持创建/修改 |
| 小红书聚光 | 聚光API | 高（需特批） | 严格配额 | 天级 | 有限支持 |
| Meta Ads | Marketing API | 中（需App审核） | 有速率限制 | 小时级 | 完整支持 |
| X Ads | Ads API | 高（需开发者审核） | 严格配额 | 小时级 | 完整支持 |
| B站花火 | 花火API | 高（邀请制） | 有限 | 天级 | 有限支持 |

**开发约束**：
- 每个平台必须有 `api_access_level` 字段：none/read_only/full
- 无 API 权限时，数据采集走浏览器只读路径，写操作不可用
- API 调用必须有速率限制和重试退避
- API 配额耗尽时必须优雅降级，不得报错崩溃

### 2.5.6 代理商体系现实

- 中国大陆很多平台（尤其巨量引擎、小红书）通过代理商开户和充值
- 代理商可能有返点政策（消耗返点 3%-15%），影响实际 ROI
- 代理商可能提供代运营服务，系统需支持"代理商操作"角色
- 跨代理商账户数据整合需考虑数据权限隔离

**开发约束**：
- 账户模型必须支持"代理商"层级（代理商 → 账户 → 计划）
- ROI 计算必须支持返点参数（实际成本 = 消耗 × (1 - 返点率)）
- 多账户数据整合必须有数据权限隔离

## 四、权限等级

| 等级 | 能力 | 默认 | 说明 |
|------|------|------|------|
| READ | 数据采集、查看 | ✅ 启用 | 只读广告数据 |
| ANALYZE | 分析、预测、建议 | ✅ 启用 | AI 分析与预测 |
| PREVIEW | 策略预览、模拟 | ⚠️ 需授权 | 模拟投流效果，不实际执行 |
| EXECUTE | 实际投流操作 | ❌ 关闭 | 创建/修改/暂停计划，必须人工确认 |

## 五、深度学习模型

### 5.1 CTR 预测模型
- 输入：用户特征 + 广告特征 + 上下文特征
- 输出：点击率预测概率
- 模型：DeepFM / DCN / 轻量级 GBDT+LR
- 训练数据：历史广告曝光-点击数据

### 5.2 CVR 预测模型
- 输入：点击后行为序列 + 用户画像 + 商品特征
- 输出：转化率预测概率
- 模型：DIN / DIEN / 序列模型
- 训练数据：历史点击-转化数据

### 5.3 智能出价优化
- 目标：最大化 ROAS 或 转化量
- 约束：预算、出价上下限
- 算法：强化学习 / 贝叶斯优化 / 线性规划
- 安全：出价建议必须人工确认后执行

### 5.4 特征工程
- 用户特征：年龄、性别、地域、兴趣、行为序列
- 广告特征：素材、文案、定向、出价、落地页
- 上下文特征：时间、平台、竞争强度
- 实时特征：当前曝光量、点击率、转化率

## 七、投流策略框架

### 7.1 受众定向
- 基础定向：年龄、性别、地域
- 兴趣定向：兴趣标签、行为标签
- 自定义受众：种子人群、相似人群（Lookalike）
- 再营销：已互动用户、已访问用户

### 7.2 预算分配
- 日预算/总预算
- 多计划预算分配（按 ROAS 动态调整）
- 预算 pacing（匀速/加速）

### 7.3 出价策略
- CPC（按点击付费）
- CPM（按千次曝光付费）
- oCPM（优化千次曝光）
- 智能出价（目标成本/目标 ROAS）

## 八、与主系统集成

- 广告数据 → 数据资产层（统一存储）
- 投流策略 → AI Gateway（智谱 glm-5.3 深度推理）
- 深度学习模型 → 本地 Ollama / 智谱 API
- 投流操作 → Permission Gate（11 级权限模型）
- 操作记录 → Evidence Chain（全链路追溯）

## 十、商业应用级标准

1. **数据准确性**：广告数据与平台后台误差 < 1%
2. **预测精度**：CTR/CVR 预测 AUC > 0.75
3. **响应速度**：数据采集 < 5 分钟延迟
4. **安全性**：所有写操作可追溯、可回滚
5. **稳定性**：7×24 小时运行，故障自动恢复
6. **可解释性**：AI 建议必须给出理由和置信度
