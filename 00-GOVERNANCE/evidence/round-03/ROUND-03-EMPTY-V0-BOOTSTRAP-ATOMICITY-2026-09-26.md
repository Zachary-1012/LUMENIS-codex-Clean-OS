An injected failure after the real Evidence owner initialized its schema left those earlier writes in place. The pre-migration backup correctly retained the empty state, but failure recovery required manual restore. The migrator now begins a transaction for this empty-v0 bootstrap, defers only its v1 marker commit, and commits explicitly when target v1 succeeds without a later versioned step. Prerequisite or first-step failure rolls back the new base schema and v1 marker with owner schema changes. Existing `set_version` callers retain the default commit behavior; partial-v0 base schema still fails closed. A v0 database with all base tables already present retains its historical path and is **not claimed repaired** by this slice. Failure logging now describes rollback of uncommitted changes without guessing a persisted version.
