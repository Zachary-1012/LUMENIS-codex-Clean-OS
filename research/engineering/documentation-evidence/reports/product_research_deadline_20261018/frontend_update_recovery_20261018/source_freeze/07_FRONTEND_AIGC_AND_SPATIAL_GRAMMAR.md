# 前端本身的AIGC与智能UI：完整工作面的表现合同

## 1. 先定义用户实际得到什么

依据当前main Experience753–759、1388–1427、1485–1496，以及44屏ScreenSpec目录的逐屏语义映射。本章是对应这些原要求的新审核设计，未宣称模型或正式Flutter已接通。每屏进一步的运行合同仍由原Owner、Core和ViewModel承接。

前端AIGC有两条互补路径。第一条是任务相关的原创视觉与创意构成：根据允许的上下文形成有序、有辨识度的阅读场、关系空间、比较构成或成果呈现；保留纸层、轻透材质、柔光与有机彩绘的产品语法，不把所有结果画成同一张卡片。第二条是智能UI：为当前问题提出适合的原生表现和动作，比如先文字、再同口径表格、局部图解或可直接调节的计算控件。两条都服务真实用户任务，不要求用户制作一件“AIGC作品”才能使用产品。

真实正文、数值、单位、引用、权限、状态和可操作边界由现有Owner提供。生成画面不能承担事实表格、关系真相或授权。不同内容对应不同工作面；编辑文稿、操作时间线、读来源、审批风险不会被通用生成画布取代。

## 2. 一次完整表达如何发生

1. 用户打开任务或改变问题；已绑定的确定性内容先可用，无需等待模型。
2. 现有C2取得获准的Task、输入版本、证据摘要、当前组件能力和设备约束。正文秘密、私有资料不能因“做视觉”被额外外传。
3. 提案只描述本屏允许的组件、语义区域、表现参数与动作引用。原创视觉资源有真实来源、许可和生成状态；没有运行时生成就显示预生成/本地示例。
4. 原有合同校验字段、范围、组件能力、资源预算和Permission。未知类型拒绝或降级为可读文字，不能执行模型生成HTML/JS。
5. 首个有用块稳定呈现。后到块按同Task/run/输入版本局部补齐；不在用户指针下移动目标，不替换正在编辑的控件。
6. 用户可对有意义的提案比较、修改、采用或拒绝。普通自动适配如窄屏重排不强制多一步确认；会影响当前手改、事实选择或业务效果的动作必须明确范围。
7. 采用视觉表达只改变允许的呈现；实际业务动作另走原Owner。保存作品时绑定内容版本与采用的表现版本，返回真实回执并读回。临时设备布局不写入业务作品。
8. 撤回提案回到前一可用表达；取消任务、暂停阅读、停止媒体、撤销已采用编辑各有明确语义。权限撤销立即禁用相关动作，历史合法草稿按原策略处理。

故障路径：无模型、超时、拒绝、部分结果、资源缺失、类型不支持、版本过期、权限变化、设备性能不足分别说明；保留原生直接操作和已有结果。不能把模型失败处理为用户丢稿，也不能不断自动重试增加费用。

## 3. 自有视觉语法与空间约束

正视阅读面是稳定中景；证据侧读在前侧，保留可见来源和返回点；背景只提供空间节奏，不承载必读信息。选中对象通过位置、轮廓、标题及必要高光同时识别，不靠颜色或发光单一信号。薄纸边缘、半透局部层、柔接触影表达“可拿起”“已落定”“属于同一对象”；不是每个矩形都加玻璃、霓虹和大投影。

审核示意采用相对层级：背景0、阅读面1、被操作对象2、证据侧读3、必要模态4。它不是写死的生产z-index；同一时刻一个活动模态。透视只发生在探索/转场/对象关系中，长文字、数字和输入框尽量正视。隐藏层必须有等价列表或明确入口，不能让遮挡成为资料遗漏。

光源默认从前上方轻柔照射，接触阴影短且低对比，抬升对象的影子随距离变化。高光用于当前焦点或允许操作，错误与风险用明确文字/图标而非红色光晕。彩绘用于对象标记、恰当的创意区域和轻量背景；不复制参考人物、社媒页面或竞品整体布局。

减少动态时，旋转、惯性、随机轨迹和持续光动改为静态层次/明确切换；功能、定位和状态完整。高对比模式去除透明叠色依赖，保边界、文字和焦点；放大与窄屏允许内容顺序重排，不缩小字号维持立体图。

## 4. 44屏基线的具体构成与适配

下表“构成”是本稿设计提案；“不变量”来自当前屏幕映射。全部保留直接路径与无AI路径。一个屏幕可含多个专用工作面，44不是页面或任务数量上限。

| 工作面 | 首个有用结果与空间构成 | 后续智能表达／原创视觉位置 | 必须保留的不变量 |
|---|---|---|---|
| ACC-01 内部入口 | 宿主真实入口状态，单一清晰继续动作 | 轻纸门框提示进入原工作，不生成账户流程 | 无callback不造路由；失败留在入口 |
| ACC-02 视角 | 当前范围＋可访问目录＋确认预览 | 当前/候选范围前后对照，未确认不切换 | 服务端scope确认；选择不授予权限 |
| ACC-03 首页 | 打开即可提任务，最重要续接点在手边 | 按当前任务形成克制的工作入口构成，不做KPI墙 | 原Task、草稿、已访问位置；建议不自动执行 |
| ACC-04 恢复 | 发生什么、影响什么、可做什么 | 原工作仍可见，阻断说明在前侧，不全屏惊吓 | 合法恢复路径与receipt；保未提交内容 |
| AI-01 任务意图 | 可编辑目标、资料与必要约束 | 随问题给文字/比较/参数等已许可表现提案 | 同Task与输入版本；用户改意图优先 |
| AI-02 真实执行 | 当前阶段和首个有用输出 | 阶段沿一条清晰路径，真实新块局部抵达 | run/input/model/recipe版本；完成以Owner为准 |
| AI-03 结论核验 | 一个结论和准确引用 | Claim阅读面＋可展开依据层，未知显式留白 | source locator/父版；局部修订不篡改原来源 |
| AI-04 能力 | 当前任务可用能力及输入输出 | 任务相关能力分组；详细风险和许可按需展开 | 每个生命周期动作独立授权；目录不等运行 |
| AI-05 服务状态 | 最新可读状态及采样时间 | 有界样本曲线，缺数据留空 | 不暴露原provider/model，不写回业务任务 |
| CTH-01 运营 | 当前主体/时间窗及事件流 | 稳定事件脊柱＋选中详情，变化有来源 | scope、event、时间；不能用装饰脉冲假实时 |
| CTH-02 主体 | 可查主体及已证关系 | 档案是正视主面，关系仅辅助定位 | 目录预览不切live Subject；未知不猜 |
| CTH-03 监测 | 变化摘要、平台lane、单条原文 | 内容原生形态重构为统一但不抹平差异的Reader | 原平台ID/原生时间/采集时间；热点与样本分开 |
| CTH-04 事件 | 时间顺序及有证关系 | 时间轴/关系图按问题切换；选中边近侧看证据 | 关系≠因果；无边不生成补全 |
| CTH-05 日期 | 有真实口径的日密度与当日样本 | 日历层只为找日期，展开正视列表 | 时区、窗口、分子分母、source |
| CTH-06 反馈 | 队列＋一条原始措辞 | 原文在前，类别解释在侧，可纠正 | 人工/AI版本分开；反馈不自动变Case |
| CTH-07 趋势 | 定义、单位、窗口与数据 | 图/表按任务并置，可直接查某点依据 | 真实计算与分母；缺值不补零 |
| CTH-08 Case | 当前Case到Outcome链 | 泳道前后关系清楚，知识在独立侧层 | canonical Case与审阅状态，不把知识盖事实 |
| CTH-09 决策 | 风险依据、Decision、实际Action状态 | 提案、审批、回执分别成层，防误认为已执行 | 原approval/effect ID；不平行建任务 |
| CTH-10 简报 | 正文与来源，先读当前结论 | 长文阅读节奏与方法/Action-Outcome局部展开 | job/report/hash/父版；源失效定位复核 |
| BMP-01 市场 | 品牌市场信号和覆盖 | 信号节奏＋来源抽屉，品牌表达有自身气质 | 样本、窗口、brand scope，不假全市场 |
| BMP-02 关系 | 品牌/子品牌/竞品已证关系 | 稀疏关系构成＋实体档案，未知关系分层 | 每条边来源/版本；平面列表等价 |
| BMP-03 机会 | 候选理由、动量/置信的真实定义 | 信号比较构成，选择后展开证据简报 | 排名解释与评分版本；不把视觉大小当质量 |
| BMP-04 传播 | 各阶段observed/unavailable | 横向渠道路径配定义矩阵，空段明确 | 单位/渠道/时间/来源；无观测不画流量 |
| BMP-05 创作者 | 匹配理由、风险与真实样本 | 类别目录＋样本阅读，不统一人气星级卡 | 指标定义/时间/评估版本；无数据不排名 |
| BMP-06 创意 | 可编辑正文/方案及真实状态 | 创意区域允许原创视觉构成，事实引用贴近正文 | Draft/Review/Approved/Delivered；修改使旧审阅失效 |
| BMP-07 活动 | 目标、预算、里程碑与影响 | 时间与预算分层，改动先看受影响区 | 估算/承诺/实支区分；父版与恢复 |
| BMP-08 播客 | 脚本/真实音轨与当前选区 | 时间线和来源分层，声音可视只来自真采样 | 独立Brief可开始；本地朗读不等成片 |
| BMP-09 评价 | 维度、真实Outcome、覆盖 | 同维比较与置信/分母并看 | 意见不冒分数；源事实不可改写 |
| BMP-10 风险 | 原始依据和待处理状态 | 严重性队列＋正视原文，警示低干扰明确 | 判断版本与决策receipt；不能以红光代替事实 |
| BMP-11 基准 | 先见币种/期间/口径 | 可比矩阵展开差距，不可比单元明确 | 每格定义、样本、scope与计算版本 |
| SH-01 独立工作 | 自有Brief/合法素材可直接进入专用工作面 | 阅读、写作、时间线、分镜按任务本身展开 | 目录不执行；不强制业务主体前置 |
| SH-02 资料 | 搜索结果及一份可读原件 | 图文/线程/视频/音频保持原生结构，研究阅读场 | Source、rights与定位；进入任务不重复搜 |
| SH-03 指标 | 指标定义与成熟度 | 树＋逐级lineage，按问题展开必要层 | 同一Metric版本；不泄DB表/路径 |
| SH-04 成果 | 真正重开Artifact与父版本 | 专属Viewer＋局部diff，清晰回原任务 | hash/Task/source一致；无内容不假比较 |
| SH-05 学习 | 候选、证据、收益风险与资格 | 变更对照和反例阅读面；推广决定回原Owner | NOT_ELIGIBLE原因；批准不等已生效；回滚读回 |
| SH-06 续接 | 通知/任务/警报各自状态 | 一个明确下一步，原上下文可见 | origin与Task保持；打开不重复执行 |
| SYS-01 健康 | 最新Guardian/队列/保护状态 | 清晰状态脊柱，按故障影响展开 | 采样时间；技术健康不冒业务成功 |
| SYS-02 采集 | 各平台真实configured/active/partial/blocked | manifest矩阵＋单lane详情，能力缺口可见 | attempt/source receipt；22来源配置不等22真实可用 |
| SYS-03 数据链 | schema/自检/可读性/Truth各层结果 | 分层检查，不用一个总绿灯 | check/time/chain；不泄漏原业务行 |
| SYS-04 安全 | 当前允许范围和审计可用性 | 简洁访问姿态，具体任务权限回该任务解释 | 页面不授予权限；策略细节不暴露 |
| SYS-05 设置 | 当前偏好、即时预览与撤销 | 独立预览台试光影/物理/密度，返回原工作 | 本端偏好不改业务；保存失败/恢复默认清楚 |
| SYS-06 浏览 | 当前来源及允许操作 | 原任务与受控页面并置，验证必要时前置 | page revision/lease/权限；浏览画面不自动成Evidence |
| SYS-07 门禁 | gate证据和未完成项 | check→scope→version→Evidence，可逐条核 | blocked/unknown/pass分开；本页不替审批 |
| SYS-08 日志 | 脱敏目录/实际Trace | 有真实trace才画路径，可回合法原Task | 无trace不生成图；不公开秘密或路径 |

## 5. 所有工作面的统一质量要求

第一次响应必须有可用信息或真实等待说明。后续更正保持稳定身份和当前输入；布局变化有局部差异提示，用户明确布局选择优先。语义动作不得由生成组件标题决定，必须绑定已有Action。敏感动作前检查当前权限与版本，不能信任旧提案。

中/英/韩是界面语言；十二语内容是另一条能力线。原文保真、RTL/bidi边界、字素选区、字幕断行和字体缺失分别验证；切UI语言不自动翻译用户内容。屏幕阅读顺序与视觉顺序一致，图关系有文字/表格等价，空间装饰不产生多余可访问焦点。

Web Workspace与Windows/macOS承担复杂工作；iOS按已批准任务角色适配，不能因难做就永久只读；原有Public Website内容家族只呈公开内容与清楚标示的演示，不搬内部操作页。四表面分别验真实操作、恢复、字体、输入与性能，不能用一个网页截图通过四端。

## 6. 本轮研究采用与不采用

DynaVis的有用原理是自然语言提出一次编辑后，让用户保留直接调节的原生控件，减少反复提示；本方案不用它的生成HTML/callback引擎。Apple的类型化渐进视图示例支持稳定身份和分段可用，但不是正确事实的保证。Zotero的选段进入笔记机制支持来源就地带入目标，我们落实成原Task的精确选段和合法引用，不复制其页面。

Nimble研究可作为既有C2对已许可组件候选的排序优化：输入真实上下文，输出候选ID/版本与none/unknown；确定性规则可解决时不等待模型。当前公开模型候选softmax不是校准可靠度，平面字段可互相矛盾，不能将概率变授权，也不能替代原创视觉。此项只作研究备选，尚未运行推理或接入，当前核心许可未明不分发代码。

外部机制只用于解释可行思路；产品自己的空间语法、组件合同、业务状态和测试由当前序境架构承接。来源与阅读边界见研究附录，不以竞品结果宣称本产品已节省时间。
