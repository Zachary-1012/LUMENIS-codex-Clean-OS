# 真实公开样本研究 real-public-v1

先读REPORT.md；CASE_READING.md记外部真实实验与实际正文读取边界。三个UCI官方原包和原件均保留，CC BY 4.0作者/DOI见报告。EXPERIMENT_DESIGN.md说明固定切分、探索性选择及负结果。

复现：python run.py；python verify_outputs.py。只用标准库，不联网、不训练、不导入产品。RESULTS.json为全部数值，两个CSV为逐行预测；VALIDATION_RECEIPT.json是独立输出重算而非外部独立评审。

LEDGER_ADDENDUM.json按既有产品义务挂回版本总账，不覆盖旧冻结索引；仅适用于当前研究范围。产品、四端、模型、创作质量与业务收益均未运行验收。

原包和数据可按其CC BY条件复用；两篇公开论文的取得仅用于本次私人研究证据，不能据此声明其原数据/图表/全文开放再分发或训练许可。
