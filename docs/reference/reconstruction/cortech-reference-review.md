## 值得保留的产品方法

1. 同集团跨城、本城直接对手、跨城高端标杆各回答不同问题。对照应按明确关系和比较理由建立，可重叠、有生效期间，避免仅按名字或城市混成一个竞品榜。
2. 全国地图用于地域分布与城市进入；时间趋势、排名和样本细节用于准确比较。用户能从对象进入原始样本、再保存比较用于监测/客户提案，才形成工作价值。
3. 评论中的停车、规则、预约、门票、权益和动线问题能进入服务工作、内容FAQ与活动调整。已存在的栏目/征集机制先核实，AI不能把客户正在做的事包装成新建议。
4. 内容目的分开：品牌文化、服务解释、互动、活动参与与转化各有评价。低点赞不自动淘汰文化内容；激励互动与自然互动、可见线索与真实成交不混淆。
5. 月度复盘覆盖内容、创作者合作、粉丝服务、投放、洞察与舆情；与寰意完整经营/品牌/研究/原创/媒体连接，不因参考侧重商场而缩成商场监测系统。

## 参考自身的限制

- 新旧日期、首次发现和指标刷新不能互代。旧帖出现新评论/传播仍可能需提醒；固定“旧帖永不报警”会漏掉复燃。固定新入库条数的异常倍数容易被补抓/覆盖变化污染。
- 关键词排除、同昵称、粉丝数和文风不足以确定主体归属、同一人或KOL/KOC/KOS商业关系。无平台ID时保待核来源身份，不能丢真实材料或编ID。
- 样本、有效样本和已处理样本分母必须明确；部分报告80/85等口径不能当全体舆情率。研究列77条详情、842卡片、290评论、12条精选动作分别说明，精选案例不估总体比例。
- 无后台数据时保持未知，不能把参考系统“无曝光/投放”限制写成寰意不支持获准后台数据。地区账号、单日次数、私有端点和历史环境变量方案不定义多用户产品。
- 页面观察到路由切换后主区溢出隐藏，普通滚动未露出竞品区域；定位标题后才滚到地图。这是本次UI可达性问题，不据此推断全系统后端。
- 同系筛选后列表仍见混合对象、层级为破折号，未证筛选生效；名称别名可能重复，需身份核验，不能仅凭名字定错。零笔记显示0%负面会误读为已观测零风险。
- 紧急条目有普通询价/正面标题；未读上下文不能直接判误报，但产品必须显示风险理由、证据和待核事实。

## 寰意的地图与比较交互合同（根亲自评估）

地图是按需视图，不是所有分析首页的装饰。地图、表、趋势共享对象集合、来源范围、时间窗和指标定义，筛选与导出一致。全国→城市/商圈→项目可逐级进入；用户可固定自己的项目、添加比较对象并保存视图。未知位置单列，不能用账号IP城市替代项目地址。

标记大小说明所表达的样本数/指标及覆盖；不能把公开样本声量份额写成市场份额。聚合点保项目数与样本数的区别。少量系列用趋势，其余按任务选小倍图或表；不把所有对象塞进彩色线团。颜色和点形有非颜色替代，键盘、触控与屏幕阅读可用；所有内容滚动可达。

点选立即反馈选中对象，再真实加载详情；90ms只属首次反馈目标。数字不做会临时显示错误业务值的计数动画。基底克制，标签清楚，重点由实际内容和当前选择形成；不复制参考圆角卡片、配色或整页模板。来源、意见和分析可按当前任务并列，保滚动与选择；不新增永久空侧栏。

具体验收：改城市/期间/关系组后地图、表、趋势、导出取同一集合；同集团不同城市保各自数据，别名不重复计数；无数据与0分开；取消/失败保原有效比较；选一个异常能直达来源版本、修订判断、保存并重开。这些是待实现合同，不是本轮已实现。
