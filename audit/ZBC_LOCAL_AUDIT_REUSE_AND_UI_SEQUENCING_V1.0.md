## 二、审计→复用判定（开发任何东西前先查台账）
对每个功能/模块/页面/规则产出统一台账行：`资产名 → 来源位置 → 当前主线是否已有 → 判定[直接复用/适配补入/真缺失新建/废弃] → 所属域(ZBMP/CTH/Shared) → 动作与验收`。
- 已有：直接复用或适配当前双域架构补入，**禁止重写/重造/恢复旧版**。
- 真缺失：本地与研究都没有，才允许新建，并标注"真缺失"依据。
- 冲突：以当前双域规划与用户最新拍板为准。
- 数据/规则/采集器/安全/AI/报告/KOS/Runtime/账户/前端全覆盖；采集器与 collector_guard、全平台 adapter 已就绪，只接入不重开发。

## 三、执行节奏（锁死，避免返工）
- **阶段一（现在，优先）**：功能/数据/规则/采集链路/Runtime/账户/前后端契约/历史数据适配融合/本地审计复用——先补齐、跑通、可自动运行。
- **阶段二（功能补齐后，统一集中推进 UI）**：把下方登记的全部 UI 更新点在当前新架构(Design System V1.1 + 双域导航)上一次性增量落地。
- 阶段一期间 UI 只做"不阻断功能的必要接线"，**不零散改版、不边做功能边调视觉**，防止重复劳动；已确认的 UI 点以本清单为准，不丢、不改口径。

## 四、UI 更新点登记清单（待功能补齐后统一实施，一项不丢）
1. 视觉调性：去素加浓但不花；同色系渐变卡、超大细数字(整数暗/小数亮)、实底选中圆、小彩色事件点；玻璃层次 1–2 层禁 glass-on-glass；六态微交互 hover/focus/active/disabled/loading/empty 统一 150–250ms。
2. 色彩：主色 #0F766E / 悬停 #14B8A6 / 深 #0D5D56，芥子金 #C9A961 极低频；三域 ZBMP #0F766E、CTH #2563EB、SYSTEM #7C3AED；弃用 OpenAI 绿 #10A37F；默认浅色、可切深色双主题。
3. 字体层级：Inter + Noto Sans SC，不粗不细、字号不过大，按层级 H1 22/600、H2 17/600、H3 15/600、Data 24/700、Body 13、Caption 11；仅常规+粗体两级字重。
4. 布局红线：整页不滚动(PC 100dvh 减顶/侧栏，手机 safe-area+dvh)，仅数据集合有界内部滚动；放不下用同级卡片横向叠层滑动+点开展开模态(iOS 照片合并样式、分页点 n/m、PC 箭头拖拽/手机 swipe、禁横滑套横滑)；断点 1280/1440/1920 + iPhone 390×844；主 CTA 每屏唯一、触控≥44px、图标必带文字标签、reduced-motion 降级。
5. 载体分工：**采集数据表格沿用既有专业模板不卡片化**；只有卡片/KPI/趋势图用新风格。
6. 导航定版：ZBMP=Overview/Brand/Content/KOS/Competition/Risk/Reports(Growth 并入 Overview+Brand Tab，Competition 独立)；CTH=Overview/Real-time/Events/Risk/Xiaohongshu/Reports(199 品牌/9 业态做 Overview Tab+Real-time 筛选器)；SYSTEM=Runtime/Collector/AI/Database/Security/Settings；全局产品切换器。
7. 账户 UI：Apple ID 式——1 主+3 管理+5 子、受信任设备行列表、ZBMP TOTP(扫码绑 iCloud 钥匙串、30s 6 位、one-time-code 自动填充)、CTH 账号密码(改密验原密码)、SYSTEM 敏感操作二次确认；v4 认证并入主线放设置，不独立占导航。
8. 设置：8 分区；设置本身双域隔离(CTH 设置不见 ZBMP)；栏目可显隐/排序/重命名/恢复默认；Skill/Agent 统一收进设置按需启用(少量快捷入口、不选不加载)；运行逻辑/功能说明/使用详解/域名接入/开发者功能统一进 设置-关于系统/开发者。
9. 形态：A3 3D 机器人改为轻量 AI 助手入口(只留问答)；D1 播客模块前端补回、资料不丢。
10. 函数驱动动态可视化：ui_view_model 接入，后端函数实时驱动 KPI/趋势/状态/实时刷新，禁 Mock/写死/假成功；前后端字段契约一致；六态对应后端真实状态。
11. 内置 AI 浏览器：采集在系统内部浏览器完成；页面不擅自跳出系统，外跳需使用者确认。
12. 增量适配不大重构、不抄袭、全部自研；素材手法融会贯通但序境旧 UI 与 2 分钟录屏已废弃不回看。
13. 标准用名（详见 PRODUCT_TERMINOLOGY_I18N_LINEARICON_V1.0）：面向用户界面**不得出现 ZBC/OSAI/SYS 等内部代号**，统一用序境LUMENIS/品牌智能/太古汇智能/系统等标准用名，技术态字符串不外露。
14. 线性图标：全站导航/功能图标统一 outline 线性（24px 网格、1.5px 描边、圆角端点），禁止实心填充块（小红书实心红块改线性），图标必带文字标签、不混多套风格。
15. 中英韩三语 i18n：zh-CN/en/ko 三套词条、可见文案走 t(key) 不硬编码、设置-外观切换默认中文、整页即时生效不混排；韩文复用三语库并母语校对，不机翻硬编、缺失回退中文并记 missing。
