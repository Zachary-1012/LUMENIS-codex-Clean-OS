## 0. User problem and invariant

- User job: inspect an AI analysis thread and trace each claim to a real returned Evidence anchor.
- No source anchor means uncertainty; the screen never fabricates a citation, case, owner or action.
- AI-03 owns a read-only thread inspector. CTH/BMP own business facts and Shared Evidence owns provenance.
- The source-first thread plus citation inspector is specific to this page and is not a generic chat layout.

## 1. Route and fields

- Read route: `GET /api/experience/screen/AI-03` via `CoreAi03Repository`.
- Current response can expose `thread` / `messages`, `binding`, `generated_at`, `source`, `bound` and safe citation fields.
- Create case, assign owner, approve or publish actions have no verified callable here and are absent.

| Field | Safe allowlist |
| --- | --- |
| Speaker | user/system/assistant normalized |
| Message | bounded text without path, URL, token, provider or model leakage |
| Citation | Only a nested server-provided canonical Evidence v2 record with a safe `evidence_id` and known `type` |
| Citation context | Evidence `scope/context` must exactly match the current `GLOBAL_ALL` or `FOCUS` context; cross-Subject/BrandFocus records are omitted |
| Citation read decision | `permission.read=true`, `permission.decision=ALLOW`, and `read_allowed=true` are required |
| Citation lineage/integrity | Non-empty typed `lineage` with `lineage_verified=true`, plus verified Evidence v2 integrity metadata and digest |
| Citation title/passage | bounded safe text from the accepted Evidence record; absent remains absent |

Bare/legacy IDs, fabricated regex-valid IDs, v1 records, missing read decisions, cross-scope records, and records without integrity are not citations and never become trusted source anchors.

## 2. States and recovery

| State | Meaning | Action |
| --- | --- | --- |
| Loading | thread read pending | Wait |
| Unbound / empty | no usable thread contract or no returned entries | Show uncertainty; no empty-to-success inference |
| Thread with citations | inspect a returned citation | Select citation locally |
| Thread without citations | conclusion has no anchor | Keep source warning visible |
| Offline / 401 / 403 / malformed | read cannot be trusted | Retry/return; no fabricated thread |

- Reduced motion does not hide source state. Focus restoration returns to the selected citation after refresh where the ID still exists.
