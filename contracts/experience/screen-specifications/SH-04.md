## 1. Product invariant and scope



SH-04 is an output queue and artifact inspector. It does not create a fake export, download a path that was never persisted, or treat a report listing as proof that an artifact can be reopened. Exact scope, Evidence/source count and persistence are part of the artifact contract.



The current App consumer uses the existing SavedWork service. The legacy screen envelope remains a rejected compatibility path when it lacks scope/permission/projection; no synthetic projection or approval is constructed. This binding does not establish full-product or native acceptance.



## 2. Binding and response contract



- `GET /api/experience/saved-work`: actual items contain `artifact`, immutable `document` and `return_ref`. Preserve `has_more`, opaque `next_cursor`, `unverified_candidates`, and `verification_complete` separately from item count.

- FOCUS reads only the selected domain and exact focus. Default GLOBAL reads existing CTH/BMP domains independently through server Permission; no mandatory selector, fabricated Subject or combined authorization. A failed domain keeps a partial-read notice. The present service enumerates exact GLOBAL records, not every focused record; full-universe discovery remains an OPEN C5/C6 dependency.

- Validate schema, Artifact/hash, work/version/parent and the returned record context. A list row is not a committed reopen receipt. Titles/body are content, not internal diagnostics, and are rendered as inert text without arbitrary path/HTML execution.

- `GET /api/experience/saved-work/{artifact_id}` revalidates original source rights, version chain and committed bytes. Only its matching receipt admits readable detail, source inspection and download controls.

- `GET /api/experience/saved-work/{artifact_id}/export?format=...` performs the existing DATA_EXPORT gate plus pre/post conversion source authorization. Supported bound formats are JSON, Markdown, TXT, DOCX, PDF and XLSX; CSV/PPT remain unbound requirements, never presented as working formats.

- Download validates returned MIME, nonempty content and source Artifact/hash headers. Browser acknowledgement means download requested, not final disk-write proof. Exact downloaded bytes are independently checked in actual acceptance.

- Original task navigation cannot be inferred from a title/kind: current return_ref has work/version/scope but no originating route. Preserve this as OPEN for the existing owner resolver. Parent version reads are independent authorization calls and must match work, version and expected parent hash.



## 3. Responsive information architecture



- Web/Desktop width at least 920 logical pixels and ordinary text scaling: a compact result list beside a bounded reading pane. Search and retry stay at the edge; full document text scrolls inside its pane. No tall explanatory hero or developer state dashboard.

- Narrow Web/Mobile and enlarged text: result list 鈫?selected reading page 鈫?return to list. Sources/details and download format menus disclose on demand. Preserve selection and page position where valid; no stacked full-list plus full-document page.

- Every control has text/tooltip, keyboard focus and non-color state. Native Windows/macOS/iOS verification remains later evidence, not inferred from browser resizing.

## 6. Accessibility and localization



- State, exact range, format and reopenability are announced as text and not by color alone.

- Preview content is rendered as inert text; no HTML or path is interpreted.

- Reading content, title, sources and both compared versions use the existing

  Flutter selection region with ordinary text semantics. They remain selectable

  and copyable, and must not be exposed as empty disabled form fields.

- The result list and reading pane use the current light/dark surface tone at

  90% and 97% opacity respectively, so a vivid user wallpaper does not compete

  with long-form reading. The surrounding workspace retains the user backdrop.

- At 390px and 200% type, both normal fresh-read and failure states must fit;

  controls wrap without clipping, and long documents scroll inside the reader.

- The title uses existing `screen.SH-04` keys in zh-CN, en and ko.

- Error copy hides raw ids, paths, provider information and diagnostics.
