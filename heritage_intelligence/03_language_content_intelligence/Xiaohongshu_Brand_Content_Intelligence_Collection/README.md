# Xiaohongshu Brand Content Intelligence Collection

Status: `HERITAGE KNOWLEDGE / CONTENT PRODUCTION RESEARCH`

## Purpose

本 Collection 用于沉淀小红书品牌内容、商业体内容、会员内容、活动内容、视频笔记与情绪型内容的语言结构、叙事机制、内容生产方法和评估标准。

它是 **Content Intelligence / Content Production 的知识资产**，不是直接替代 Production Truth 的运行时逻辑，也不是把历史文案机械套模版。

## Primary corpus

首批语料由项目负责人于 2026-09-09 提供，覆盖 12 类真实内容样本（编号 2–13），主要场景包括：

- 香氛/新品种草；
- 周年 UGC 征集与互动；
- 七夕节日礼遇；
- 时尚甄选；
- 高端会员权益；
- 度假/穿搭情绪视频；
- 周年主题展览；
- 会员空间体验；
- 情绪疗愈型内容；
- 品牌/文化伙伴周年共创；
- 周年礼遇总览；
- 建筑/艺术主题视频叙事。

原则：**学习结构、语言张力、内容机制与场景适配，不复制原句，不把单篇样本当模板。**

## Core insight

这一批内容的共同优势不是“辞藻华丽”，而是：

```text
具体场景 / 事件
→ 人的感受
→ 可被想象的细节
→ 品牌/空间价值自然出现
→ 事实与权益落地
→ 轻互动或行动入口
```

优质内容不从“品牌要说什么”起笔，而从“用户此刻会感到什么、看到什么、记住什么”进入。

## Content families

### A. Product / Sensory Seeding
适用于香氛、美妆、服饰、餐饮、家居等。

结构：
`感官入口 → 单品差异 → 场景想象 → 到店/体验信息 → 轻互动`

重点：把成分、材质、香调、设计语言翻译成可感知体验，而不是参数罗列。

### B. Event / Campaign Narrative
适用于周年、节日、展览、快闪、主题活动。

结构：
`时间/事件锚点 → 集体记忆或当下情绪 → 活动价值 → 参与方式 → 时间地点`

重点：活动信息必须完整，但不能从活动细则起笔。

### C. Membership / Premium Service
适用于会员中心、积分权益、高端礼遇。

结构：
`生活方式价值 → 具体权益/空间 → 使用场景 → 身份感但不炫耀 → 明确入口`

重点：高端感来自“克制、细节、被照顾感”，不是堆叠“尊贵/奢华/臻享”。

### D. Emotional / Cultural Content
适用于情绪、文化、艺术、城市记忆、品牌共创。

结构：
`情绪命题 → 日常细节/文化记忆 → 价值回响 → 品牌只做承载者 → 留白`

重点：少讲大道理，让事件与物件承担隐喻。

### E. Video Note Narrative
视频笔记文案更需要：
`第一句定调 → 视觉节奏句 → 少量解释 → 结尾落点`

避免把图文笔记整段搬到视频字幕或配文中。

## Use in LUMENIS

未来可被以下能力定向检索使用：

```text
Content Task
→ Content Domain Retrieval
→ Scene Classification
→ Style DNA Retrieval
→ Facts / Campaign Constraints
→ Draft
→ Rubric Evaluation
→ Revision
→ Human Approval / Publish
```

禁止：
- 直接把历史样本作为新文案输出；
- 用固定句式批量换词；
- 因“高级感”牺牲活动事实、时间、门店、礼遇与参与规则；
- 让 AI 生成不可核验的品牌/活动信息；
- 把平台热点词硬塞进品牌语境。

## Promotion gate

本知识进入实际 Content Agent / Skill 前必须：

`Heritage Retrieval → Current Brief → Fact Contract → Draft → Evaluation → Human Approval → Evidence`

原则：**不是让 AI 学会“像某篇文案”，而是让 AI 学会“为什么这类内容成立”。**
