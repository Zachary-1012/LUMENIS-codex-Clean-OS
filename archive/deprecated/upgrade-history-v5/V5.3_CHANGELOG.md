# v5.3.0 更新说明

## 本次定位
- 系统名称固定为：**广州太古汇·舆情监测系统**。
- 本版本重点为网页 UI/交互升级，不改变“广州太古汇主体过滤优先、小红书为主平台、全网发现作为底层辅助”的产品定位。

## UI
- 恢复第一版清晰的左侧导航与首页模块分布。
- 保留情感分布、风险等级分布、内容分类、风险预警、舆情日历等核心模块。
- 采用 iOS / Apple 风格的留白、圆角、玻璃质感、轻阴影、渐进展开与抽屉详情。
- 所有主要模块增加 hover / tap 提示、按压反馈、平滑滚动、抽屉过渡、Toast 状态反馈。
- 手机端自动切换为横向导航与单列布局。

## 热门话题
- 新增 `/api/hot-topics`。
- 热门话题不再只展示负面舆情，正面、中性、负面均保留。
- 每个话题可直接打开小红书搜索：`广州太古汇 + 话题`。
- 话题颜色仅表示方向，不表示风险等级。

## 后端
- 版本号更新至 5.3.0。
- 增加热门话题聚合接口与数据库函数。
- 不修改既有 notes / web_mentions / events 的核心数据结构。
- 数据库继续使用启动时自动迁移机制。

## 安全/升级原则
- **不要用新包中的 data 文件覆盖公司电脑原有 data/monitor.db。**
- 升级前先执行数据库备份。
- 远程 5G 使用时务必启用 Basic Auth，再启动 Cloudflare Quick Tunnel。
