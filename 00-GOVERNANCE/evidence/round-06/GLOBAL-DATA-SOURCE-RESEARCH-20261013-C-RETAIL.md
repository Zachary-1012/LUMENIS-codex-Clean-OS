- 研究项目：序境/LUMENIS 全球数据源研究（External Data 层）
- 研究员：子研究员 C（全球商业运营与零售数据）
- 验证日期：2026-10-13
- 方法：browser.search / browser.open 逐条核验官方入口；每个 URL 均经实际检索或打开验证，未核实的不写、不编。
- PO 授权备注：2026-10-13 PO 授权允许在获准范围内使用 REA 对目标网站做逆向推理（仅理解公开平台数据结构与访问机制，不绕过登录/付费/风控/隐私）。本轮为 External Data 编目阶段，浏览器核验已能确立 URL、字段结构与访问条件，故以浏览器核验为主；进入采集实施阶段后，可对 data.stats.gov.cn 查询接口、各商场官网 JS 数据接口等目标启用 REA 做机制级解析。

## 可用性分层定义

- VERIFIED_PUBLIC：已通过 browser.open/search 实际验证可公开访问
- VERIFIED_AUTHORIZED：已验证，需授权/账号后可访问（本轮无）
- CONDITIONAL：官方入口已识别但本次未能完全确认加载，或需简单条件（如注册开发者 Key）
- RESTRICTED：企业级付费/询价，公开渠道无法获取数据
- NOT VERIFIED：未能核实官方入口
- SUPERSEDED：已被替代（本轮无）

## 最重要的发现与缺口

1. **标杆商场官网是 CTH 最直接的一手 External Data，但结构化程度分化严重**：香港 ifc 的商户 PDF（含铺位号-电话-营业时间三元组）与 Apple 的 sitemap+逐店页是"金标准"；多数商场官网为营销型页面，品牌清单需逐站解析。这是采集模板设计的首要输入。
2. **国际五大行中国研究全部免费公开，是业态与商圈数据的最佳公开来源**：Savills/CBRE/JLL/戴德梁行均发布季度/年度零售报告，含城市空置率、租金、新增供应、业态开店增速等硬指标（如戴德梁行 15 城中高端商场空置率 11.2%），且口径透明可交叉验证。
3. **客流数据是最大缺口**：Placer.ai（美国为主、中国覆盖未证实）与 ShopperTrak（Sensormatic）均为企业级付费，中国大陆公开的商场级客流数据几乎空白；短期只能依赖各地商务局发布的商圈客流转引数据（如赢商网转引的北京国庆 70 商圈 6035 万人次）。
4. **政府统计免费但颗粒度止于省/业态级**：国家统计局社零数据（2026年1–8月 327569 亿元，+1.1%）是法定基准，但无法下钻到商场/门店；data.stats.gov.cn 查询接口可在 REA 授权下做机制解析以实现程序化拉取。
5. **高德 POI 官方 API 是门店级批量采集的最优程序化路径**：lbs.amap.com 经核验真实存在，返回字段含名称、地址、电话、分类与坐标；建议作为主通道立项，先申请 Key 验证配额后按"品牌×城市"矩阵拉取。
