#### 2.2 6场景公关回复话术公式（录入案例库，专报应对策略可调用）
| 场景 | 回复公式 | 禁忌 |
|---|---|---|
| 服务态度/歧视 | 共情致歉→强调平等尊重→涉事人员处理→全员培训承诺 | 不说"个人行为与商场无关"；不辩解"顾客也有问题" |
| 活动安全/秩序 | 致歉→承认预判不足→受伤顾客跟进→人流管控整改方案 | 不甩锅顾客；不隐瞒受伤 |
| 食品安全/卫生 | 致歉→立即停业下架→全额退款→超预期补偿→全门店排查 | 不先说"外部入侵"；不只道歉不补偿 |
| 内容/物料争议 | 当天撤除→承认审核疏漏→致歉→全流程复盘→完善审核机制 | 不辩解"只是创意"；不拖延撤除 |
| 价格/规则争议 | 致歉→重新核查→退还不合理费用→优化规则公示 | 不嘲讽顾客；不拿"最终解释权"压人 |
| 不实信息/抹黑 | 感谢关注→客观陈述事实(附凭证)→欢迎私信核实→持续改进 | 不报警威胁；不扣帽子；不删评 |

#### 2.3 ACT 通用回复法则
- A（Acknowledge 承认）：不回避，先共情致歉
- C（Communicate 沟通）：说明已采取动作和核查进度
- T（Transform 转化）：给出可检验整改方案，危机转改进契机
→ 集成到 AI 专报应对策略生成 prompt，作为输出结构约束

#### 2.4 日报模板对齐（一页纸结构）
daily_report.py 输出需包含：
1. 一句话概览：今日监测X条/负面X条/最高互动X/核心话题XX/等级🟢🟡🔴
2. 数据速览：总提及/负面/负面占比/最高互动/环比±%
3. 负面TOP3：业态-笔记摘要-互动-状态
4. 今日动作：已处理/待跟进(责任人·时限)/预警
5. 专报触发条件标注（满足任一即升级）

#### 2.5 专报触发条件对齐（risk_engine + daily_report）
5个触发条件（满足任一即升级专报）：
1. 单条负面互动 ≥ 500（注意：现有 risk_engine 是 >50000 升级 high，需新增专报触发线 500）
2. 负面帖 ≥ 3 条集中爆发
3. 涉及安全·歧视·违法（关键词+subject_rules联动）
4. 本地 KOC 转发（kos_profiles 联动）
5. 集团或媒体问询（人工标记触发）

#### 2.6 模块联动机制
- 专报生成时：自动按场景分类匹配案例库 2-3 个同类案例编号，引用处置方式和恢复周期
- 事件处置完成：本次事件可作为新案例（C-16起）录入案例库
- 季度复盘：更新案例库"对太古汇启示"，优化话术库
- 案例库场景分类与 risk_engine 风险类型映射
