- an isolated disposable database selected by the canonical `ZBC_DB_PATH` override;

### END-TO-END PATH

1. Launch the local Product Core against the isolated database.
2. Launch the current Windows Desktop binary from current source.
3. Core transport bootstrap and runtime identity enter the workspace without a product-account wall.
4. Navigate to SYSTEM / SYS-01. Subject/BrandFocus selection is `N/A`: SYSTEM infrastructure is neither CTH Subject-first nor BMP Brand/Market-first, and the test must not fabricate a business context.
5. Flutter calls `GET /api/experience/screen/SYS-01`; Product Core delegates to the current SYSTEM runtime owner.
6. The page shows a real runtime result plus source, observation time, trace identifier and read-only boundary.
7. Refresh re-reads the current observation.
8. Stop or make Core unavailable, verify an honest unavailable state, restore Core and use the visible retry/reconnect path.
