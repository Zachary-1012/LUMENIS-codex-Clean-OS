# Research / OSS
Use current authoritative sources, Exa/web, and GitHub implementation evidence. Before adding a dependency, prove a capability gap, verify license/notice obligations, record it in the canonical third-party register, and keep it behind a bounded adapter where practical. Research may improve an existing owner; it must not create a parallel product architecture.
