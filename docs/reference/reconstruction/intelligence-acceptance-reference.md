## 3. 样本、真值与误差：比“跑完多少条”更重要

1. **任务单元独立且预先冻结。** 测试前写明用户问题、允许来源/权限/时点、必要结果、保留对象、成功和失败条件、时间/资源预算。不能在看完答案后由执行agent改验收目标。固定公开基准按其实际版本/切分/方法报告；本产品扩展集另报，不能把自改题目成绩挂原榜单名。
2. **分层抽样而非只挑漂亮案例。** 按品牌/商业/研究/内容任务、中文/中英混合、来源类型、新旧信息、长短材料、模态、客户权限与任务长度覆盖。原产品的独立创作、视频/播客、无AI路径和AI增强各自验收，不能拿中文研究成绩替代全部能力。公开可见样本不是随机总体，不随意套总体置信区间。
3. **严格时间与事件隔离。** 开发集和封存验证集按客户/项目/事件/时间分组，去除近重复而不只去同hash文件；先固定资料截至时间，再测之后的更正和新任务。旧公开基准可能已进入预训练，需另有后来产生且获授权的真实保留集。测试集不进提示范例、检索知识、记忆/策略更新或训练；修复后保留原失败记录，以新封存变体验证泛化。
4. **独立人工复核，自动评分只辅助。** 两名合适专业复核者盲看混排输出，按具体事实/操作/范围判定并保分歧及裁定；需要中文行业语境者由能理解该业务的人复核。对数值/格式/对象范围用确定性检查辅助；评价模型如使用，需独立校准对人评的错误和分层偏差，不允许生成者自评为唯一依据。没有现实专业评审资源时如实未验，不让另一个agent冒充行业专家已签收。
5. **报告分母、失败和不确定性。** 每项报告样本数、适用范围、失败/放弃/外部阻塞、重复运行与资源预算。成功率给置信区间，时长给中位/P95和未完成比例；不能将超时/权限失败样本从分母悄悄移除，必要时同时报告全部任务和条件可执行子集。聚类任务使用按事件/客户分组的误差估计，不能把同一帖100条评论当100个独立案例。
6. **零观测错误不是零风险。** 对独立同分布二项样本，n次零失败的一侧95%失败率上界是 `1−0.05^(1/n)`；例如n=299约0.997%。这是统计说明，**不是宣布本产品要用299条就合格**，更不适用于明显相关/选择偏差的开放样本。硬约束仍要求所测路径无越权、无静默丢失、无未授权外部动作；发现一次就修复受影响路径。
7. **比较净工作量与结果。** 用同真实输入、同交付要求、同时间/资源条件，比较旧有效路径/人工专业工作方式与改进路径；包括收集、核查、改错、导出、重开、维护和客户返修耗时。只缩短初稿生成但增加复核修复不算收益；同模型的公开分数不能代表整个产品比用户现有工具更省力。

## 4. 监测时效和覆盖的具体口径

这部分是**产品自定义且必须预先公布的服务指标**，没有伪造外部认证门槛：

- 分别保存事件发生/源发布时间、首次可观察时间（若可核）、首次发现时间、最后成功检查、通知时间。源发布时间未知/被改写时保持未知，不伪造精确“发现延迟”；至少报告从已知观察点到发现的区间。
- 已知测试源的事件召回 = 在观察窗口内被发现的应发现事件 / 该范围预先标注的应发现事件。结果还要报告未检查来源与未完成分页。未知公开总体只能报样本覆盖，不能拿“自己抓到的全部”作分母证明100%。
- 发现延迟按已知发生/可见时间定义；若到测试结束仍未发现，记漏检或删失，不能只给已发现部分的漂亮P95。检查执行可靠度和业务事件发现效果分开。
- 语义变化用人工标注的事实/主张/事件变化比对；页面hash只说明字节变化，广告/时间戳抖动不是舆情信号；hash不变也不能代替没读完的分页、评论和媒体。
- 条件约定包含用户选择的时段、频率、来源实际限制和权威Worker运行条件。没有检查、检查失败、权限失效、未发现变化四种状态不可混淆。手机/Windows/Web UI关闭与权威Worker是否运行按真实部署分别判断。
- 通知质量用需处理事件的检出与误报、重复提醒、实际决策帮助核查；不以通知数量作进度。响应SLA与发现SLA分别定义；客户/值班人一小时回复目标不能冒全天一小时发现承诺。

## 5. 进入现行验收的方式

不建立第二套管理或评分体系。把上表具体测量写回对应现有能力的完成条件：适用ASVS安全断言、引用/反证/中文与模态分项、真实浏览采集结果、版本与局部修改保全、故障恢复、监测覆盖/时效、独立复核后的业务结果。门槛在测试前按任务风险和可接受返工定好；不得虚构“行业统一95分”或任意权重的专业分。

公开基准成绩必须注明同版数据/脚本、配置、样本范围、模型和运行条件，未运行就写未运行；只有同条件可比较的结果才能支持相应维度的相对结论。领先声明还需真实工作对照与独立专业评审，不能由agent口头评9分、自签PASS、源码存在、截图、健康检查或hash替代。

hash仍可用于锁定输入、导出版本、检查字节完整性与定位差异，**它不能证明事实正确、引用支持、画面好看、公式正确、声音可听、监测抓全或用户工作完成**。标准/框架提供约束，基准提供有界对照，完整用户工作提供最终可交付证据；三者分别保留，不互相替代。
