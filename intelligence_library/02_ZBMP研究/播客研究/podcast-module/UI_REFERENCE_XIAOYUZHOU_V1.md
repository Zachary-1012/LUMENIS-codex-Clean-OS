# Xiaoyuzhou UX Reference V1

## Evidence

The current App Store listing describes Xiaoyuzhou as a podcast-specific app with discovery, high-energy likes, discussion, listening-time tracking, search and subscription import; the listing also notes voice dynamics/comments and video playback for some shows. Independent product analyses identify compact primary navigation, a persistent player bar, episode detail, comment timestamping and timeline high-energy markers as core interaction patterns.

## What we borrow

- Persistent player continuity.
- Timeline as an interaction surface, not decoration.
- Timestamp-linked comments/annotations.
- Compact primary navigation.
- Episode-first information architecture.
- Fast jump from comment/marker to audio position.
- Discovery driven by content units and user signals.

## What we do not borrow

- Consumer social feed as the main workspace.
- Xiaoyuzhou colors, typography or branded visual identity.
- Any proprietary implementation.
- Unverified assumptions about private/internal ranking algorithms.

## ZBC transformation

Timestamp comment → editorial annotation + evidence link.

High-energy marker → observed audience marker + separate AI story/insight marker.

Episode page → research/production workspace.

Profile → person dossier + interview history + story/problem graph.

Discovery → benchmark/research discovery.

Listening history → production/consumption history.

## Design principle

Borrow the interaction logic where it reduces cognitive load; keep ZBC's established visual system and evidence-first information hierarchy.
