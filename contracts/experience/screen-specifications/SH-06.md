## 1. Product invariant and scope

SH-06 is a read-only operational inbox with distinct lanes for tasks, notifications and alerts. It reports the state of verified work items; it does not create approval, assignment, snooze, retry or other external effects from a card. Every item must carry verified origin and exact range confirmation.

The current task/notification builder exposes global operational records without a verified actor-bound range. The App therefore refuses the legacy shape and does not show unscoped queue data, task totals or raw operational identifiers.

## 2. Binding and response contract

| UI region | Required runtime value | App behavior |
| --- | --- | --- |
| Inbox range | `GLOBAL_ALL` or exact `FOCUS` range plus read authorization | Show business range; hide raw focus id |
| Task lane | `data.tasks[]` or typed items with task kind | Show title, priority, state, due time, origin and evidence link state |
| Notification lane | `data.notifications[]` or typed items with notification kind | Show operational notification state |
| Alert lane | `data.alerts[]` or typed items with alert kind | Preserve blocked/high-priority state; do not turn it into success |
| Origin/evidence gate | `origin_verified`/`source_verified`, `scope_verified`/`scope_confirmed` and `evidence_linked`/`trace_available` | Drop items that cannot prove origin, exact range and Evidence linkage |
| Existing route | `GET /api/experience/screen/SH-06` | Current global task/DLQ/health shape is blocked |

Operational state remains explicit: ready, partial, offline and unconfirmed are not interchangeable. Missing due time or evidence link remains missing. Every item needs canonical row scope, row read permission, Evidence linkage, and verified lineage/integrity. A `GLOBAL_ALL` envelope rejects an item explicitly scoped to a focus; an exact FOCUS envelope accepts only the matching active item scope.

## 3. Responsive information architecture

### Desktop (available width ≥1120 logical px)

- Task, notification and alert lanes form separate filterable regions.
- A selected-item inspector shows source, timing, state and evidence-link status.

### Intermediate width (760–1119 logical px)

- Priority and state labels remain visible without relying on color.

### Mobile (available width <760 logical px)

- Keep the selected lane/list before the selected item's detail in the mobile flow. Opening a detail and returning preserves the lane, filters and selected item; an absent or withdrawn item is explained without silently changing scope.
- Selection is local; no approval/snooze/assignment control is rendered.

## 4. State and recovery

| State | Meaning | Behavior |
| --- | --- | --- |
| Loading | Inbox response is pending | Live loading status; no stale items |
| Ready | Scope, read authorization and item origin are verified | Render the selected lane and detail |
| Empty | Verified lane has no items | Explain the lane is empty; do not invent work |
| Scope unavailable/denied | Range/permission is absent | “通知与待办暂不显示”; no items or totals |
| Authentication/offline/invalid | Core recovery or response problem | Safe retry; no raw diagnostics |
| Blocked item | Real blocked/failed state | Preserve blocked state and explain it; do not mark complete |

## 5. Actions and effects

已批准闭环目标：接收AI-01/原任务的真实完成、重要失败和待确认条目；普通后台进度可查但不重复推送。投递绑定actor/可见范围/task/结果版本与去重键，回执失败只恢复通知，不重跑业务。打开回到原成果并保留草稿，群内不得暴露私聊或其他scope资料。当前read-only投影之外未接线动作保持OPEN；不改变本页已有禁止直接产生业务效果的边界。
