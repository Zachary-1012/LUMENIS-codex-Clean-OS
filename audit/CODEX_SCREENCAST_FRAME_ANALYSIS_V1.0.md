## 二、提取的设计模式（序境适配版）

### 2.1 设置框架（SYSTEM/Settings + ZBMP/CTH 各自设置）
- 左栏固定约 240px：返回 + 搜索框 + 分组（分组名=11px 灰色大写感小字），项=线性图标 16px + 13px 文字，选中=浅灰圆角 8px 背景；外链项右侧 ↗
- 主区域最大宽度约 720px，**不放页面大标题（用户明令）**，直接呈现分组卡片
- 分组卡片：圆角 12-16px、细边框/极浅底、内部分行；组间留白 32-40px
- 设置行：左=名称 13-14px medium + 下一行 11-12px 灰色描述；右=控件；行间细分割线或 12px 留白

### 2.2 控件库（全部组件化，全站统一）
| 控件 | 形态 |
|---|---|
| 开关 | iOS 风 40×24 胶囊，开=序境主色（非系统蓝），关=#D1D5DB |
| 下拉 | 白底圆角 8px 细边框 + chevron；浮层=白底圆角 12px 阴影，选项=主文字+灰色说明+选中✓ |
| 滑块 | 主色轨道 + 黑色/主色圆点 + 右侧数值 |
| 文本框 | 浅灰底圆角 8px，focus 主色细环 |
| 胶囊按钮（次） | 浅灰底 #F3F4F6、深灰字、圆角 8px：管理/更改/清除/导入 |
| 主按钮 | 黑底白字（序境改为主色底）：添加/保存 |
| 危险按钮 | 红字或浅红底红字：删除 |
| 计数 Tab | 「名称 N」灰色数字计数，选中下划线/加粗 |
| 快捷键胶囊 | 浅灰底圆角 6px、等宽字体、Ctrl+K 样式 |
| 加载 | 线性转圈 + "正在加载…"；骨架屏=灰条动画（PR 列表） |
| 空状态 | 居中线性图标 + 一句引导 |

### 2.3 列表行模式（Skill/插件/宠物/账号成员/浏览器引擎通用）
- 行=左 32-40px 圆角彩色图标（内容类用品牌轻色底+线性/微立体图标，不用花哨渐变铺底）+ 中=名称 13-14px + 描述 11-12px 灰 + 右=开关/按钮/三点
- hover：行底变浅灰 + 右侧浮现「…」更多操作
- 选中态：「选择」→「已选」灰底

### 2.4 新对话/工作台首页模式（A3 轻助手 + Intelligence 入口适配）
- 居中问候/提问标题（仅首页允许，设置/业务页禁止大标题）
- 4 张快捷能力卡片横/网格：线性图标+标题+一句说明
- 底部输入条：左上下文标签（当前项目/域）+ 输入区 + 右权限状态 + 模型选择 + 发送
- 右下角轻量 AI 助手球（A3：废弃 3D 机器人，仅问答）

### 2.5 已安排任务模式（Runtime/Scheduler 适配）
- 建议/计划任务行：彩色小图标 + 名称 + 周期时间（工作日 08:00 灰字）+ 描述 + 启用操作

### 2.6 外观设置适配（主题中心）
- 三主题预览卡：浅色/深色/跟随系统，用序境真实界面缩略 mockup，选中=主色/黑 1.5px 边框
- 主题配置：强调色（序境品牌色，芥子纳须弥色系，不用 OpenAI 绿）、背景/前景色值胶囊、字体（Inter+Noto Sans SC，字重常规不粗不细）、字号 px 数值、半透明侧边栏开关、对比度滑块、减少动态效果（对应 reduced-motion 降级）

## 三、与既有序境 token 的映射（不另起 Design System）
- 圆角：卡片 16px / 控件 8-12px / 弹窗 24px（沿用 zbc-design-v1.1）
- 色彩：ZBMP 青绿 #0F766E→#14B8A6、CTH 蓝 #2563EB→#60A5FA、SYSTEM 紫 #7C3AED→#A78BFA，芥子金 #C9A961 极低频；彩色只出现在图标/进度/图表/选中态，不整面铺
- 字体：Inter + Noto Sans SC；H2 17/600、H3 15/600、名称 13-14、描述 11-12、数据 24-32/700
- 毛玻璃：rgba(255,255,255,.6-.8)+blur(20px) 仅浮层/侧栏
- No-Scroll：PC 100dvh、移动端 safe-area；同级卡片横向叠层滑动+点开展开模态

## 四、禁止项（用户口径）
- 禁止页面大标题（首页/新对话除外）
- 禁止大铺面、整页花哨渐变、旧 UI 回潮
- 禁止 Mock/假数据/死按钮；所有控件必须接真实 API（函数驱动）
- 禁止把 Codex 文案/英文结构原样照抄，只取布局与交互模式，文案走中英韩三语+标准用名（去内部代号）
