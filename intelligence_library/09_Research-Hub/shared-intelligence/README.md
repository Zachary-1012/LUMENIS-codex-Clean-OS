# Shared research materials

本目录保存已经积累的研究、案例与实测证据，不承担产品执行路由、工作窗口调度或发布授权。当前研发只读取仓库根 `AGENTS.md` 及其链接的原有产品、体验、Owner和机器合同。

## 原有材料入口

| 材料 | 用途 |
|---|---|
| `research/` | 原研究问题、分析、技术方案与核验记录；按对应来源、时间和适用范围阅读。 |
| `research/content-intelligence/` | 内容理解与制作案例，关联原任务和实际消费者后判断采用。 |
| `CASE-LIBRARY.md` | 案例组织与研究主题参考。 |
| `docs/M5-FULL-INTEGRATION-STATUS-20260901.md` | 对应日期的集成证据，不能充当当前产品运行状态。 |
| `docs/M5-ACCELERATED-FULL-INTEGRATION-STATUS-20260902.md` | 对应日期的实施与核验记录，仍须回到当前源码判断是否适用。 |

原研究记录、结果、失败和来源保留，已撤回的旧三仓库总控、固定九阶段、固定巡检时刻、只增不减和一律立即推送等执行文件从工作副本中移除。不在这里复刻替代规则；需要复核变更过程时查看对应Git提交。

采用研究时沿原Source Owner记录材料版本、适用条件、实际实现及成果验证；研究观点、样例、原作者描述和历史PASS均不自动成为当前生产事实、权限或用户验收结论。
