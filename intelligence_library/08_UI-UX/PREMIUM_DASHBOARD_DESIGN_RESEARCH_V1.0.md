# 高端品牌 Dashboard 设计研究 → ZBC 增量落地清单 V1.0

> 2026-09-06 全网研究 Linear / Stripe / Vercel / Supabase / Mercury / Ramp / Attio / Hex 等 2026 高端 SaaS 与金融看板案例，结合用户9张素材，提炼"精致、灵动、不素不花"的可落地手法。原则：**增量适配，不大重构**。来源见文末。

## 一、高级感的底层共识（Stripe / Linear / Vercel）
1. **强对比 + 聪明留白 + 单色为骨**：结构靠中性灰阶、字重、间距、背景层级表达；**颜色只留给"意义"**（状态/选中/风险/品牌主操作）。Linear：结构一律灰，彩色仅表义。→ ZBC：三域色(ZBMP青/CTH蓝/SYSTEM紫)与语义色(红橙黄绿)只出现在状态、选中、风险、主CTA；分隔优先用留白和背景深浅，少画硬边框。
2. **克制即自信（restraint reads as confidence）**：不堆满、不每处都高亮；calm 单指标聚焦（Mercury/Ramp 用一个清晰大数字建立信任）。
3. **锐利排版**：高对比字重阶梯；UI 正文字重取 regular 与 medium 之间（Linear 用 510），不粗不细正合用户要求；ID/编号/数值/Token 用等宽数字或等宽 chip（浅填充+1px ring，不用彩色文字）。

## 二、"精致灵动"的真正分水岭：微状态（重点投入）
- 高端产品把 hover / focus / active / disabled / loading / empty 六态逐个精雕：每态有独立颜色、过渡曲线、手感；输入框有专门设计的 focus ring，按钮有按压反馈。
- ZBC 落地：统一交互 token（duration 150/200/250ms、统一 ease-out、focus ring 2px 品牌色半透、hover 提升一档背景+极轻阴影、active 轻微缩放/压深、disabled 降透明禁交互）；loading 用骨架而非转圈、empty/error/degraded/no_data 各有精致空态。**灵动来自微状态与有意义的过渡，不是堆动画。**

## 三、2026 材质与布局趋势（对应用户素材，克制使用）
1. **玻璃拟态已成熟为"战略性少量"**：只用在 overlay/modal/navbar/浮动工具条/叠层卡这 1–2 层表达深度，**禁止 glass-on-glass、禁止大面积玻璃内容面**（与 No-Scroll 契约一致）。
2. **低饱和同色系渐变**营造高级商务感：浅灰→浅蓝/同色系柔和渐变做关键卡背景，必须保证文字对比可读性；深色卡用单色径向光晕+点阵/网格纹理。渐变只在 关键KPI卡/主CTA/数据viz。
3. **从"堆图表"回归优秀表格**：2026 明确趋势是高密度、安静的 chrome + 专业表格；calm 单指标大数字胜过满屏图表。→ 印证用户：**采集数据表格保持既有专业模板，不卡片化**；趋势图只在需要表达趋势处出现。
4. 深色优先适合监控/开发工具（SYSTEM Runtime/AI/Collector），业务工作台(ZBMP/CTH)默认浅色、可切深色。

## 四、ZBC 增量落地清单（在 V1.1 设计系统上叠加，不动骨架）
- [ ] 中性灰阶建结构，三域色/语义色仅表义；分隔用留白与背景层级替代硬边框
- [ ] 全组件补齐六态 + 统一动效/focus token；骨架屏；精致 empty/error/no_data/degraded
- [ ] 关键 KPI：单卡聚焦大数字（整数粗、小数/单位浅）、同色系低饱和渐变、点开展开
- [ ] 同级卡片横向叠层滑动（分页点/第n共m/箭头，点开展开弹层），符合 No-Scroll 2.1
- [ ] 趋势图：渐变面积、分段语义色条+当前位置标记、折线高亮节点；数值等宽
- [ ] 采集数据表格维持原专业模板（排序/筛选/分页/有界内滚），不套卡片渐变
- [ ] 玻璃仅浮层/导航/叠层卡 1–2 层，禁 glass-on-glass；大圆角 16–24、柔多层阴影
- [ ] 浅色暖灰底+极淡光晕、深色墨黑+单色径向光；双主题对比验证可读性
- [ ] 主 CTA 每屏唯一：品牌色渐变胶囊+对比圆箭头；其余操作中性
- [ ] reduced-motion 降级；动效必有触发/起止/可中断，不遮挡内容
- [ ] 所有可见值函数驱动真实来源，缺失 null/—，精致但不造数

## 四点五、ref_dyn 参考帧与14条UI技巧增量（2026-09-06 逐帧，序境旧UI/2分钟录屏已废弃）
- iOS27 液态玻璃：深色通透玻璃卡(模糊+对比调好保证可读)、环形进度中心数值、**设备电量行列表(图标+名+百分比+细电池条+细分割)→用于受信任设备/会话管理**、逐小时时间轴、双主题统一色调。
- 浅色极简：超大标题、**分区极淡底色**区分模块(淡绿/淡蓝/淡紫)、选中实底黑圆、小彩色事件点、底部胶囊工具条。
- 金融数据：暗色超大细数字(整数暗/小数亮)、同色系渐变卡(橄榄绿/赤陶/青紫)、内嵌圆钮CTA、分段语义色条+当前位置标记、荧光细曲线。
- 14条UI技巧固化为组件验收：8pt亲密间距(关联近/无关远)；3:1对比；**每屏单主按钮+主/次/三级权重**；触控≥44px；重要操作别全藏菜单；大字减字距；**不能只靠颜色表义(配图标/文字)**；尽量单一对齐、左对齐为主；只用常规+粗体两级字重(特细/特粗只给大数字大标题)；**极简≠简单，图标必须带文字标签**；Before→After(主按钮实底、标题加粗、分组清晰、留白合理)。
