# LUMENIS Research Library

This directory contains research, source material, benchmarks, design studies, platform intelligence, content intelligence, and reusable learning assets.

Rules:
- Research assets are retained even when production code is retired.
- Research material is non-authoritative for runtime behavior unless a current production contract explicitly adopts it.
- Production code, deprecated implementations, generated audit caches, recovery dumps, and backup copies do not belong here.
- New research should be filed by subject area rather than by migration date or retired repository name.

Top-level areas currently include:
- `content-intelligence/`
- `ui-ux/`
- `intelligence/`
- `research-hub/`
- `podcast/`
- `engineering/`
- `ai-runtime/`
