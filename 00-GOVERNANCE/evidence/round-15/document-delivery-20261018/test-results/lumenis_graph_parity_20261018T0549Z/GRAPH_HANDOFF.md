Booleans, null, invalid strings and nonfinite numbers are rejected. Raw payload remains part of exact approval hash; normalized values only drive inference. No new year cap is imposed. Original route reads JSON fields, not query-window parameters. Identity/scope derive from verified request context; X-Actor-ID is never authority. A server-approved actor/scope and runtime HUMAN_APPROVAL + COMMIT remain required for effect. Preview does not issue approval.

Restore the original title-only common-token heuristic: valid timestamps sorted chronologically; at least one shared title token; parallel when gap <= parallel_hours (including equal timestamps), else within days_window derive for >=3 shared tokens and follow for >=1.
