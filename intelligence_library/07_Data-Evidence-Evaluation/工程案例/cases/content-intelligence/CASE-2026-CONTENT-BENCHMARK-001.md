# Content Intelligence Benchmark 001

## Purpose
建立真实、可追溯、可分类的内容案例池。案例用于研究内容策略，不用于复制固定文案。

## Evidence policy
- A：原始内容/品牌或真人身份/时间/平台/可观察结果齐全
- B：真实运营者或品牌方访谈，有策略与部分结果
- C：行业研究/第三方拆解，可用于假设，不直接作为生产事实
- D：二手营销文章，仅作线索
- AI生成案例不得进入真实案例池

## Case 0001 — 用户真实案例
- Theme：入秋 × 香氛 × 小众香水 × 情绪/Lifestyle
- Strategy：节点 + 治愈 + 气味记忆 + 松弛
- Visual narrative：安静氛围 → 好运彩蛋 → 香氛空间 → 气味记忆
- Lesson：文案必须根据目标、受众、节点、品牌和内容类型动态分类生成，不得模板化。

## Case 0002 — 观夏「和世界玩儿」
- Source quality：A/B boundary；公开第三方数据研究，原始活动与品牌身份可核验，互动数据来自数说故事公开案例
- Source: https://www.datastory.com.cn/details/514
- Platform：小红书等社媒
- Strategy：女性成长/自由想象 + 艺术/文化 + 香氛产品
- Evidence：公开案例称主题活动互动热度超4.1万，#和世界玩儿#浏览53万+；新品浓香水「我」在活动UGC关键词中贡献29%互动量。
- Lesson：产品可以作为价值观叙事的载体，而不是直接产品介绍；UGC可以从品牌主题扩展成用户自己的表达。

## Case 0003 — 观夏内容宇宙 / UGC
- Source quality：B/C；公开行业案例研究
- Sources: https://www.digitaling.com/articles/1329929.html ; https://www.adquan.com/article/350719
- Strategy：东方文化 + 香气 + 艺术 + 生活方式
- Evidence：公开研究称观夏UGC占比85.78%；小红书UGC涉及香薰、香气、礼物、门店、Citywalk、探店、家居、穿搭、日常vlog等。
- Lesson：品类内容可以向场景、生活方式和用户自我表达扩展；内容系统需要支持跨品类语义迁移。

## Case 0004 — 观夏「昆仑煮雪」用户心智
- Source quality：B/C
- Source: https://www.digitaling.com/articles/1329929.html
- Strategy：产品气味 → 记忆 → 人格/生活方式
- Evidence：公开研究提到“昆仑煮雪”与i人、INFP/INFJ等用户自我认同产生关联。
- Lesson：用户UGC可能创造品牌方未预设的新卖点；系统应区分“品牌定义卖点”和“用户生成卖点”。

## Case 0005 — 观夏私域与小红书闭环
- Source quality：C；第三方运营拆解
- Source: https://www.woshipm.com/marketing/5494174.html
- Platform：小红书/私域
- Strategy：内容心智 → 企业号/投放 → 站内或私域转化
- Evidence：公开拆解称企业号存在多篇高互动内容，并分析了小红书店铺与私域承接路径。
- Lesson：内容系统不能只优化互动，还需要支持“传播目标”分类：认知、互动、搜索、转化、私域沉淀。

## Case 0006 — 观夏早期东方香叙事
- Source quality：C
- Source: https://www.digitaling.com/articles/700412.html
- Strategy：东方文化 + 香气故事 + 生活场景
- Lesson：香氛内容可以通过记忆、生活仪式和感官叙事降低“产品硬广感”；但此案例年代较早，不能直接外推当前平台规则。

## Benchmark taxonomy candidates
1. 情绪型：状态/治愈/松弛/共鸣
2. 场景型：Citywalk/探店/家居/通勤/旅行
3. 产品种草型：香调/功能/适用人群/体验
4. 品牌世界观型：文化/艺术/价值观
5. UGC共创型：用户表达/挑战/征集
6. 节点型：节气/季节/节日/社会节点
7. 搜索型：问题解决/清单/攻略
8. 转化型：礼赠/购买决策/门店/会员
9. 热点借势型：热点作为入口，品牌价值保持独立
10. 失败/低效型：后续必须补充，用于反例学习

## Important constraint
这些案例只用于形成“策略候选、分类、Benchmark和研究假设”。不得把任何单一案例的文案、标签、发布时间或互动结果直接复制到新内容；生产输出必须重新根据 ContentContext 计算。
