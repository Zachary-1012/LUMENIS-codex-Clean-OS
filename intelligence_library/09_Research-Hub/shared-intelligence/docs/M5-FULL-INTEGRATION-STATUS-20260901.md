## Full integration completion definition

The integration is complete only when:

1. every in-scope source module has an owner;
2. duplicate authoritative implementations are removed or explicitly retained with a retirement plan;
3. shared capabilities have canonical Contracts and Adapters;
4. Governance has no execution bypass;
5. Execution has no governance bypass;
6. Baseline/Supplement semantics are deterministic and lifecycle-safe;
7. GitHub CI passes the relevant targeted and full suites;
8. contract, integration and regression tests pass with executable evidence;
9. security and migration audits pass;
10. legacy implementations are retired only after equivalence evidence;
11. mobile product verification passes;
12. the end-to-end Learning → Evidence → Capability → Governance → Execution → Result → Learning loop is demonstrated.
