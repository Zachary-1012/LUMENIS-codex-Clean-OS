# Podcast Research Reader

The Research Reader is a focused reading surface, not a dashboard.

## Information hierarchy

1. Executive conclusion
2. Key findings
3. Evidence-backed analysis
4. Patterns and hypotheses
5. Validation status
6. Transferable practices
7. Don't-copy constraints
8. Sources and runtime metadata

## Interaction rules

- Default view shows only the minimum context needed to understand the conclusion.
- Secondary detail uses progressive disclosure.
- Evidence opens in a side drawer rather than replacing the reading position.
- Every conclusion must retain evidence status and confidence.
- Claims without evidence remain explicitly marked as unverified.
- Reader navigation follows document hierarchy, not dashboard-card density.
- Research can link to Case, Person, Topic, Episode, Segment, Story Node and Learning records.

## First benchmark

`cases/liangzi-interview-record-v1.md` is the first benchmark case. It is a research asset, not an endorsement. Conclusions must distinguish observed facts, derived observations, hypotheses, validation and transferable patterns.
