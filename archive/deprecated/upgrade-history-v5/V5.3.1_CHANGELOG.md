# v5.3.1 更新说明

## 核心原则
- 不改变“广州太古汇主体过滤优先、小红书为主平台、全网发现作为底层辅助”的产品定位。
- 不覆盖用户现有 `data/monitor.db`、`.venv`、`.env`。

## AI 可插拔网关
- 新增 `/api/ai/status` 与 `/api/ai/test`。
- `AI_PROVIDER=auto` 优先探测 Ollama、LM Studio、llama.cpp。
- 检测不到本机模型时使用内置本地规则，不影响系统运行。
- 设置页增加“智能引擎”入口，显示当前引擎、模型、状态与本机检测结果。

## 公开互联网发现层
- 默认 Adapter：Google News RSS、GDELT、自定义 RSS。
- `web_mentions` 保持独立数据层，并新增 `source_adapter / query / canonical_url` 字段迁移。
- 公开发现结果仍必须经过广州太古汇主体验证；发现层仅用于底层发现和关键词反哺。

## 历史库
- 保留主体硬过滤 → 规则初判 → 本地 AI（若可用）→ 相关性/情感/风险/摘要 → 事件聚合的复核链路。
- 原始笔记不物理删除，复核结果通过状态与 `note_review_history` 留痕。

## UI
- AI 接口不再隐藏在代码里，系统设置提供明确的智能引擎入口。
- 延续 iOS 风格的轻量按压、Toast、抽屉、平滑滚动与渐进披露。
