# 视觉、交互与可用性：专业验收依据

2026-10-30，根亲自研究与制定。用于完整方案的可执行质量要求；没有制作新界面、运行产品测试或获得认证。标准帮助查漏，原创视觉与专业工作质量仍须实际审阅。

## 直接落实到寰意的签收

| 工作面 | 必须实际执行 | 合格证据与不接受的替代 |
|---|---|---|
| 初次与再次工作 | 用自己的文件开始，直接打开原稿；第二次找到并重开，继续上次选区/意见 | 能到达有效成果、理解保存状态；不靠示例数据、菜单齐全或巨大输入框证明 |
| 研究与资料 | 并读原文和当前稿，沿引用回原位置，再返回；长名、中文/韩文、混合字体、OCR不确定均处理 | 位置和读写状态连续，来源可辨；可访问文字和键盘操作实际验证 |
| 经营/地图/比较 | 切城市、比较集、期间，联动地图/趋势/表格，修改一个纳排条件 | 同一口径与选区，未知坐标不补点、缺值不补零；密集图可读，并有适用表格等价阅读 |
| Office | 选段/页/组内对象/单元格，编辑、撤销、评论、锁定与导出 | 指向明确、选区外保全、工具跟随当前对象；大图截图或只读预览不能替代编辑 |
| 视频与播客 | 真实播放与寻址，拖动剪点/片段、数值精调、多轨监听、重开恢复 | 内容与时间轴同步、选择可见、输入法/快捷键正确；拖放有点按/键盘替代，不能用动画代替真正预览 |
| 长任务与失败 | 一边处理一边改已有稿；取消、重连、素材缺失和保存失败 | 已完成部分可用，迟到结果不覆盖新稿；准确区分运行与完成，进度不编造 |
| 偏好与辅助操作 | 放大文字、缩放、窄屏、减少/关闭动效、高对比、仅键盘、读屏 | 不丢关键功能、顺序与反馈。二维时间线/图表可使用合适滚动和等价控制，不强行压扁来满足页面重排 |

WCAG目标按适用A/AA准则完整执行。具体已核的易漏项：普通UI/必要图形非文本对比3:1；目标尺寸24×24 CSS像素或符合明确定义的间距/等价/例外；焦点不被浮层完全遮住；可拖动作提供不需拖动的指针路径。320 CSS像素重排要求有二维内容例外，不把例外扩成所有页面都不适配。文字间距由用户调整后不得裁切。焦点外观的AAA准则不能误标为AA强制。精确条款在实际实现时按固定规范版本核对。

90ms保留为寰意首次可见操作反馈的工程目标：选中、按下、拾起、输入。它不是所有过渡的统一时长，也不承诺后台工作90ms完成。按参考硬件、输入方式、实际负载和P50/P95记录；Web同时观察INP分布，Windows原生不假报Web指标。连续拖动/滚动另测帧时间与卡顿、音视频另测预览/seek/同步、长任务另测首个有用结果及最终交付。阈值不能靠延迟展示、假成功或偷偷减少数据达成。

## 审阅方式

根负责原创视觉决定，不把配色、构图、动效审美交给子代理。开发时先在真实专业工作中呈现可操作界面，审阅字体层级、密度、内容主次、控制关系、原生作品质感和品牌辨识；不把“有植物/像素/材质”当质量。官网叙事与应用操作分别审，不套同一模板。

选代表性工作面、真实内容规模、系统状态和关键分支，加按WCAG-EM方法的随机样本，检查完整流程。不同作品专业差异必须覆盖：表格/地图/演示/时间线不互相代验。用户任务检验有效性、总耗时和主观负担；记录帮助次数、误操作、修复成本及未完成原因，不能只记成功者。独立用户与专业人员评审用于验证可理解与可交付；自动规则、截图对比、设计文件只是其中证据。

所有检查同时服务全功能：发现复杂场景困难时修操作与实现，不删除功能，不以“高级功能以后再说”让当前界面显得干净。
