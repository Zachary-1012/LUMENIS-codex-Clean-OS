## 二、视觉模型诊断摘要（供后续精修参考）

### 布局架构
- 导航栏占比约 1/4，主内容区 3/4；建议导航收敛至 ~120px（P0）
- 注意：序境规范要求高信息密度，需权衡，非机械缩小

### 信息层级
- 主标题 32px 与输入框 16px 层级差大；建议主标题收敛（P0/P1）
- 版权信息建议弱化（#999→#ccc，10px）

### 配色质感
- 主内容区纯白 #fff vs 导航 #f5f5f5 对比过强 → 建议 Stone 暖灰统一（P1）
- 输入框边框 #ddd 偏硬 → 用 --zb-stone-200 #E7E5E4（P1）
- 主操作按钮纯黑 #000 → 深灰 #333（P2，视品牌基调定）

### icon 统一性
- 存在线性/填充混用 → 统一线性小 Icon 16px #666/#333（P1）

### 状态表达
- "负面确认 34" 未用彩色小圆点 → 建议红色状态点（P1）
- "需处理 1" 橙色点偏冲突 → 收敛为语义色小圆点（P1）
- 注意：序境规范彩色小圆点是"状态签名"，须按语义色表，非任意取色

### 移动端适配
- 侧栏移动端占 1/4 → 建议底部 tab / 抽屉（P1，序境 Mobile-first 已规划）

## 三、筛选原则

视觉模型建议**仅作设计顾问参考**，不直接照单全收：
- 与序境母规范冲突的（如建议任意橙色、纯白改纯灰、过度缩小标题）→ 不采纳或降级
- 符合规范的（token 化、Stone 暖灰、线性 icon、状态点语义、间距统一）→ 纳入精修 backlog
- 所有落地必须走 zbip-tokens.css 令牌，禁止新裸色值
