# O｜ZBMP 平台化研究报告

> 交付物 O · 所属：OSAI P0 三位一体研究体系 · ② Product Intel
> 状态：10大问题 + 18项平台化能力 + 微内核 + 四类插件 + 三级混合隔离 + 定价 + 路线图

## 核心定位结论

**ZBMP 是"平台+垂直应用"的孵化底座，而非通用舆情平台**。不与清博/识微正面竞争。

为内部垂直应用提供"60%通用 + 40%垂直"的快速组装能力，新应用 0→1 从 12 个月压缩到 3 个月。

## 10 大平台问题（摘要）

1. 平台与垂直应用边界不清
2. 多租户数据隔离不完善
3. 插件运行时缺失
4. 能力复用率低
5. 无统一 SDK/API
6. 实时预警引擎缺失
7. 无 CI/CD 流水线
8. 运维体系不完整
9. 定价模型未校准
10. 平台能力与 OSAI 组件对接未定义

## 18 项平台化能力（分类）

- 数据采集框架（多数据源适配）
- 基础 NLP 引擎（分类/情感/实体）
- 多租户运行时（RLS 隔离）
- 插件运行时（四类插件）
- 实时预警引擎（四大平台核心）
- 统一 API/SDK
- 报告模板引擎
- 通知渠道适配
- …（完整 18 项详见研究轨迹）

## 微内核 + 四类插件

```
微内核（核心：多租户 + 身份 + 权限 + 事件总线）
  ├── 数据源插件
  ├── 分析模型插件
  ├── 报告模板插件
  └── 通知渠道插件
```

## 三级混合数据隔离

| 级别 | 隔离方案 |
|------|---------|
| 标准租户 | RLS（行级安全） |
| 高级租户 | 独立 Schema |
| 企业租户 | 独立数据库 |
| 战略租户 | 独立部署 |

六层强制隔离：身份→权限→RLS→Schema→DB→部署
