## 1. 前置条件（P0 级，先于一切施工）

- [ ] **企业号蓝 V 认证**（营业执照+品牌授权书，3-7 工作日）——个人号/未认证企业号**无法接入**
- [ ] **聚光平台推广资质认证**（可同步申请）——私信/留资 API 数据权限依赖聚光
- [ ] **小红书商业开放平台开发者认证** → 创建应用 → 获取 **AppID + AppSecret**
- [ ] 每个企业号/主体独立认证授权；KOS 员工号通过企业号绑定（聚光后台勾选）
- 影响：现有采集链路（live_engine 公开内容）不受影响；本契约仅新增**私信/留资**数据通道

## 2. 需接入的端口清单（Ports/Interfaces）

### 2.1 官方数据端口（核心）
| # | 端口 | 类型 | 用途 | 认证 |
|---|---|---|---|---|
| P1 | **聚光私信线索 API**（webhook） | POST 消息接收地址 | 私信进线→留资线索实时推送 | 聚光主账户 Token |
| P2 | **表单线索 API** | 拉取/回调 | 表单留资线索 | 聚光 Token |
| P3 | **私信通能力**（im/multiCustomerService） | 配置型接口 | 欢迎语、关键词自动回复、留资卡、社媒名片 | 企业号授权 |
| P4 | **OAuth 授权链路** | 授权流 | 聚光→ZBC 接收端授权（无需账号密码） | AppID/AppSecret |

### 2.2 合规留资路径（唯一指定）
```
用户私信进线
  → 自动欢迎语（系统弹卡）
  → 关键词自动回复：留资卡（手机号）/ 社媒名片（企微/个微）
  → 用户填手机号/加微 → 线索归集 ZBC 后台
```
- 留资卡创建：专业号后台「咨询服务 → 获客工具 → 商家名片」（手机号/企微/个微三型）
- **禁止**（判导流违规）：私信/笔记/评论直发微信、手机号、谐音暗语、二维码

### 2.3 可选桥梁（非必须，供对比）
| 工具 | 能力 | 是否采用 |
|---|---|---|
| 芝麻云帆（官方授权） | 多账号归集 + 接 Coze/Dify/FastGPT AI 回复 | 评估（若自研成本高） |
| 来鼓 Pro | 意向评论识别→1v1 私信、沉默客户追粉（留资率+38%） | 借鉴其机制，自研 |
| 有赞多客服 | 聚光专业号+KOS 号接入 | 不采用（封闭） |

## 5. 合规红线（硬约束，写入测试）

1. 不直发微信/手机号/二维码/谐音暗语（一律走私信通卡片）
2. 不绕过平台风控；不 AI 自动评论；不托管养号
3. Token/AppSecret 只存 .env/密钥库，**永不进 Git**
4. AI 回复若启用 → 按平台规则披露
5. 响应时效目标：15S 首响 ≥85%、30S 回复 ≥90%（投流号口径）

## 6. 验收标准（ZBC 测试）

- [ ] 私信进线 → webhook 收到 → leads 表落库（<5s）
- [ ] 关键词命中 → 自动发留资卡（用例：多少钱/怎么买/有没有XX）
- [ ] 评论意向分层正确率 ≥90%（对照人工标注集）
- [ ] 留资线索进入报告中心统计
- [ ] 安全测试：无密钥泄漏（secret scanning 通过）
