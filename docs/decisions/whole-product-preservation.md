# 全产品保全、强化与合并决定

日期：2026-10-30（Asia/Shanghai）。依据：产品负责人关于全新专业产品、完整能力不得弱化、逐条吸收旧要求及直接更新正式文档的连续纠正。

本文记录取舍理由，不形成第二套规划或开发状态表。完整产品范围归[PRODUCT-SPEC](../PRODUCT-SPEC.md)，专业行为归[业务](../domains/business.md)、[研究创作与媒体](../domains/creative.md)、[系统与智能](../domains/intelligence.md)，职责归[架构](../ARCHITECTURE.md)，体验归[DESIGN](../../DESIGN.md)，通过条件归[验收合同](../ACCEPTANCE.md)。

## 保留的是完整专业工作

寰意是服务媒体、广告、品牌营销和商业运营的智能工作空间。商业运营团队、品牌与代理团队、独立研究与创作用户共享能力；购买理由可以聚焦，专业能力不因入口收敛或分批开发删减。工作、监测、资料、成果是使用组织方式，不是四种有限功能。

完整保留客户委托、主体档案与经营、市场消费者研究、财务预算与资源、品牌策略、创作者合作、内容与活动、实验归因、舆情事件、决策行动；独立研究、原创创作、Word/PPT/表格/PDF、完整视频与播客、语言声音以及自研行业AI均有独立专业要求。业务算法在后台承担，用户能直接检查依据、参数、范围和结果，不必调度内部研发流程。

主体一级类型严格只有品牌主体（brand）和商业主体（company）。品牌归品牌主体，商场等商业经营对象归商业主体。客户委托、商户经营者、门店、产品及平台账号保独立身份、档案和完整业务行为；客户关系、集团归属、法律/运营、场内经营等关系保类型、方向、来源及适用期间，不新增并列主体枚举，也不把这些对象降为主体的一段备注或几个字段。原目录及全部经营、监测、合作、财务和创作消费者必须保全。

正式主体目录可持续添加有据在中国境内营业的商业主体或品牌主体，包括国际品牌在中国经营，保原目录分类和有效数据，不限预装清单。境外资料可服务具体研究与比较，不自动扩为全球主体库。临时研究和创作无需先登记主体；这只取消通用门槛，不删除主体领域。

基础业务、专业编辑、保存重开和恢复无需AI。AI增强进入各实际消费者并分别证明收益。Web、Windows和完整官网保各自职责与验收；macOS/iOS依既定设备条件后置，不借后置减少原范围。

## 合并重复负担，替换失效实现

| 处置 | 理由与保全条件 |
|---|---|
| 合并采集与浏览取数的任务、来源、身份、游标和恢复合同 | 一套通用采集系统与强化浏览能力协同；直接公开采集、用户授权浏览及已有获准接口按实际字段/时效选择，不复制调度器或掩盖来源差异 |
| 合并重复资料、权限、版本、任务、导入导出与反馈基础实现 | 同一材料和作品跨入口保持同一身份和版本；各专业输入、状态、操作、消费者及质量仍逐项验收 |
| 合并重复导航和强制内部步骤 | 按真实任务呈现直接操作；专业工作面、快捷键、选区、播放头和失败返回保留，不把四入口当四张同模板表单 |
| 替换被否定的页面骨架、空壳入口、模板生成与伪成功 | 新界面必须承载真实作品密度和专业操作；固定文字、接口成功或截图不能代交付，替换不撤回其原能力 |
| 替换不适用方法和混淆数据口径 | 保要解决的业务问题，说明适用条件与新方法；未知不填零，样本声量不冒市场份额，相关不冒因果，当前累计值不冒历史序列 |
| 复用经核实的自有有效代码、交互机制与已有批准接入 | 逐项核新合同、调用者、许可、数据、恢复及真实操作；不复制被否定视觉，不将存在源码当成可用证明 |

原研究、原始资料、未提交有效成果、用户数据及历史作品保留。删除重复实现须先证明对应有效能力已由现行实现接住；研究引用或目录清理不构成接替证明。资料与能力逐条去向见[重构研究依据](../reference/reconstruction/README.md)及五份保全对照。

## 六项具体增加与深化

以下是相对旧方案更明确的新增行为或深化合同，不宣称所有底层思想都是首次提出。可靠来源、可编辑成果、局部修改、版本恢复和客户反馈本来就有要求，不能重新包装成六项全新发明。

| 增加或深化 | 用户实际得到什么 | 为什么增加及原能力关系 |
|---|---|---|
| 跨格式交付批次冻结与增量补交 | 同一方案、PPT、预算、视频、节目及字幕等锁定实际成员版本；修改后只重做受影响项，失败成员可补交 | 将原版本与媒体输出义务补成成套客户交付，减少各文件版本不一致；共享已有成果/工程所有者 |
| 原生客户评论到具体对象的闭环 | 保作者、原话、被评版本和页/对象/区间锚点；消歧后实际修改，再打开对应差异 | 强化已有客户反馈与修订；“已处理”须对应真实变化，不新增评论孤岛 |
| 修改意图、影响范围与执行差异 | 改价格、禁用词、镜头或一句声音时，指出相关正文、预算、译版、字幕和章节；按范围采用并保未选内容 | 将原来源更正传播与局部修改延伸至跨成果联动，避免客户每改一次重做整套 |
| 更精确的批准范围与失效判断 | 批准绑定对象/主张、版本、用途、渠道、市场和期限；修改仅重核受影响部分 | 补细原权利、客户确认与交付限制，减少整份反复审批；不把普通本地编辑变成审批流程 |
| 多种可比关系的地图、表格和趋势联动 | 同体系跨城、本城竞争、跨城标杆可以重叠；同范围、时间、指标和来源联动并导出 | 吸收Cortech可借鉴的方法，深化原竞争研究和主体关系；不复制其代码、皮肤或单一排名逻辑 |
| 按目的地保存音频交付配置并核终编码 | 格式、采样率、声道、响度及真峰各有适用目标；原混音和派生分开，最终编码后解码测量与听审 | 将原播客母带和多版交付细化，避免统一响度目标或只验编码前文件；不新增独立音频服务 |

六项由现有业务、成果、媒体及任务所有者承担，不另建第二产品、运行时或数据权威。原完整能力的补齐、恢复或换名不能冒新增成果；文档中的新增行为也不代表已实现。

## 采集与自研AI的明确边界

公开信息的稳定性、准确性、时效、覆盖和可恢复性是产品核心。来源围绕实际任务发现与获取，区分原文、页面上下文、公开指标、授权后台及分析结果。监测连接后续判断、可编辑交付、意见修订和继续关注，准确显示检查空窗与授权失效。

平台账号由每位用户自行连接，产品身份与平台会话分开，不硬编码开发者账号或地区为通用用户限制。扫码与官方登录遵循站点实际支持；会话保在对应用户与平台上下文，系统浏览器登录不能假定自动转移。能登录不等于全部字段或历史内容可读，挑战、限速、撤权与缺口须如实处理，不暗换身份或绕过访问限制。

通用模型接口、已有自研小模型、全业务智能应用、未来训练与蒸馏是一套自研行业AI的组成，不是四个产品、四入口或四套并行系统。检索、记忆、长期工作、语言与多模态、工具执行、行业判断和创作必须落到真实业务结果；模型接口不能替代已有小模型能力，未来训练不能后置当前智能义务。

CPU及其他无GPU训练纳入当前自研AI升级，先冻结具体任务、现有资产、数据/标签资格、独立留出、资源预算、质量收益及重载回退方案，全部开发前置完成后再实施。GPU依赖训练保留未来条件路线，不阻基础业务、获准推理、专业编辑、检索记忆与可验证的学习。研究不自动批准接入新模型或服务；CPU任务不等于整个行业AI范围。保持自研路线，已有批准技术可复用，新增研究先找解决方法再决定实现，不扩大未批准集成。

已归档研究须逐实质内容落实到能力、方法、交互或验收，不以保全数量签采用完成。重复合并保差异与出处，失效观点作有据纠正。用户放弃追索的四份业务DOCX及两份历史声音报告不再作缺件或阻塞，其原专业能力由现有材料与适用补研承接。缺少旧分类定义、原模型包或旧评价量表时，保原业务目标、建立有来源的新定义与可复现替代资产，不能无期限等原名或伪称找回。

品牌底蕴沿用“芥子纳须弥”、寰意的人本定位、满天星和五植物身份；品牌理念、哲学及承诺原位更新到[PRODUCT](../../PRODUCT.md)和[DESIGN](../../DESIGN.md)。旧生态命名保沿革，不恢复竞争产品入口。品牌要求与全部领域一同兑现，不只重做Logo和宣传页。

通用OS/任意应用控制、独立图片编辑产品及已撤回的内部声音采集克隆专项不恢复。作品内图文、封面、媒体处理、普通录音及合法外部声音包仍保各自能力；撤回专项不波及它们。
