# LUMENIS Content Intelligence 下一次检索执行指令 V1

## 定位

本模块属于 Content Intelligence（内容制作能力域），不是独立产品。

目标：作为序境旗下多个产品共享能力层，沉淀可复用的内容理解、分析、策划、生成、评估能力。

禁止：
- 不复制第三方完整内容
- 不保存受版权保护的完整节目文本、字幕、脚本
- 不直接把研究资料作为 Production Runtime

遵循：

Source → Provenance → Semantic Review → Copyright/License Review → Method Extraction → Capability Promotion
