## 1. 芥子纳须弥（本库 Canonical 哲学，Zero Sequence 保护）

**[芥子纳须弥]** E4 / FACT / 中（梵汉佛教语境） / v1.0 2026-09-04 / 本库 BRAND-LIFE-PHILOSOPHY-RESEARCH-BASELINE.md
- 来源：佛典「芥子纳须弥」典故（《维摩诘经》不思议解脱品等）。
- 本体系定义：**微小之中本身就包含通向整体的结构。**
- 解释边界：芥子=最小有意义单元（信号/事件/行为/关系/知识单元/代码模块/Agent 感知单元）；须弥=由关系、结构、意义和演化形成的整体。
- 禁用简化：不得简化为 `small → big` 或机械组装；核心是**局部中的结构与关系具有通向、显现与参与整体的潜能**。

**[序境 / 서경 / Xujing]** E4 / FACT / 中·韩（英文 TBD） / v1.0 2026-09-04 / 本库
- 序境（中文 Canonical）、서경（韩文 Canonical）、Xujing（仅历史研发标识，不作新英文 Canonical）。

## 2. Embedded Wholeness（嵌入式整体）

**[Embedded Wholeness]** E1-CONCEPT / CONCEPT / 英 / v1.0 2026-09-04 / 本库语义空间（§7.3 基线）
- 定义：**整体并非后来添加，而是可以通过局部中已有的关系与结构被显现。**
- 与芥子纳须弥同构：都是"局部内蕴整体潜能"，是品牌英文命名最高语义约束之一。

## 3. Relational Becoming（关系性生成）

**[Relational Becoming]** E3 / VERIFIED / 英 / 2026-09-04 / Whitehead 过程哲学 + 当代关系本体论
- 核心主张：**存在本质上是关系性的；实体并非先独立存在再进入关系，而是经由关系过程生成自身。**
- 来源链：
  - Whitehead《Process and Reality》(1929)：现实由 "actual occasions / actual entities" 构成；每一实际缘起都通过 "prehension（领悟）" 把握其他缘起，经 "concrescence（合生）" 达成统一，再作为数据进入未来缘起。"The many become one, and are increased by one."
  - 关系本体论（Whitehead; Barad 2007 "agential realism" / intra-action）：测量与观察参与构成被观察者，relata 不先于 relation。
  - 系统科学印证：动态耦合、相位锁定、跨频耦合（Strogatz 2003; Pikovsky 2001）——意识等涌现现象来自动态关系而非孤立组分的固有属性。
- 与序境关联：为 `Relation → Structure → Meaning → Intelligence → Action → Feedback → Evolution` 生命循环提供哲学支撑；命名候选的"关系性/生成性"语义可追溯到此处。
- **术语归属核验**（E3/VERIFIED，来源见并行基线 `LANGUAGE-BRAND-LIFE-INTELLIGENCE-RESEARCH-2026-09-04.md`）："relational becoming" 是既有研究术语（哲学时间论 2006、对话教育学 2022、关系本体论 2025 等均有使用），**非序境原创**。可作内部研究描述，不得表述为序境专有哲学术语。

**[The many become one, and are increased by one]** E3 / VERIFIED / 英 / 1929 / Whitehead, Process and Reality
- 序境「芥子→须弥→芥子」反馈链的哲学对应：局部分化为整体，整体又作为数据/经验回馈新的局部。与双子库协作（Intelligence↔Core）同构。

**[世界观层级：LIFE→WORLDVIEW→PHILOSOPHY→BRAND→…→FEEDBACK→EVOLUTION]** E1 / CONCEPT / 通用 / v1.0 / 本库基线 §3
- 产品不是哲学的直接同义物，而是哲学在技术、组织与真实世界中的可验证显现。

## 4. 与生命系统的衔接

**[生命循环：感知→关系→结构→意义→理解→智能→行动→反馈→学习→演化]** E1 / CONCEPT / 通用 / v1.0 / 本库基线 §2.1
- 生命并非孤立单元堆叠，而是在持续关系、反馈与演化中形成并保持为整体的过程（CONCEPT，非已实现功能）。

## 5. 方法论映射

**[从局部理解整体 + 从整体反哺局部]** E1 / CONCEPT / 通用 / v1.0 / 本库基线 §6
- 研究不只看单点，识别局部信号背后的关系、结构与系统意义；整体模型反过来改善对单点的解释。
- 落地应用：舆情分析（单条事件→全网结构→回馈单条解读）、内容创作（单一符号→圈层语义场→符号再生成）、AI 系统（Agent 局部感知→全局记忆→反馈学习）。

## 6. 世界观与命名约束的联结

- 英文命名候选若要通过「生命层哲学测试」，语义应落在：**局部/关系/生成/整体显现/生命演化** 的语义场，而非"工具/控制/静态存在"语义场。
- 参考语义候选空间（均为研究语义，非品牌名）：Embedded Wholeness, Relational Becoming, Emergence, Wholeness, Becoming, Revelation, Living System（占用现状见 05-NAMING-RESEARCH.md）。
