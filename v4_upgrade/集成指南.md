## 二、快速集成（3步）

### 第1步：在 app.py 末尾添加

```python
# ===== V4.0 升级模块集成 =====
from v4_upgrade import create_v4_blueprint, init_v4_modules
init_v4_modules()  # 初始化认证表、注册适配器
app.register_blueprint(create_v4_blueprint())
```

### 第2步：安装依赖

```bash
pip install flask requests pdfplumber python-docx openpyxl
```

### 第3步：启动

```bash
# 双击 start_v4.bat
# 或
python app.py
```

## 六、API接口一览

### 认证
- `POST /v4/auth/login` - 登录
- `POST /v4/auth/logout` - 登出
- `GET /v4/auth/me` - 当前用户信息

### 设置页
- `GET /v4/settings/api/users` - 用户列表
- `POST /v4/settings/api/users` - 创建用户（需安全验证）
- `POST /v4/settings/api/users/<id>/status` - 启用/禁用
- `POST /v4/settings/api/users/<id>/reset-password` - 重置密码
- `POST /v4/settings/api/change-password` - 修改自己密码
- `GET /v4/settings/api/audit-logs` - 审计日志
- `GET /v4/settings/api/audit-stats` - 审计统计

### 采集适配器
- `GET /v4/adapters/platforms` - 列出采集平台
- `POST /v4/adapters/search` - 多平台搜索
- `POST /v4/adapters/search-merged` - 多平台搜索合并去重

### 外部导入
- `POST /v4/importer/upload` - 上传文件解析预览
- `POST /v4/importer/confirm` - 确认导入入库

### 数据清洗
- `POST /v4/data/fix-publish-date` - 修复publish_date
- `GET /v4/data/empty-content` - 空正文笔记统计
- `GET /v4/data/backfill-tasks` - 生成补抓任务批次

## 七、LOCK约束（重要）

以下太古汇核心业务函数**禁止修改内部实现**，V4模块只做外壳封装：
- `SUBJECT_WORDS` - 关键词词典
- `subject_hit()` - 关键词匹配
- `aggregate_events()` - 事件聚合
- `build_daily_report()` - 日报生成

## 八、不覆盖现有系统

- V4所有代码在 `v4_upgrade/` 目录下，不修改现有文件
- 新增数据库表以 `v4_` 前缀，不影响现有38张表
- 现有HTTP Basic Auth保留作为兜底，V4认证并行运行
- 现有采集器、报告、笔记功能完全不受影响

## 九、数据清洗使用

# 预览（不修改）

## 十、采集适配器扩展

新增采集平台只需继承 `BaseAdapter` 并实现 `search()` 方法：

```python
from v4_upgrade.adapters import BaseAdapter, AdapterResult, registry

class MyPlatformAdapter(BaseAdapter):
    platform_name = "my_platform"
    platform_display = "我的平台"

    def search(self, keyword, max_results=20):
        # 实现采集逻辑
        notes = [self._make_note(title="...", content="...", url="...")]
        return AdapterResult(success=True, notes=notes)

registry.register(MyPlatformAdapter())
```
