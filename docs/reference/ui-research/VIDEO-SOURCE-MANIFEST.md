## 6. 既有逐帧分析结论（后续 UI 蓝图的既定基准，勿推翻）

- 桌面端三栏：260px `#F9F9F9` 侧栏 + 纯白主区 + 280px 右配置/AI 栏；侧栏分组（工作空间/新建/列表/底部设置与头像）。
- 设置页：左分组导航 + 右侧「标题 + 描述 + 右侧控件」行，选中项浅灰。
- 对话/空状态：空状态居中引导；用户气泡右对齐浅灰、AI 左对齐；时间分隔。
- 输入区：大圆角输入框，含 +/模型名/圆形发送键；下拉菜单 = 图标 + 标题 + 描述两行。
- 移动端：满宽贴底 Sheet（顶部圆角 24 + 拖拽条）、毛玻璃导航、骨架屏、居中空状态。
- 状态色仅用于小状态点/小标签，须同时配文字与图标；整体黑白灰侘寂、低装饰、高信息密度。
