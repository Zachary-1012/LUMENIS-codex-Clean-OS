Scope: existing SYSTEM Collector, Shared Database/Evidence and Permission,
registered CTH/BMP/GLOBAL context, the existing collection API and Scheduler.
No second collector, registry, queue or store is introduced. M alone integrates;
other windows remain unresumed. No paid GPU or model call is involved.

## Actual source changes

1. Bind scoped Raw notes, signed Evidence, Canonical, native platform fields and
   append-only metric observations to the same existing transaction. Revocation,
   mismatched source identity or a critical write failure rolls it all back.
   Noncritical run-log failure does not erase an already committed real result.
2. Retain native post/author IDs and publication/capture/update distinctions;
   unknown metrics remain null and source-visible zero stays zero. Updated source
   metrics never silently restore the previous known count as the current count.
3. Task purpose, registered aliases, city/venue/topic/time constraints and
   continuation enter the existing collection API. Focused caller scope cannot
   be replaced by another query target. Clients cannot claim a completed server
   checkpoint to bypass collection; internal task-owner checkpoints remain distinct.
4. Fix the actual signed-Scheduler disconnect: purpose plans already admitted six
   platforms, but the Collector and Permission resource resolver still allowed
   only public_http/web_atom. The existing revocable signed-plan path now checks
   the complete current query and batch bound, normalizes XHS to its same protected
   primary adapter, and uses the real Collector transaction. The generic end-user
   AUTO default, session ownership, pacing and challenge handling are unchanged.
5. Package the exact reviewed 100-term/41-source original and verify seed references
   during query compilation. Old terms, raw spelling, URLs, unknown heat, source
   time and original metadata remain unchanged. Runtime lookup does not depend on
   a developer attachment/work directory; it does not auto-admit sources or training.
6. Fix two GLOBAL refresh defects found during integration: an unchanged source
   must retain existing analysis/annotations and original Canonical capture time;
   a new BMP observation must not be rejected by a legacy CTH column default.
   Only IDs actually inserted in the current transaction may replace that default;
   existing cross-domain/scope records remain protected.
7. Reuse retained WeChat/Instagram native-public parsing, private HK worker
   checkpoint/time/identity fixes, and the existing verified browser-start owner.
   Search-index dates and previews do not become full original post evidence.
