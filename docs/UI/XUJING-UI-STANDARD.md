# 序境 Xujing · UI 设计标准（用户需求权威基线）

> 版本：v1.0 · 2026-09-04
> 来源：用户多轮明确要求 + 上传《动态视觉及ui视觉交互参考》逐帧解析（文字规范为最高优先级）+ GitHub 设计系统前沿研究
> 适用范围：序境-Core（ZBC）与序境-Intelligence（OSAI）全部 UI 模块，中/英/韩三语言同一视觉语言

---

## 一、品牌与哲学

- 产品名：**序境 Xujing**；品牌哲学：**芥子纳须弥**（小即大、克制中的丰盈）。
- Zachary 仅保留为历史仓库 / 研发身份标识，不作为产品品牌。
- 启动海报：**浅色系**（禁深色底）。
- 参考品味：Prada / MiuMiu 时尚品味、LeLabo 香氛的质感克制、观夏的架构布局、Safari / Chrome 页面架构（内置浏览器）。

## 二、视觉基调（一次性定格，不反复横跳）

1. 黑白米灰侘寂（wabi-sabi）：米白/灰为主，细线、留白、低装饰、高信息密度但不拥挤。
2. **微光银（Silver Shimmer）**：银色流光动态全局循环浮动——品牌标题斜向银光扫过、卡片极淡银光呼吸；**不要太深**，始终浅色高级。
3. 细线 SVG icon：1.5px stroke、24×24 viewBox、currentColor、圆头线帽（对齐 Lucide/Feather 方法论）。
4. 动态可视化服务判断：数据驱动、可下钻，**禁为动画而动画、禁假数据假动画**。
5. 层级关系优化：图标 → 文本 → 间距 → 卡片 → 弹窗，逐级清晰。

## 三、14 条 UI 逻辑规范（素材文字原文，最高优先级）

1. **按元素密切关系划分空间**：主间距 6pt 垂直重复对齐；需分开的组用 4pt 次级分隔；按钮间保持 16pt；图标与文字间距表达关联度。
2. **界面元素对比度 ≥3:1**（非文本），文本 ≥4.5:1（WCAG A），AAA 级 7:1；深色模式下放大文本字号保证可读。
3. **单个主按钮执行最重要的操作**：按钮分主/次/取消层级；避免一屏两个主按钮致用户犹豫。
4. **按钮足够目标尺寸**：移动端 ≥48pt×48pt（iOS 44pt / Android 48dp）；按钮间距足够防误触。
5. **确保重要内容可见**：弹窗内容简洁、位置合适、用户可快速浏览；不阻塞当前流程。
6. **减少大文本字间距**：显示型大文本字间距合理，过大降低辨识度。
7. **不要仅依赖颜色作指标**：必须叠加图标/文字/形状辅助识别（→ 状态点 .xj-dot + 文字标签双通道）。
8. **尽量避免多屏对齐**：坚持一种对齐方式，减少滚动/拖动下的视觉偏移困惑。
9. **文本对比度 4.5:1**：正常文本 <18pt 4.5:1；大文本（粗体18pt+/常规24pt+）3:1。
10. **考虑移除不必要容器**：已用其他设计方法时，移除容器提升界面简洁。
11. **仅使用常规与粗体字重**：避免过多字重层级造成视觉混乱；标题用粗体、正文常规。
12. **保持一致**：元素功能一致、圆角一致、组件一致，降低学习成本。
13. **极简 ≠ 单调**：极简用合理逻辑呈现信息层级；图标必须有文字说明，颜色不可消失。
14. **平衡图标与文本组合**：图标与文字间距 ≥1.5× 图标大小，保持紧密关联与视觉秩序。

> 小结：平衡、有序、统一；高度一致性让用户直观理解、降低进入成本。

## 四、动效设计逻辑（用户明确喜欢的方向）

来自参考素材（非普通淡入，而是组合动效）：
- **Stagger**：多个元素逐个级联进入（每个间隔小延迟，形成瀑布式级联）。
- **Multi-translate Keyframes**：多段 translate 沿不同方向冲入（非规则直线飞入）。
- **Float**：轻柔持续漂移，让静态元素灵动、轻盈。
- **Continue-through**：元素各部件持续移动、最终一起落位聚合。
- 结果：**有质感的 Motion，没有大段呆板停顿**。

**实现铁律（用户强约束）**：动效底层逻辑必须由代码建立函数计算 → 数据导入形成表格 → 表格转为代码 → 形成实时动效；动态数据真变才动一次，持续状态按真实 status 呼吸（zbip_motion.js 表驱动引擎）。

## 五、Design Token 体系（GitHub 前沿：primitive→semantic→component）

- 语义三层：primitive（基础值）→ semantic（意图，组件只消费此层）→ component（按组件覆盖）。
- 现代色彩：oklch + color-mix 派生状态色；`:root{color-scheme:light}` + `[data-theme]`。
- 银灰语义 token 见 `static/css/xujing-silver.css`：`--xj-silver-50..500`、`--xj-ink(-soft/-mute)`、`--xj-ok/warn/err/unk`、`--xj-shine-band`。
- 状态色语义 token：ok #3e7c5b / warn #c8a24b / err #c94f4f / unk #9aa5b3。

## 六、细线 icon 体系

- `static/js/xujing-icons.js`：注册表（数据表，52+ 图标）→ `xicon(name,size,cls)` 函数 → 模板 `${xicon()}` / 拼接 `+xicon()+` 调用。
- 规则：1.5px stroke、currentColor、24×24、圆头；状态点用 `.xj-dot`（CSS 圆点）而非彩色 emoji。
- **禁则：任何 emoji 不得作为正式 icon**（含 ⚡ 闪电）；状态符号类 emoji 由 CSS 状态点 / 纯文本替代。

## 七、响应式 / 多端

- Web：完整分析/管理/审计；App：实时状态/风险/操作/监控；Mobile Web：轻量快速；Mini Program：客户报告/核心指标。
- 能力全、不减配，仅渲染器/信息密度/交互差异。
- 中/英/韩切换自动适配文字长度与布局，禁止溢出挤压。

## 八、无障碍

- 文本对比度 ≥4.5:1；非文本 ≥3:1；焦点指示 :focus-visible。
- `prefers-reduced-motion: reduce` 时关闭全部动效（silver-shimmer、card-shine 等）。

## 九、全局禁则（Zero-Sequence 级）

1. 禁 emoji 当正式 icon；状态符号类 emoji 函数化/CSS 状态点化。
2. 禁假数据、假动画、假绿、双真相；UI 不建立第二套业务计算。
3. 禁大字报、巨型 Logo、巨型 Icon、无意义装饰。
4. 动效必须数据驱动（表→函数→实时动效），禁止写死循环动画。
5. 不明晰时保持克制：高质感 > 花哨，留白 > 堆砌。
