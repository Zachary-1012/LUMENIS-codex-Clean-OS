## 每项共同执行条件

每次操作核当前对象、版本、客户/工作区、资料用途与权限；取消保合法输入，过期结果不覆盖当前稿。保存须实际持久化读回，修改可撤销或生成明确新版本；确认外部动作绑定目标、内容和授权范围，不把关闭弹层当取消已发生效果。所有动作提供适用的键盘、点按和读屏路径；输入法、文字选区、播放头与阅读锚点优先保持。窄屏重组同一对象和操作，不删字段来适配。逐条完成条件还包括正常结果、相关失败/冲突、保存重开和该行写明的特殊要求。

定位简写：主稿§5/6为具体工作面和视觉交互；业务§1–9见[业务合同](../../domains/business.md)；创作§1–10见[创作合同](../../domains/creative.md)；智能§1–7见[智能合同](../../domains/intelligence.md)。这些是同一方案的职责，不是新产品入口。

## 共用视觉与首次使用的明确补足

以上213项保的是实际操作与行为差异，不强制保旧“213种设计”统计口径。新对象/原规划细项不以213为上限。原295个IC和311步骤是旧索引：既有映射用于找原要求，不能用合并计数删除其中不同输入、状态或消费者。44屏原接口/字段/错误/权限合同仍逐项随对应领域迁移，不复活被否定页面。

首次进入可直接打开文件、写空白稿、描述目标或继续工作；不强制选择职业/主体/模型。随手记可从文字、网页或媒体选区就地留下带出处笔记，随后选带入哪个工作；创建随手记不自动外发、训练或改变原作品。当前任务、结果、来源、意见和活动历史有明确关系，返回保原位置。

通知只对有用结果、需决定或重要异常触发，可看普通进度但不广播每段内部输出；范围、接收人、版本和去重明确，必要确认不被静默丢掉，通知点击返回准确工作。偏好实际读回，本端保存不冒云同步。

动作首次可见反馈以原90ms目标验，连续直接操作保60fps与p95帧时间16.7ms原目标；按明确硬件、场景、分辨率与样本测量。网络/渲染/推理完成另量，不把单帧或空页测试当达标。复杂真实任务采用WCAG2.2 AA、200%字号、键盘/读屏、触控目标及减少动态验收，参照[视觉验收依据](visual-acceptance-reference.md)。桌面、Web、窄屏和条件后置的macOS/iOS分别记录，不互冒通过。
