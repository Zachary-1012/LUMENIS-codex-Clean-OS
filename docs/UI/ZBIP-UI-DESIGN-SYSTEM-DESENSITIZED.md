## 一、设计系统概述

### 1.1 平台定位
- **平台名称**：Z-Brand Intelligence Platform（ZBIP）
- **设计语言**：侘寂黑白灰 + 微光银 + 大彩色语义 icon + 海浪浮动
- **设计参考**：Prada / MiuMiu（极简时尚）、LeLabo / 观夏（留白架构）、GPT / Codex / Linear（工程产品）
- **核心原则**：Quiet（克制）、Precise（精准）、Dense（高密度）、Minimal（极简）、Fast（快速）、Readable（可读）

### 1.2 视觉风格关键词
- 大面积留白，低装饰，弱边框
- 高信息密度，明确排版层级
- 小型状态点（彩色圆点）作为视觉签名
- 紧凑按钮，统一圆角，清晰层级
- 银色流光全局循环浮动，海浪逻辑，微光银
- 禁止：大面积渐变、装饰性背景、无意义阴影、彩色卡片海洋、过度圆角

## 二、设计 Token 体系

### 2.1 颜色 Token（Stone 暖黑白灰）

| Token | 值 | 用途 |
|---|---|---|
| `--zb-stone-0` | #FFFFFF | 纯白 |
| `--zb-stone-50` | #FAFAF9 | 画布底（页面背景） |
| `--zb-stone-100` | #F5F5F4 | 凹陷区/表头 |
| `--zb-stone-200` | #E7E5E4 | 默认边框 |
| `--zb-stone-300` | #D6D3D1 | 强边框/分隔 |
| `--zb-stone-400` | #A8A29E | 禁用状态 |
| `--zb-stone-500` | #78716C | muted 文本 |
| `--zb-stone-600` | #57534E | 次级文本 |
| `--zb-stone-700` | #44403C | 主文本 |
| `--zb-stone-800` | #292524 | 强调文本/按钮 |
| `--zb-stone-900` | #1C1917 | 最深文本 |

### 2.2 语义色（仅用于状态和重要操作）

| 颜色 | 值 | 用途 |
|---|---|---|
| Success | #22C55E | 正常/健康/成功 |
| Warning | #F59E0B | 关注/警告 |
| Danger | #EF4444 | 严重/错误/风险 |
| Info | #3B82F6 | 信息/进行中 |
| Idle | #D6D3D1 | 未知/未激活 |

**规则**：颜色不能成为唯一的信息表达方式，必须同时有文字 + icon + 状态。

### 2.3 间距 Token
- 4 / 8 / 12 / 16 / 24 / 32 / 40 px
- 组件内边距：8-16px
- 组件间距：16-24px
- 区块间距：32-40px

### 2.4 圆角 Token
- 4px：小元素（标签、状态点）
- 8px：按钮、输入框、卡片
- 12px：弹窗、抽屉、大卡片
- 禁止：超过 16px 的圆角

### 2.5 阴影 Token（微光银柔和阴影）
- 卡片默认：`0 1px 3px rgba(28,25,23,0.04), 0 4px 12px rgba(28,25,23,0.03)`
- 卡片悬停：`0 2px 8px rgba(28,25,23,0.06), 0 8px 24px rgba(28,25,23,0.05)`
- 按钮：`0 1px 2px rgba(28,25,23,0.15)`
- 禁止：厚重阴影、彩色阴影、发光阴影

## 五、交互规则

### 5.1 状态机
所有操作必须有明确反馈：
- **Idle**：默认状态
- **Hover**：浅灰背景，cursor pointer
- **Active/Pressed**：深色背景，缩放 0.98
- **Loading**：禁用点击，显示加载指示器
- **Success**：绿色状态点 + 成功提示
- **Error**：红色状态点 + 错误信息 + 重试
- **Disabled**：灰色，opacity 0.5，禁用点击

### 5.2 异步操作
所有异步操作必须：
1. 点击 → 视觉反馈（按钮 loading 状态）
2. 处理中 → 禁用重复点击
3. 成功 → 绿色 Toast + 数据刷新
4. 失败 → 红色 Toast + 错误详情 + 重试按钮

### 5.3 危险操作
删除、归档、重置等危险操作必须：
1. 点击 → 二次确认弹窗
2. 确认 → 执行 + 成功提示
3. 支持撤销（5 秒内）

### 5.4 动效系统
| 动效类型 | 时长 | 曲线 | 用途 |
|---|---|---|---|
| 微交互（hover/click） | 100-150ms | ease-out | 按钮、链接、icon |
| 状态变化 | 180-280ms | ease-in-out | 状态点、标签、展开/收起 |
| 页面/弹窗转换 | 280-400ms | cubic-bezier(0.4,0,0.2,1) | 弹窗、抽屉、页面切换 |
| 全局流光 | 12-18s | ease-in-out infinite | 银色流光海浪浮动 |

**规则**：所有动画必须有目的，禁止无意义动画。低端设备必须能正常运行。

### 5.5 键盘导航
- Tab：在可交互元素间移动
- Enter：激活当前元素
- Esc：关闭弹窗/抽屉
- Ctrl+K：打开命令面板/搜索
- ↑↓：在列表/菜单中移动
- 所有可交互元素必须有 focus 样式（2px 近黑外框）

## 六、响应式设计

### 6.1 断点
| 断点 | 宽度 | 设备 |
|---|---|---|
| Mobile | 390-430px | 手机 |
| Tablet | 768-1024px | 平板 |
| Desktop | 1280-1440px | 桌面 |
| Wide | 1920px+ | 宽屏 |

### 6.2 移动端适配
- 左侧栏 → 底部导航（5 个核心功能）
- 顶部栏 → 紧凑模式，搜索可展开
- 表格 → 卡片列表（每行转卡片）
- 弹窗 → 底部 Sheet（从底部滑出）
- 抽屉 → 全屏覆盖
- 考虑：单手操作、拇指区域、安全区域、键盘弹出

### 6.3 内容溢出处理
- 表格：横向滚动，固定首列
- 文本：单行省略（...），hover 显示完整
- 数字：等宽字体，右对齐
- 图片：等比缩放，object-fit cover

## 八、产品差异化设计

### 8.1 CTH-POMS（舆情监测生产系统）
- **定位**：舆情风险驾驶舱
- **重点**：实时、风险、事件、报告
- **布局**：Dashboard 信息密度高，状态清晰，风险优先
- **首页**：健康状态 + 监测状态 + 事件状态 + 风险状态 + 快捷操作

### 8.2 ZBMP（品牌监测平台）
- **定位**：品牌智能平台
- **重点**：品牌资产、市场洞察、竞品、AI 分析
- **布局**：分析工作台，探索性，关系化，分析化
- **首页**：品牌概览 + 市场趋势 + 竞品对比 + AI 洞察

### 8.3 DCC（研发治理中枢）
- **定位**：研发控制中心
- **重点**：任务、审计、版本、Evidence、Release
- **布局**：控制台化，状态明确，操作精准，审计可追溯

### 8.4 SICI（智能研究学习中枢）
- **定位**：研究实验平台
- **重点**：Research、Experiment、Runtime、Knowledge
- **布局**：实验工作台，实验可追踪，证据可验证，知识可沉淀

## 十、附录：设计参考

### 10.1 时尚品牌参考
- **Prada**：极简、克制、黑白灰、高级质感
- **MiuMiu**：年轻、俏皮、但保持极简骨架
- **LeLabo**：留白、实验室感、标签美学
- **观夏**：东方侘寂、留白、自然质感

### 10.2 工程产品参考
- **GPT / Codex**：聊天式交互、命令面板、状态驱动
- **Linear**：高密度、键盘优先、动效精致
- **Vercel**：极简、黑白、几何感
- **GitHub Primer**：组件化、语义化、可访问性

### 10.3 设计原则总结
> **同一产品家族，不同产品职责，不同信息架构。**
> 用户一眼就知道这是同一个 ZBIP 产品家族，
> 但进入不同产品后，CTH-POMS 像舆情驾驶舱，
> ZBMP 像品牌情报工作台，DCC 像研发控制中心，
> SICI 像研究学习工作台。
